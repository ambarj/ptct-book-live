The Big Three: Centers, Sources, Saddles

In Section 5.3 you learned to find fixed points. Now comes the deeper question: what happens near them? Nearby trajectories can circle forever, spiral in, spiral out, or split — and the behavior falls into just a few fundamental types. Classify the fixed points, and you understand the entire phase portrait.

Learning Objectives
  • Recognize the six fundamental fixed-point types: center, stable/unstable node, stable/unstable spiral, and saddle
  • Connect each type to its eigenvalue signature: real vs complex, positive vs negative
  • Use the trace-determinant plane to classify any 2×2 linear system at a glance
  • Identify fixed-point types from phase portraits alone

For a linear system \( \dot{\mathbf{x}} = \mathbf{A}\mathbf{x} \), the eigenvalues of \( \mathbf{A} \) completely determine the behavior near the origin. And those eigenvalues depend on just two numbers: the trace \( \tau = a + d \) and the determinant \( \Delta = ad - bc \).

Eigenvalues from trace and determinant:

$$ \lambda_{1,2} = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2} $$

Real eigenvalues when \( \tau^2 > 4\Delta \). Complex when \( \tau^2 < 4\Delta \). The sign of \( \tau \) determines stability. The sign of \( \Delta \) separates saddles from everything else.

The Classification Map

The trace-determinant plane is the complete classification for linear systems. Every point \( (\tau, \Delta) \) maps to a unique type:

  • \( \Delta < 0 \): Saddle (always unstable)
  • \( \Delta > 0, \; \tau < 0 \): Stable (node if \( \tau^2 > 4\Delta \), spiral if \( \tau^2 < 4\Delta \))
  • \( \Delta > 0, \; \tau > 0 \): Unstable (node or spiral)
  • \( \Delta > 0, \; \tau = 0 \): Center (neutrally stable)

You see trajectories approaching the origin but along curved paths that wrap around it. What type is this?
Explanation: Curved paths that wrap and converge → stable spiral. A center also wraps but never converges. A stable node converges but along straight lines (eigenvector directions). The key distinction: spirals have complex eigenvalues (oscillatory), nodes have real eigenvalues (monotonic).
A system where trajectories approach the origin along straight lines (not curves) has eigenvalues that are .
Explanation: Real eigenvalues produce straight-line trajectories along eigenvectors. This is because the general solution is \( \mathbf{x}(t) = c_1 e^{\lambda_1 t} \mathbf{v}_1 + c_2 e^{\lambda_2 t} \mathbf{v}_2 \). When started on an eigenvector, the motion stays on that line. Which of these fixed-point types are structurally stable — meaning a small perturbation of the matrix does NOT change the type? (Select all that apply)
Explanation:
  • Center: ✗ Lives on the τ = 0 boundary. Any perturbation pushes τ positive or negative, converting it to a spiral. Centers are structurally unstable.
  • Stable spiral: ✓ Lives in the interior of a region. Small changes to τ and Δ keep it a stable spiral.
  • Unstable node: ✓ Also in a region interior — robust to perturbations.
  • Saddle: ✓ The entire half-plane \( \Delta < 0 \) is saddle territory — very robust.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def solve_rk4(A, x0, T, N):
    """RK4 solver for dx/dt = A @ x."""
    h = T / N
    x = np.array(x0, dtype=float)
    traj = [x.copy()]
    for _ in range(N):
        k1 = A @ x
        k2 = A @ (x + h/2 * k1)
        k3 = A @ (x + h/2 * k2)
        k4 = A @ (x + h * k3)
        x += h/6 * (k1 + 2*k2 + 2*k3 + k4)
        traj.append(x.copy())
        if np.linalg.norm(x) > 20:
            break
    return np.array(traj)

# Six canonical types
types = {
    'Center':          np.array([[0, 1], [-4, 0]]),
    'Stable Node':     np.array([[-1, 0], [0, -3]]),
    'Unstable Node':   np.array([[1, 0], [0, 3]]),
    'Saddle':          np.array([[2, 0], [0, -1]]),
    'Stable Spiral':   np.array([[-0.2, 1], [-1, -0.2]]),
    'Unstable Spiral': np.array([[0.2, 1], [-1, 0.2]]),
}

fig = make_subplots(rows=2, cols=3,
                    subplot_titles=list(types.keys()))

for idx, (name, A) in enumerate(types.items()):
    row, col = idx // 3 + 1, idx % 3 + 1
    T = 20 if 'Node' in name or 'Saddle' in name else 30
    for theta in np.linspace(0, 2*np.pi, 10, endpoint=False):
        x0 = [1.5 * np.cos(theta), 1.5 * np.sin(theta)]
        traj = solve_rk4(A, x0, T, 2000)
        fig.add_trace(go.Scatter(
            x=traj[:, 0], y=traj[:, 1],
            mode='lines', line=dict(width=1),
            showlegend=False
        ), row=row, col=col)

fig.update_xaxes(range=[-3, 3], zeroline=True,
                 zerolinecolor='#808080')
fig.update_yaxes(range=[-3, 3], zeroline=True,
                 zerolinecolor='#808080')
fig.update_layout(template='plotly_dark',
                  height=700, width=900)
fig.show()

import numpy as np
import plotly.graph_objects as go

# Build the trace-determinant classification diagram
tau = np.linspace(-4, 4, 400)
delta = np.linspace(-3, 6, 400)
T, D = np.meshgrid(tau, delta)

# Classify each point: 0=Saddle, 1=StableNode, 2=UnstableNode,
#                       3=StableSpiral, 4=UnstableSpiral
Z = np.zeros_like(T)
Z[D < 0] = 0                                    # Saddle
Z[(D >= 0) & (T**2 >= 4*D) & (T < 0)] = 1      # Stable Node
Z[(D >= 0) & (T**2 >= 4*D) & (T >= 0)] = 2     # Unstable Node
Z[(D >= 0) & (T**2 < 4*D) & (T < 0)] = 3       # Stable Spiral
Z[(D >= 0) & (T**2 < 4*D) & (T >= 0)] = 4      # Unstable Spiral

colors = ['#ff006e', '#00ff88', '#ff5722',
          '#40c4ff', '#ffbe0b']
names = ['Saddle', 'Stable Node', 'Unstable Node',
         'Stable Spiral', 'Unstable Spiral']

fig = go.Figure()
fig.add_trace(go.Heatmap(
    z=Z, x=tau, y=delta, opacity=0.3,
    colorscale=[[i/4, c] for i, c in enumerate(colors)
                for _ in range(2)],
    showscale=False, zmin=-0.5, zmax=4.5
))

# Parabola boundary
t_par = np.linspace(-4, 4, 200)
fig.add_trace(go.Scatter(
    x=t_par, y=t_par**2/4, mode='lines',
    line=dict(color='white', width=2, dash='dash'),
    name='Δ = τ²/4'
))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Trace τ', range=[-4, 4],
               zerolinecolor='#808080'),
    yaxis=dict(title='Determinant Δ', range=[-3, 6],
               zerolinecolor='#808080'),
    height=550, width=600
)
fig.show()
