The Binomial Distribution

You know the statistics of random walks: \( \langle x \rangle = 0 \) and \( \langle x^2 \rangle = N \). But what is the exact probability of ending at position \( m \) after \( N \) steps? The answer is the binomial distribution — the same distribution that describes coin flips. It starts spiky for small N, but as N grows, it morphs into a smooth bell curve: the Gaussian.

Learning Objectives
  • Derive the probability \( P(n_R) = \binom{N}{n_R} p^{n_R} q^{N-n_R} \) of taking \( n_R \) right steps out of \( N \)
  • Convert between \( n_R \) (right steps) and position \( m = 2n_R - N \)
  • Watch the binomial distribution evolve from discrete and spiky (small N) to a smooth Gaussian (large N)
  • Verify that simulation histograms match the exact binomial formula

The Binomial Distribution:

$$ P(n_R \text{ right steps}) = \binom{N}{n_R} p^{n_R} q^{N - n_R}, \qquad \binom{N}{n_R} = \frac{N!}{n_R!\,(N - n_R)!} $$

Position after N steps: \( m = 2n_R - N \) (ranges from \( -N \) to \( +N \) in steps of 2). The peak is at \( n_R = Np \), i.e., \( m = N(p - q) \). The width is \( \sigma = 2\sqrt{Npq} \).

Why Only Even or Odd Positions?

After N steps, the position \( m = 2n_R - N \) has the same parity as N. If N is even, only even positions are reachable; if N is odd, only odd positions. This is why the distribution has gaps — you can’t be at position 3 after 10 steps, because 10 − 3 = 7 isn’t divisible by 2. The gaps disappear visually for large N as the spacing becomes negligible.

Set N = 20, p = 0.5. Where is the peak of the distribution?
Explanation: For p = 0.5: peak at \( m = N(p - q) = 0 \). The most probable outcome is equal numbers of left and right steps, returning to the origin. But the probability of exactly m = 0 decreases as \( 1/\sqrt{N} \) — even the most likely position becomes unlikely for large N.
Increase N from 20 to 80. By what factor does the distribution’s width grow? Predict, then verify. .
Explanation: The width scales as \( \sigma = \sqrt{N} \), so going from \( N = 20 \) to \( N = 80 \) multiplies it by \( \sqrt{80/20} = \sqrt{4} = 2 \). Quadrupling the steps only doubles the spread — the \( \sqrt{N} \) law again. Watch the histogram get twice as wide, not four times.
Set p = 0.6 (biased). How does the distribution change?
Explanation: With p = 0.6, the peak shifts to \( m = N(2p - 1) = 20 \times 0.2 = 4 \). The distribution is still bell-shaped but asymmetric and centered at the drift value. The width is slightly narrower: \( \sigma = 2\sqrt{20 \times 0.6 \times 0.4} \approx 4.38 \).

Python Code

Python 

import numpy as np
import plotly.graph_objects as go
from math import comb

N, p = 50, 0.5
q = 1 - p

# Exact binomial P(n_R) for each possible n_R
n_R_vals = np.arange(0, N + 1)
m_vals = 2 * n_R_vals - N  # position
probs = np.array([comb(N, int(nR)) * p**nR * q**(N-nR)
                  for nR in n_R_vals])

# Gaussian approximation
mu = N * (p - q)
sigma = 2 * np.sqrt(N * p * q)
x = np.linspace(mu - 4*sigma, mu + 4*sigma, 200)
gauss = np.exp(-(x - mu)**2 / (2 * sigma**2)) / (sigma * np.sqrt(2*np.pi))

fig = go.Figure()
fig.add_trace(go.Bar(x=m_vals, y=probs,
    marker_color='#00f3ff', opacity=0.7, name='Binomial'))
fig.add_trace(go.Scatter(x=x, y=gauss * 2,  # factor 2 for bar spacing
    mode='lines', line=dict(color='white', width=2, dash='dash'),
    name=f'Gaussian (σ={sigma:.1f})'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Position m', zerolinecolor='#808080'),
    yaxis=dict(title='P(m)', zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go
from math import comb

N, p, n_walkers = 50, 0.5, 5000

# Simulation
finals = np.sum(np.random.choice([-1, 1], (n_walkers, N)), axis=1)

# Theory
n_R_vals = np.arange(0, N + 1)
m_vals = 2 * n_R_vals - N
probs = np.array([comb(N, int(nR)) * p**nR * (1-p)**(N-nR)
                  for nR in n_R_vals])

fig = go.Figure()
fig.add_trace(go.Histogram(x=finals, nbinsx=N+1,
    histnorm='probability density',
    marker_color='#00f3ff', opacity=0.6,
    name='Simulation'))
fig.add_trace(go.Bar(x=m_vals, y=probs / 2,  # /2 for density
    marker_color='#ffbe0b', opacity=0.5,
    name='Exact binomial'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Position m', zerolinecolor='#808080'),
    yaxis=dict(title='Probability density', zerolinecolor='#808080'),
    barmode='overlay', height=450, width=600)
fig.show()
