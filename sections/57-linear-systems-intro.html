Linear Systems & Eigenvalues

Every 2D linear system can be written as \( \dot{\mathbf{x}} = A\mathbf{x} \) where \( A \) is a 2×2 matrix. In the last section you explored the love-affairs model — adjusting personality parameters and watching phase portraits change. But why do certain parameter choices give spirals while others give saddles? The answer is eigenvalues: two numbers that encode everything about the system’s behavior.

Learning Objectives
  • Write any 2D linear system in matrix form \( \dot{\mathbf{x}} = A\mathbf{x} \) and identify the matrix \( A \)
  • Compute eigenvalues and eigenvectors of a 2×2 matrix and interpret their meaning in phase space
  • Understand that eigenvectors are special directions of pure exponential motion, and eigenvalues set the rate
  • See how the general solution \( \mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2 \) builds every trajectory from two fundamental modes

The Linear System:

$$ \dot{x} = ax + by, \qquad \dot{y} = cx + dy $$

In matrix form:

$$ \dot{\mathbf{x}} = A\mathbf{x}, \qquad A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} $$

The eigenvalues \( \lambda_{1,2} \) satisfy \( \lambda^2 - \tau\lambda + \Delta = 0 \) where \( \tau = a + d \) (trace) and \( \Delta = ad - bc \) (determinant).

Explorer: Eigenvector Directions

Eigenvectors are the special directions in phase space where motion is purely exponential: a particle launched along an eigenvector stays on that line forever, growing or decaying as \( e^{\lambda t} \). All other trajectories are combinations of motion along both eigenvector directions. Adjust the eigenvalues directly and watch the phase portrait respond.

Why Eigenvectors Matter

If you launch a trajectory from a point on an eigenvector line, it stays on that line: \( \mathbf{x}(t) = x_0 e^{\lambda t} \hat{\mathbf{v}} \). The eigenvector is an invariant line — the flow never leaves it. For a saddle, the two eigenvector lines are the stable and unstable manifolds. For a node, both eigenvector lines point toward (or away from) the fixed point, and all other trajectories approach tangent to the slow eigenvector (the one with eigenvalue closer to zero).

Set \( \lambda_1 = 2, \lambda_2 = -1 \) (a saddle). Which eigenvector direction do trajectories escape along as \( t \to \infty \)?
Explanation: The solution is \( \mathbf{x}(t) = c_1 e^{2t}\mathbf{v}_1 + c_2 e^{-t}\mathbf{v}_2 \). As \( t \to \infty \), the \( e^{2t} \) term dominates and the \( e^{-t} \) term vanishes. So all generic trajectories eventually align with \( \mathbf{v}_1 \) — the unstable manifold.
Set \( \lambda_1 = -0.5, \lambda_2 = -3 \) (a stable node). As trajectories approach the origin, which eigenvector direction do they become tangent to?
Explanation: Near the origin, \( \mathbf{x}(t) \approx c_1 e^{-0.5t}\mathbf{v}_1 + c_2 e^{-3t}\mathbf{v}_2 \). The \( e^{-3t} \) component dies out much faster than \( e^{-0.5t} \), so eventually only the \( \mathbf{v}_1 \) component survives. All trajectories become tangent to the slow eigenvector as they approach the fixed point. The fast direction is “used up” first.

Explorer: Solution Decomposition

The general solution is a sum of two fundamental modes: \( \mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2 \). Each mode evolves independently along its eigenvector direction. Set an initial condition and watch the two modes combine to build the full trajectory.

The Big Picture

Every linear system is just a combination of exponentials along special directions. The eigenvalues tell you the rates (growth, decay, or oscillation) and the eigenvectors tell you the directions. This is why eigenvalue analysis is so powerful: two numbers (\( \lambda_1, \lambda_2 \)) determine the entire qualitative behavior of the system — no simulation needed.

import numpy as np
import plotly.graph_objects as go

def rk4_solve(A, x0, T, N):
    """Solve dx/dt = Ax using RK4."""
    h = T / N
    x = np.array(x0, dtype=float)
    traj = [x.copy()]
    for _ in range(N):
        f = lambda u: A @ u
        k1 = f(x); k2 = f(x + h/2*k1)
        k3 = f(x + h/2*k2); k4 = f(x + h*k3)
        x += h/6 * (k1 + 2*k2 + 2*k3 + k4)
        if np.linalg.norm(x) > 20: break
        traj.append(x.copy())
    return np.array(traj)

# Saddle example
A = np.array([[1, 1], [0, -2]])
eigenvalues, eigenvectors = np.linalg.eig(A)
print(f"Eigenvalues: {eigenvalues}")
print(f"Eigenvectors:\n{eigenvectors}")

fig = go.Figure()
colors = ['#00f3ff', '#ff006e', '#ffbe0b', '#00ff88',
          '#bb86fc', '#ff5722', '#76ff03', '#40c4ff']

# Trajectories from multiple ICs
for k in range(8):
    th = k * np.pi / 4
    traj = rk4_solve(A, [1.5*np.cos(th), 1.5*np.sin(th)], 5, 1000)
    fig.add_trace(go.Scatter(
        x=traj[:,0], y=traj[:,1], mode='lines',
        line=dict(color=colors[k], width=1.5),
        showlegend=False))

# Eigenvector lines
for i in range(2):
    v = eigenvectors[:, i]
    fig.add_trace(go.Scatter(
        x=[-3*v[0], 3*v[0]], y=[-3*v[1], 3*v[1]],
        mode='lines',
        line=dict(color='white', width=1.5, dash='dash'),
        name=f'v{i+1} (λ={eigenvalues[i]:.1f})'))

fig.update_layout(
    template='plotly_dark',
    title=f'A = [[{A[0,0]},{A[0,1]}],[{A[1,0]},{A[1,1]}]]',
    xaxis=dict(title='x', range=[-3, 3],
               zerolinecolor='#808080'),
    yaxis=dict(title='y', range=[-3, 3],
               zerolinecolor='#808080',
               scaleanchor='x'),
    height=500, width=550)
fig.show()

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# Stable node: eigenvalues -0.5 and -3
# Build matrix with eigenvectors at 30° and 120°
lam1, lam2 = -0.5, -3.0
th = np.radians(30)
V = np.array([[np.cos(th), np.cos(th + np.pi/2)],
              [np.sin(th), np.sin(th + np.pi/2)]])
D = np.diag([lam1, lam2])
A = V @ D @ np.linalg.inv(V)

# Solve from IC and decompose into modes
x0 = np.array([1.5, 0.5])
c = np.linalg.solve(V, x0)  # Decomposition coefficients

t = np.linspace(0, 6, 500)
mode1 = np.outer(c[0] * np.exp(lam1 * t), V[:, 0])
mode2 = np.outer(c[1] * np.exp(lam2 * t), V[:, 1])
full = mode1 + mode2

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Phase Portrait', 'Mode Decomposition'])

# Phase portrait with eigenvector lines
fig.add_trace(go.Scatter(
    x=full[:,0], y=full[:,1], mode='lines',
    line=dict(color='#00f3ff', width=2),
    name='Trajectory'), row=1, col=1)

for i, (v, lam, col) in enumerate(zip(
        V.T, [lam1, lam2], ['#ff5722', '#00ff88'])):
    fig.add_trace(go.Scatter(
        x=[-3*v[0], 3*v[0]], y=[-3*v[1], 3*v[1]],
        mode='lines', line=dict(color=col, dash='dash'),
        name=f'v{i+1} (λ={lam})'), row=1, col=1)

# Time series of mode amplitudes
fig.add_trace(go.Scatter(
    x=t, y=c[0]*np.exp(lam1*t), mode='lines',
    line=dict(color='#ff5722', width=2),
    name=f'c₁e^(λ₁t)'), row=1, col=2)
fig.add_trace(go.Scatter(
    x=t, y=c[1]*np.exp(lam2*t), mode='lines',
    line=dict(color='#00ff88', width=2, dash='dash'),
    name=f'c₂e^(λ₂t)'), row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(zerolinecolor='#808080', row=1, col=1,
    range=[-3, 3], title='x')
fig.update_yaxes(zerolinecolor='#808080', row=1, col=1,
    range=[-3, 3], title='y', scaleanchor='x')
fig.update_xaxes(zerolinecolor='#808080', row=1, col=2,
    title='Time')
fig.update_yaxes(zerolinecolor='#808080', row=1, col=2,
    title='Amplitude')
fig.show()
