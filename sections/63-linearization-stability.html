Stability from Linearization

You now have all the tools: find fixed points, compute the Jacobian, extract eigenvalues, classify on the τ-Δ plane. This section puts the full pipeline together and addresses the critical question: when can you trust the linearized prediction? The answer involves a key concept — hyperbolic fixed points.

Learning Objectives
  • Execute the complete linearization pipeline: system → fixed points → Jacobian → eigenvalues → classification
  • Understand hyperbolic fixed points: no eigenvalue has zero real part → linearization is trustworthy
  • Identify non-hyperbolic cases (centers, zero eigenvalues) where nonlinear terms can change the qualitative behavior
  • Apply linearization to classify multiple fixed points of a single system and build the global phase portrait

The Complete Pipeline:

$$ \dot{\mathbf{x}} = \mathbf{F}(\mathbf{x}) \;\xrightarrow{1}\; \mathbf{F}(\mathbf{x}_0) = 0 \;\xrightarrow{2}\; J = D\mathbf{F}\big|_{\mathbf{x}_0} \;\xrightarrow{3}\; \lambda_{1,2} \;\xrightarrow{4}\; \text{Classification} $$

Trust rule: If all eigenvalues have nonzero real part (\( \text{Re}(\lambda) \neq 0 \)), the fixed point is hyperbolic and linearization gives the correct qualitative behavior.

Hyperbolic = Trustworthy

A fixed point is hyperbolic if no eigenvalue of the Jacobian lies on the imaginary axis (i.e., \( \text{Re}(\lambda_i) \neq 0 \) for all \( i \)). The Hartman-Grobman theorem guarantees that near a hyperbolic fixed point, the nonlinear system is topologically equivalent to its linearization. Saddles, stable nodes, unstable nodes, and spirals are all hyperbolic — they’re robust. Centers (\( \text{Re}(\lambda) = 0 \)) are not hyperbolic and can be destroyed by tiny nonlinear perturbations.

import numpy as np
import plotly.graph_objects as go

def rk4(f, g, x0, y0, T, N):
    h=T/N; X,Y=[x0],[y0]; x,y=x0,y0
    for _ in range(N):
        k1x,k1y=f(x,y),g(x,y)
        k2x,k2y=f(x+h/2*k1x,y+h/2*k1y),g(x+h/2*k1x,y+h/2*k1y)
        k3x,k3y=f(x+h/2*k2x,y+h/2*k2y),g(x+h/2*k2x,y+h/2*k2y)
        k4x,k4y=f(x+h*k3x,y+h*k3y),g(x+h*k3x,y+h*k3y)
        x+=h/6*(k1x+2*k2x+2*k3x+k4x)
        y+=h/6*(k1y+2*k2y+2*k3y+k4y)
        if abs(x)>20 or abs(y)>20: break
        X.append(x); Y.append(y)
    return np.array(X), np.array(Y)

def analyze_fp(name, J, x0, y0):
    tau = np.trace(J)
    delta = np.linalg.det(J)
    evals = np.linalg.eigvals(J)
    hyp = all(abs(e.real) > 1e-6 for e in evals)
    if delta < 0: fp_type = 'Saddle'
    elif abs(tau*tau - 4*delta) < 0.1:
        fp_type = 'Star Node'
    elif tau*tau < 4*delta:
        fp_type = 'Center' if abs(tau)<0.05 else \
                  ('Stable Spiral' if tau<0 else 'Unstable Spiral')
    else:
        fp_type = 'Stable Node' if tau<0 else 'Unstable Node'
    print(f'{name} at ({x0},{y0}):')
    print(f'  J = {J.tolist()}')
    print(f'  τ={tau:.2f}, Δ={delta:.2f}, λ={evals}')
    print(f'  Type: {fp_type}')
    print(f'  Hyperbolic: {"YES ✓" if hyp else "NO ✗ (caution!)"}')
    return fp_type, hyp

# Damped pendulum: θ̈ + 0.3θ̇ + sin(θ) = 0
f = lambda x,y: y
g = lambda x,y: -np.sin(x) - 0.3*y

fps = [(0, 0, 'Hanging down'),
       (np.pi, 0, 'Inverted')]

for x0, y0, name in fps:
    J = np.array([[0, 1],
                  [-np.cos(x0), -0.3]])
    analyze_fp(name, J, x0, y0)

# Phase portrait
fig = go.Figure()
colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88',
          '#bb86fc','#ff5722','#76ff03','#40c4ff']
for k in range(8):
    th = k*np.pi/4
    X, Y = rk4(f, g, 1.5*np.cos(th), 3*np.sin(th), 20, 3000)
    fig.add_trace(go.Scatter(x=X, y=Y, mode='lines',
        line=dict(color=colors[k], width=1.5),
        showlegend=False))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='θ', range=[-4,4],
        zerolinecolor='#808080'),
    yaxis=dict(title='ω', range=[-3,3],
        zerolinecolor='#808080'),
    height=500, width=600)
fig.show()

import numpy as np

def is_hyperbolic(J):
    """Check if all eigenvalues have nonzero real part."""
    evals = np.linalg.eigvals(J)
    return all(abs(e.real) > 1e-6 for e in evals)

def trust_report(name, J):
    evals = np.linalg.eigvals(J)
    tau = np.trace(J)
    delta = np.linalg.det(J)
    hyp = is_hyperbolic(J)
    print(f'\n=== {name} ===')
    print(f'  λ = {evals}')
    print(f'  τ = {tau:.3f}, Δ = {delta:.3f}')
    if hyp:
        print(f'  ✓ HYPERBOLIC — linearization RELIABLE')
        print(f'    Reason: all Re(λ) ≠ 0')
    else:
        print(f'  ✗ NON-HYPERBOLIC — linearization UNRELIABLE')
        for e in evals:
            if abs(e.real) < 1e-6:
                print(f'    Offender: λ = {e} has Re ≈ 0')

# Test cases
trust_report('Stable spiral',
    np.array([[-0.5, 1], [-1, -0.5]]))

trust_report('Center (caution!)',
    np.array([[0, 1], [-1, 0]]))

trust_report('Saddle',
    np.array([[1, 1], [0, -2]]))

trust_report('Zero eigenvalue (caution!)',
    np.array([[0, 1], [0, -1]]))
