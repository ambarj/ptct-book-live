Runge-Kutta 4th Order (RK4)

RK2 used two slope evaluations per step and achieved \( O(h^2) \). What if we sample the slope at four carefully chosen points? That's RK4 — and the payoff is spectacular: the error drops to \( O(h^4) \).

Learning Objectives
  • Understand RK4's four-stage recipe: sample slopes at the start, two midpoints, and the end
  • Implement RK4 and race it against Euler and RK2 on a driven oscillator
  • Verify fourth-order convergence \( O(h^4) \) — halving \( h \) reduces error by 16×
  • See why RK4 is the default choice: far fewer total evaluations for the same accuracy

The RK4 Recipe:

$$ \begin{aligned} k_1 &= f(t_n,\; y_n) & &\text{(slope at start)} \\[4pt] k_2 &= f\!\left(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}\,k_1\right) & &\text{(slope at midpoint, using } k_1\text{)} \\[4pt] k_3 &= f\!\left(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}\,k_2\right) & &\text{(slope at midpoint, using } k_2\text{)} \\[4pt] k_4 &= f\!\left(t_n + h,\; y_n + h\,k_3\right) & &\text{(slope at end)} \\[6pt] y_{n+1} &= y_n + \frac{h}{6}\!\left(k_1 + 2k_2 + 2k_3 + k_4\right) & &\text{(weighted average)} \end{aligned} $$

Four evaluations of \( f \) per step. The weights \( (1, 2, 2, 1)/6 \) come from matching the Taylor expansion to fourth order — but you don't need to derive them. Just trust the recipe and verify it works.

Why These Weights?

The weights \( \frac{1}{6}(1, 2, 2, 1) \) arise from Simpson's rule for numerical integration. Think of it as a weighted average that gives more importance to the midpoint slopes (sampled twice, weighted double) — this is the same idea that makes Simpson's rule so accurate for integrals. The result: RK4 captures terms through \( O(h^4) \) in the Taylor expansion without ever computing a derivative of \( f \).

To test RK4 on a richer problem than the simple harmonic oscillator, we'll use a driven oscillator:

Driven harmonic oscillator:

$$ \ddot{x} + x = \cos(\omega t) \qquad \omega = 0.8 $$

with initial conditions \( x(0) = 1 \), \( \dot{x}(0) = 0 \). The exact solution is \( x(t) = \frac{\cos(\omega t) - \omega^2 \cos(t)}{1 - \omega^2} \).

The Efficiency Argument

RK4 costs 4 evaluations per step. Euler costs only 1. Isn't that a waste? Not at all. To match RK4's accuracy, Euler needs astronomically more total evaluations. Let's see this quantitatively.

  • This is why RK4 is the default for scientific computing: unbeatable efficiency for smooth problems.
Why Not RK5, RK6, ...?

Higher-order methods exist, but they require more than one extra evaluation per order beyond RK4. An order-5 method needs 6 evaluations (not 5), order-6 needs at least 7, and so on. RK4 sits at a sweet spot: 4 evaluations for 4th-order accuracy. Going higher gives diminishing returns unless you need extreme precision. For most physics problems, RK4 is the right tool.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(f, y0, T, h):
    """RK4 method for systems: y' = f(t, y)."""
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0)))
    y[0] = y0
    for i in range(len(t) - 1):
        k1 = np.array(f(t[i], y[i]))
        k2 = np.array(f(t[i] + h/2, y[i] + h/2 * k1))
        k3 = np.array(f(t[i] + h/2, y[i] + h/2 * k2))
        k4 = np.array(f(t[i] + h, y[i] + h * k3))
        y[i+1] = y[i] + (h/6) * (k1 + 2*k2 + 2*k3 + k4)
    return t, y

# Driven oscillator: x'' + x = cos(0.8t)
omega = 0.8
f_driven = lambda t, y: [y[1], -y[0] + np.cos(omega * t)]

h = 0.20
T = 50
t_rk4, y_rk4 = rk4(f_driven, [1, 0], T, h)

# Exact solution
t_exact = np.linspace(0, T, 2000)
x_exact = (np.cos(omega * t_exact) - omega**2 * np.cos(t_exact)) / (1 - omega**2)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Position vs Time', 'Phase Portrait'])

fig.add_trace(go.Scatter(x=t_exact, y=x_exact, name='Exact',
    line=dict(color='#808080', dash='dash')), row=1, col=1)
fig.add_trace(go.Scatter(x=t_rk4, y=y_rk4[:,0], name='RK4',
    line=dict(color='#ff00ff')), row=1, col=1)

v_exact = (-omega * np.sin(omega * t_exact) + omega**2 * np.sin(t_exact)) / (1 - omega**2)
fig.add_trace(go.Scatter(x=x_exact, y=v_exact, name='Exact',
    line=dict(color='#808080', dash='dash'), showlegend=False), row=1, col=2)
fig.add_trace(go.Scatter(x=y_rk4[:,0], y=y_rk4[:,1], name='RK4',
    line=dict(color='#ff00ff'), showlegend=False), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.show()

import numpy as np
import plotly.graph_objects as go

def euler(f, y0, T, h):
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0))); y[0] = y0
    for i in range(len(t) - 1):
        y[i+1] = y[i] + h * np.array(f(t[i], y[i]))
    return t, y

def rk2(f, y0, T, h):
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0))); y[0] = y0
    for i in range(len(t) - 1):
        k1 = np.array(f(t[i], y[i]))
        k2 = np.array(f(t[i] + h/2, y[i] + h/2 * k1))
        y[i+1] = y[i] + h * k2
    return t, y

def rk4(f, y0, T, h):
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0))); y[0] = y0
    for i in range(len(t) - 1):
        k1 = np.array(f(t[i], y[i]))
        k2 = np.array(f(t[i] + h/2, y[i] + h/2 * k1))
        k3 = np.array(f(t[i] + h/2, y[i] + h/2 * k2))
        k4 = np.array(f(t[i] + h, y[i] + h * k3))
        y[i+1] = y[i] + (h/6) * (k1 + 2*k2 + 2*k3 + k4)
    return t, y

# Convergence test: SHO x'' = -x, exact x(T) = cos(T)
f_sho = lambda t, y: [y[1], -y[0]]
T = 5.0

h_values = np.logspace(-3, 0, 25)
euler_err, rk2_err, rk4_err = [], [], []

for h in h_values:
    exact = np.cos(T)
    _, ye = euler(f_sho, [1, 0], T, h)
    _, yr = rk2(f_sho, [1, 0], T, h)
    _, y4 = rk4(f_sho, [1, 0], T, h)
    euler_err.append(abs(ye[-1, 0] - exact))
    rk2_err.append(abs(yr[-1, 0] - exact))
    rk4_err.append(abs(y4[-1, 0] - exact))

fig = go.Figure()
fig.add_trace(go.Scatter(x=h_values, y=euler_err, name='Euler O(h)',
    mode='markers+lines', line=dict(color='#00f3ff')))
fig.add_trace(go.Scatter(x=h_values, y=rk2_err, name='RK2 O(h²)',
    mode='markers+lines', line=dict(color='#00ff9f')))
fig.add_trace(go.Scatter(x=h_values, y=rk4_err, name='RK4 O(h⁴)',
    mode='markers+lines', line=dict(color='#ff00ff')))

# Reference slopes
fig.add_trace(go.Scatter(x=[1e-3, 1], y=[1e-3, 1],
    name='slope 1', line=dict(color='#808080', dash='dot')))
fig.add_trace(go.Scatter(x=[1e-3, 1], y=[1e-6, 1],
    name='slope 2', line=dict(color='#808080', dash='dot')))
fig.add_trace(go.Scatter(x=[1e-3, 1], y=[1e-12, 1],
    name='slope 4', line=dict(color='#808080', dash='dot')))

fig.update_layout(template='plotly_dark',
    xaxis=dict(type='log', title='Step size h',
               gridcolor='#2a2f4a', linecolor='#808080'),
    yaxis=dict(type='log', title='|Error at t=T|',
               gridcolor='#2a2f4a', linecolor='#808080'),
    title='Convergence: Euler vs RK2 vs RK4')
fig.show()
