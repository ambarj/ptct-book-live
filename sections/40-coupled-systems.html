Solving Coupled Systems

In Section 4.6 you learned to convert a single second-order ODE into a pair of coupled first-order equations. But many physical systems are inherently coupled — predators depend on prey, voltage depends on current, Romeo's feelings depend on Juliet's. The vector Euler method you already know handles all of these: just update every variable at each time step.

Learning Objectives
  • Apply vector Euler's method to solve general coupled ODE systems
  • Visualize solutions simultaneously in time domain and phase space
  • Use vector fields and multi-trajectory portraits to understand system behavior

The real payoff is phase space. Instead of plotting \( x(t) \) and \( y(t) \) separately against time, we plot \( (x, y) \) as a single trajectory. This reveals structure — closed orbits, spirals, limit cycles — that time-domain plots hide.

Key Insight: Phase Portraits Reveal Structure

Time-domain plots show when things happen. Phase portraits show what kind of behavior the system exhibits: closed orbits (energy conservation), spirals (damping or growth), limit cycles (self-sustained oscillation). The same Euler solver produces both views — it's just a matter of which axes you plot.

Explanation:
  • Arrows circulate: True — the SHO has a center at the origin with rotational flow.
  • Arrows point away: False — they circulate, not radiate outward.
  • Trajectory follows arrows: True — Euler steps along the local velocity vector.

Switch to the Van der Pol system. What happens when you start a trajectory near the origin (set \( x_0 = 0.1, y_0 = 0 \))?
Explanation: The Van der Pol oscillator has an unstable fixed point at the origin (trajectories spiral out) but a stable limit cycle that attracts all nearby trajectories. Small perturbations grow until the orbit reaches the limit cycle, then stays there. This is fundamentally different from both damped (spiral in) and undamped (closed orbit) oscillators.
Why Vector Fields Matter

A vector field shows you the system's behavior everywhere at once, without solving anything. You can read off fixed points (where arrows vanish), flow directions, and qualitative behavior just by looking. Euler's method is simply "follow the arrows, one step at a time."

Which statements about phase portraits are correct? (Select all that apply)
Explanation:
  • Crossing: False — for autonomous systems (\( \dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}) \)), trajectories cannot cross because the velocity is uniquely determined at each point.
  • Spiral to point: True — energy is lost each cycle, so the orbit shrinks (e.g., damped oscillator).
  • Closed orbits: True — if a trajectory returns to its starting point, there must be a conserved quantity preventing it from spiraling in or out.
  • All circles: False — phase portraits can be ellipses, spirals, limit cycles, hyperbolic curves, and more.

Python Implementation

Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler_system(f, y0, t_max, h):
    """Vector Euler solver for coupled ODEs."""
    t = [0.0]
    Y = [np.array(y0, dtype=float)]
    y = np.array(y0, dtype=float)
    n_steps = int(t_max / h)
    for i in range(n_steps):
        y = y + h * np.array(f(y, t[-1]))
        t.append(t[-1] + h)
        Y.append(y.copy())
    return np.array(t), np.array(Y)

# Predator-Prey (Lotka-Volterra)
def predator_prey(y, t):
    x, p = y
    return [x * (1.5 - p), p * (x - 1.0)]

t, Y = euler_system(predator_prey, [1.0, 1.0], 15, 0.01)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Time Domain', 'Phase Portrait'])

fig.add_trace(go.Scatter(x=t, y=Y[:,0], name='Prey',
    line=dict(color='#00f3ff', width=2)), row=1, col=1)
fig.add_trace(go.Scatter(x=t, y=Y[:,1], name='Predator',
    line=dict(color='#ff6b6b', width=2)), row=1, col=1)
fig.add_trace(go.Scatter(x=Y[:,0], y=Y[:,1], name='Trajectory',
    line=dict(color='#00ff9f', width=2)), row=1, col=2)

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='t', linecolor='#808080'),
    yaxis=dict(title='Population', linecolor='#808080'),
    xaxis2=dict(title='Prey (x)', linecolor='#808080'),
    yaxis2=dict(title='Predator (y)', linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def euler_system(f, y0, t_max, h):
    t = [0.0]
    Y = [np.array(y0, dtype=float)]
    y = np.array(y0, dtype=float)
    for _ in range(int(t_max / h)):
        y = y + h * np.array(f(y, t[-1]))
        t.append(t[-1] + h)
        Y.append(y.copy())
    return np.array(t), np.array(Y)

# Damped oscillator: x' = v, v' = -x - 0.3v
def damped(y, t):
    return [y[1], -y[0] - 0.3 * y[1]]

fig = go.Figure()

# Vector field
xg = np.linspace(-3, 3, 15)
yg = np.linspace(-3, 3, 15)
for xi in xg:
    for yi in yg:
        dx, dy = damped([xi, yi], 0)
        mag = np.sqrt(dx**2 + dy**2)
        if mag > 0.01:
            s = 0.2 / mag  # normalize arrow length
            fig.add_annotation(x=xi+s*dx, y=yi+s*dy,
                ax=xi, ay=yi, xref='x', yref='y',
                axref='x', ayref='y', showarrow=True,
                arrowhead=2, arrowsize=1, arrowwidth=1.5,
                arrowcolor='rgba(128,128,128,0.5)')

# Multiple trajectories from a ring
for angle in np.linspace(0, 2*np.pi, 8, endpoint=False):
    x0 = 2 * np.cos(angle)
    y0 = 2 * np.sin(angle)
    t, Y = euler_system(damped, [x0, y0], 20, 0.02)
    fig.add_trace(go.Scatter(x=Y[:,0], y=Y[:,1],
        mode='lines', line=dict(width=1.5),
        showlegend=False))

fig.update_layout(template='plotly_dark',
    xaxis=dict(range=[-3,3], title='x',
        zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(range=[-3,3], title='v',
        zerolinecolor='#808080', linecolor='#808080',
        scaleanchor='x'))
fig.show()
