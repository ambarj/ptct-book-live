The Superposition Principle

Drop two stones into a pond. The ripples from each stone spread outward independently — and where they overlap, the water simply adds the two displacements together. This is the superposition principle: for linear systems, the sum of any two solutions is itself a solution. It's one of the most powerful ideas in physics, underlying everything from sound and light to quantum mechanics.

Learning Objectives
  • State the superposition principle and explain when it applies
  • Add two sinusoidal waves and predict the resulting amplitude
  • Distinguish linear from nonlinear systems using the superposition test
  • Build complex waveforms from simple sinusoidal components

The superposition principle:

$$ \text{If } x_1(t) \text{ and } x_2(t) \text{ are solutions, then } x(t) = A\,x_1(t) + B\,x_2(t) \text{ is also a solution.} $$

This works for any linear system — the simple harmonic oscillator \( \ddot{x} + \omega^2 x = 0 \), the wave equation, Maxwell's equations (in vacuum), and Schrödinger's equation. It fails for nonlinear systems like \( \ddot{x} + x^3 = 0 \).

Adding Two Waves

Start with the simplest case: two cosine waves at the same frequency \( \omega \). Adjust the amplitudes and phases to see how the sum changes. The key discovery: the sum of two cosines at frequency \( \omega \) is always another cosine at frequency \( \omega \) — only the amplitude and phase change.

Interactive: Wave Adder
Key Insight

When \( \Delta\phi = 0 \) (waves in phase), the amplitudes add: \( A = A_1 + A_2 \). When \( \Delta\phi = 180° \) (waves out of phase), they subtract: \( A = |A_1 - A_2| \). In general, \( A^2 = A_1^2 + A_2^2 + 2A_1A_2\cos(\Delta\phi) \). Set A&sub1; = A&sub2; = 1 and sweep φ&sub2; from 0° to 180° to watch the sum smoothly go from constructive to destructive interference.

When Does Superposition Work?

Superposition works because the governing equation is linear. Here's the test: take two signals, apply the system to their sum, and compare with applying the system to each separately then adding. If \( f(x_1 + x_2) = f(x_1) + f(x_2) \), the system is linear and superposition holds. Try switching to a nonlinear system to see what breaks.

Interactive: Linearity Tester
Key Insight

For \( f(x) = x \) and \( f(x) = 2x \), the yellow and green curves overlap perfectly: superposition holds. But for \( f(x) = x^2 \), they diverge dramatically because \( (x_1+x_2)^2 \neq x_1^2 + x_2^2 \) — the cross term \( 2x_1 x_2 \) breaks superposition. This is why nonlinear systems are so much harder to analyse: you can't solve the parts separately and add them up.

Explanation
Superposition holds only for linear systems. Both \( f(x) = x \) and \( f(x) = 2x \) are linear (they satisfy \( f(\alpha x) = \alpha f(x) \) and \( f(x_1+x_2) = f(x_1)+f(x_2) \)). The nonlinear systems \( x^2 \) and \( x^3 \) fail the test.
Switch to f(x) = x². Why does superposition fail?
Explanation
\( (x_1 + x_2)^2 = x_1^2 + 2x_1 x_2 + x_2^2 \), but \( x_1^2 + x_2^2 \) is missing the \( 2x_1 x_2 \) cross term. This "mixing" of the two signals is the hallmark of nonlinearity. It's why nonlinear systems generate new frequencies (harmonics, sum/difference frequencies) not present in the inputs.
Which of these physical systems obey superposition? (Select all that apply)
Explanation
  • True: Sound waves at normal loudness are well described by the linear wave equation. Two conversations don't "mix" into new frequencies.
  • True: Maxwell's equations in vacuum are linear, so light beams pass through each other without interaction.
  • False: Breaking waves are highly nonlinear — the large amplitudes and turbulence violate the small-amplitude assumption needed for linearity.
  • True: Ohm's law \( V = IR \) is linear, so voltages from different sources add directly (this is the basis of circuit superposition theorems).

Building Complex Waves from Simple Ones

Since superposition lets us add solutions, we can work backwards: decompose any periodic signal into a sum of sinusoids. This is the idea behind Fourier analysis. Use the sliders to adjust the amplitudes of the first four harmonics (\( \omega, 2\omega, 3\omega, 4\omega \)) and try to match the target waveform. Can you build a square wave from sines?

Interactive: Pattern Builder
Key Insight

A square wave's Fourier series is \( \frac{4}{\pi}\left[\sin(\omega t) + \frac{\sin(3\omega t)}{3} + \frac{\sin(5\omega t)}{5} + \cdots\right] \). Only odd harmonics appear! With just 4 harmonics, you can already get a recognisable approximation. This is the power of superposition: infinitely complex signals are built from infinitely simple components.

Python Code

Here's the Python equivalent for superposition and Fourier synthesis.

Python 
import numpy as np
import plotly.graph_objects as go

t = np.linspace(0, 8*np.pi, 1000)

# Two waves with same frequency, different amplitude and phase
A1, A2 = 1.0, 1.0
omega = 1.0
phi1, phi2 = 0, np.pi/2  # 90° phase difference

x1 = A1 * np.cos(omega*t + phi1)
x2 = A2 * np.cos(omega*t + phi2)
x_sum = x1 + x2

# Resultant amplitude from formula
A_res = np.sqrt(A1**2 + A2**2 + 2*A1*A2*np.cos(phi2-phi1))
print(f"A_result = {A_res:.4f}  (expected sqrt(2) = {np.sqrt(2):.4f})")

fig = go.Figure()
fig.add_trace(go.Scatter(x=t, y=x1, name='x₁', line=dict(color='#00f3ff', dash='dot')))
fig.add_trace(go.Scatter(x=t, y=x2, name='x₂', line=dict(color='#ff00ff', dash='dot')))
fig.add_trace(go.Scatter(x=t, y=x_sum, name='Sum', line=dict(color='#ffff00', width=2.5)))
fig.update_layout(template='plotly_dark',
    xaxis=dict(title='t', gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-2.5, 2.5], gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

t = np.linspace(0, 4*np.pi, 1000)

# Build a square wave from Fourier series
n_harmonics = 20
x_fourier = np.zeros_like(t)
for n in range(1, n_harmonics+1, 2):  # odd harmonics only
    x_fourier += (4/np.pi) * np.sin(n*t) / n

# True square wave for comparison
x_square = np.sign(np.sin(t))

fig = go.Figure()
fig.add_trace(go.Scatter(x=t, y=x_square, name='True square wave',
    line=dict(color='#808080', dash='dash', width=2)))
fig.add_trace(go.Scatter(x=t, y=x_fourier, name=f'{n_harmonics//2+1} harmonics',
    line=dict(color='#ffff00', width=2.5)))

# Also show partial sums
for k in [1, 3, 5]:
    partial = np.zeros_like(t)
    for n in range(1, k+1, 2):
        partial += (4/np.pi) * np.sin(n*t) / n
    fig.add_trace(go.Scatter(x=t, y=partial, name=f'{k//2+1} term(s)',
        line=dict(width=1, dash='dot'), opacity=0.5))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='t', gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-1.5, 1.5], gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'))
fig.show()
