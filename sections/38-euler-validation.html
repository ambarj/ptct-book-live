Testing and Validation

You’ve built a working Euler solver. How do you know it’s giving the right answer? For equations with known solutions, you can compare directly. For equations without closed forms, you need convergence testing — if the answer changes less and less as you shrink \(h\), it’s probably converging to the truth. This section teaches you the physicist’s verification toolkit: plot against known solutions, measure how errors grow, and confirm the expected convergence rate.

Learning Objectives
  • Validate a numerical solution against a known exact answer
  • Understand how Euler error grows over time and scales with step size
  • Confirm the first-order convergence: halving \(h\) roughly halves the global error

Explanation: Growth ODEs amplify errors because the derivative increases with \(x\) — a small overshoot leads to a bigger slope, which leads to a bigger overshoot. Decay ODEs damp errors because the derivative decreases as \(x\) shrinks. This is why growth equations are harder to solve numerically.
For the forced equation (\(dx/dt = \cos(t)\), exact: \(\sin(t)\)), what shape does the error curve have?
Explanation: The forcing function \(\cos(t)\) oscillates, so the local truncation error oscillates too. Because \(dx/dt = \cos t\) doesn’t depend on \(x\), the errors do not compound — they add up to \(\tfrac{h}{2}(1-\cos t)\), a bounded hump that peaks near \(t \approx \pi\) and returns toward zero near \(t \approx 2\pi\). The error is largest where the curvature (second derivative) of the solution is highest.

Key Insight: The Halving Test

Look at the final error values above. When you halve \(h\) (from 0.10 to 0.05), the final error also roughly halves. (Don’t use the 0.50 → 0.25 pair for this test: \(h = 0.5\) makes \(1 - 2h = 0\) for the decay equation — a fluke that breaks the pattern.) This is the signature of a first-order method: error \(\sim O(h)\). Euler’s method is first-order accurate.

$$ \text{Global error} \approx C \cdot h $$

where \(C\) depends on the ODE, the time interval, and the exact solution’s curvature.

Reading the Log-Log Plot:

$$ \log(\text{error}) = \log(C) + p \cdot \log(h) $$

On a log-log plot, this is a straight line with slope = \(p\) (the convergence order). For Euler, \(p = 1\). The right panel shows the measured slope — it should hover near 1.0.

Python: Validation Toolkit

Python 

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler_solve(f, x0, t_max, h):
    t_list, x_list = [0.0], [x0]
    t, x = 0.0, x0
    for i in range(int(t_max / h)):
        x = x + h * f(x, t)
        t = t + h
        t_list.append(t)
        x_list.append(x)
    return np.array(t_list), np.array(x_list)

# Solve with two step sizes
f = lambda x, t: -2 * x
exact = lambda t: np.exp(-2 * t)

t1, x1 = euler_solve(f, 1.0, 3.0, h=0.5)
t2, x2 = euler_solve(f, 1.0, 3.0, h=0.1)
t_ex = np.linspace(0, 3, 300)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Solution', 'Absolute Error'])

# Left: solutions
fig.add_trace(go.Scatter(x=t_ex, y=exact(t_ex), name='Exact',
    line=dict(color='#808080', dash='dash')), row=1, col=1)
fig.add_trace(go.Scatter(x=t1, y=x1, name='h=0.5',
    line=dict(color='#ff6b6b'), mode='lines+markers'), row=1, col=1)
fig.add_trace(go.Scatter(x=t2, y=x2, name='h=0.1',
    line=dict(color='#00f3ff'), mode='lines+markers',
    marker=dict(size=3)), row=1, col=1)

# Right: errors
fig.add_trace(go.Scatter(x=t1, y=np.abs(x1 - exact(t1)),
    name='|err| h=0.5', line=dict(color='#ff6b6b'),
    fill='tozeroy', fillcolor='rgba(255,107,107,0.15)'), row=1, col=2)
fig.add_trace(go.Scatter(x=t2, y=np.abs(x2 - exact(t2)),
    name='|err| h=0.1', line=dict(color='#00f3ff'),
    fill='tozeroy', fillcolor='rgba(0,243,255,0.15)'), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.show()

# Print error ratio
e1 = abs(x1[-1] - exact(t1[-1]))
e2 = abs(x2[-1] - exact(t2[-1]))
print(f"Error (h=0.5): {e1:.6f}")
print(f"Error (h=0.1): {e2:.6f}")
print(f"Ratio: {e1/e2:.1f}x (expect ~5x for 5x smaller h)")
Python 

import numpy as np
import plotly.graph_objects as go

def euler_solve(f, x0, t_max, h):
    t_list, x_list = [0.0], [x0]
    t, x = 0.0, x0
    for i in range(int(t_max / h)):
        x = x + h * f(x, t)
        t = t + h
        t_list.append(t)
        x_list.append(x)
    return np.array(t_list), np.array(x_list)

# Convergence study: error vs h on log-log scale
f = lambda x, t: -2 * x
exact_final = np.exp(-2 * 3.0)  # x(3) = e^-6

h_values = [0.5, 0.25, 0.1, 0.05, 0.025, 0.01]
errors = []

for h in h_values:
    t, x = euler_solve(f, 1.0, 3.0, h)
    errors.append(abs(x[-1] - exact_final))

fig = go.Figure()
fig.add_trace(go.Scatter(x=h_values, y=errors, name='Euler error',
    mode='lines+markers', line=dict(color='#00f3ff', width=2),
    marker=dict(size=8)))

# Reference: O(h) line
fig.add_trace(go.Scatter(x=h_values, y=[e*h_values[0]/h_values[0] for e in [errors[0]]*len(h_values)],
    name='O(h) reference', line=dict(color='#808080', dash='dot')))
# Better: use actual O(h) slope
h_ref = np.array(h_values)
fig.add_trace(go.Scatter(x=h_ref, y=errors[0] * h_ref / h_ref[0],
    name='slope = 1', line=dict(color='#ffff00', dash='dash', width=1.5)))

fig.update_layout(
    template='plotly_dark',
    title='Convergence: Error vs Step Size (log-log)',
    xaxis=dict(title='h (step size)', type='log',
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='|Error at t=3|', type='log',
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
)
fig.show()

# Compute slopes
for i in range(1, len(h_values)):
    slope = np.log(errors[i]/errors[i-1]) / np.log(h_values[i]/h_values[i-1])
    print(f"h={h_values[i]:.3f}: slope = {slope:.2f}")
