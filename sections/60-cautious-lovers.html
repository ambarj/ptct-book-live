Cautious Lovers Model (Optional)

In Section 5.6 you explored general love-affair dynamics with four personality parameters. Here we study a beautifully symmetric special case: both partners have identical personalities. The matrix becomes symmetric, the eigenvalues simplify to \( \lambda = a \pm b \), and the entire relationship fate reduces to a single question: does cautiousness beat responsiveness?

Learning Objectives
  • Model symmetric relationships with \( A = \begin{pmatrix} a & b \\ b & a \end{pmatrix} \) where \( a \) is cautiousness and \( b \) is responsiveness
  • Derive that eigenvalues are simply \( \lambda_1 = a + b \) and \( \lambda_2 = a - b \), with eigenvectors along the diagonals
  • Map the \( (a, b) \) parameter space into regions of different relationship fates
  • Understand why symmetric matrices always have perpendicular eigenvectors and what this means physically

The Symmetric Love Model:

$$ \dot{R} = aR + bJ, \qquad \dot{J} = bR + aJ $$

Both partners have cautiousness \( a \) (self-response) and responsiveness \( b \) (response to partner). The matrix is symmetric: \( A = \begin{pmatrix} a & b \\ b & a \end{pmatrix} \).

Eigenvalues: \( \lambda_1 = a + b \) (eigenvector \( (1, 1) \) — mutual feelings) and \( \lambda_2 = a - b \) (eigenvector \( (1, -1) \) — opposite feelings).

Explorer: Cautiousness vs Responsiveness

Adjust the two personality parameters. Cautiousness \( a < 0 \) means strong feelings fade on their own; responsiveness \( b > 0 \) means each partner’s feelings amplify the other’s. The battle between these two forces determines everything.

Perpendicular Eigenvectors

Because \( A \) is symmetric, its eigenvectors are always perpendicular. The mutual-feelings direction \( (1, 1) \) and the opposite-feelings direction \( (1, -1) \) are at right angles. This means the two modes are completely independent: changing one doesn’t affect the other. Symmetric matrices always decompose motion into independent perpendicular modes — this is why physicists love them (normal modes of vibration work the same way).

Explanation: Both \( \lambda_1 = a + b = -1 \) and \( \lambda_2 = a - b = -3 \) are negative. This is a stable node. All trajectories converge to the origin: both Romeo and Juliet become indifferent. Cautiousness (\( |a| = 2 \)) overwhelms responsiveness (\( b = 1 \)), so the flame dies out.
Now set \( a = -1, b = 2 \), so \( \lambda_1 = 1, \lambda_2 = -3 \). Since the eigenvalues have opposite signs, the fixed point is a .
Explanation: \( \lambda_1 = 1 > 0 \) and \( \lambda_2 = -3 < 0 \) — opposite signs mean saddle. Responsiveness (\( b = 2 \)) exceeds cautiousness (\( |a| = 1 \)), so mutual feelings grow while opposite feelings decay. The couple either falls deeply in love or sinks into mutual hate, depending on initial conditions.
The transition from stable node to saddle occurs exactly when…
Explanation: The transition happens when \( \lambda_1 = a + b = 0 \), i.e., \( b = -a = |a| \) (since \( a < 0 \) for cautiousness). At this boundary, \( \lambda_2 = 2a < 0 \) is still negative, so we go from two negative eigenvalues (stable node) to one positive + one negative (saddle). Responsiveness matching cautiousness is the tipping point.

Which statements about the symmetric love model are true? (Select all)
Explanation:
  • Spirals possible: ✗ Symmetric matrices have real eigenvalues (spectral theorem). Complex eigenvalues (needed for spirals) are impossible.
  • Fixed eigenvectors: ✓ For \( A = \begin{pmatrix} a & b \\ b & a \end{pmatrix} \), the eigenvectors are always \( (1, 1) \) and \( (1, -1) \), regardless of \( a \) and \( b \).
  • Oscillations: ✗ No complex eigenvalues → no oscillations. Only exponential growth or decay.
  • Real eigenvalues always: ✓ This is the spectral theorem: symmetric real matrices always have real eigenvalues and orthogonal eigenvectors.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(A, x0, T, N):
    h = T/N; x = np.array(x0, float)
    xs, ts = [x.copy()], [0.0]
    for i in range(N):
        f = lambda u: A @ u
        k1=f(x); k2=f(x+h/2*k1); k3=f(x+h/2*k2); k4=f(x+h*k3)
        x += h/6*(k1+2*k2+2*k3+k4)
        if np.linalg.norm(x) > 20: break
        xs.append(x.copy()); ts.append((i+1)*h)
    return np.array(xs), np.array(ts)

# Cautious lovers: a = -1.5, b = 0.8
a, b = -1.5, 0.8
A = np.array([[a, b], [b, a]])
lam1, lam2 = a + b, a - b
print(f'λ₁ = {lam1:.2f}, λ₂ = {lam2:.2f}')

fig = make_subplots(1, 2, subplot_titles=[
    'Phase Portrait', 'Time Series'])

colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88',
          '#bb86fc','#ff5722','#76ff03','#40c4ff']

for k in range(8):
    th = k * np.pi / 4
    traj, t = rk4(A, [2*np.cos(th), 2*np.sin(th)], 8, 1500)
    fig.add_trace(go.Scatter(
        x=traj[:,0], y=traj[:,1], mode='lines',
        line=dict(color=colors[k], width=1.5),
        showlegend=False), row=1, col=1)

# Eigenvector lines
for v, lam, col in [([1,1], lam1, '#ff5722'),
                     ([1,-1], lam2, '#00ff88')]:
    fig.add_trace(go.Scatter(
        x=[-3*v[0], 3*v[0]], y=[-3*v[1], 3*v[1]],
        mode='lines', line=dict(color=col, dash='dash'),
        name=f'λ={lam:.1f}'), row=1, col=1)

# One time series
traj, t = rk4(A, [2, 0.5], 8, 1500)
fig.add_trace(go.Scatter(x=t, y=traj[:,0], mode='lines',
    line=dict(color='#00f3ff', width=2), name='Romeo'),
    row=1, col=2)
fig.add_trace(go.Scatter(x=t, y=traj[:,1], mode='lines',
    line=dict(color='#ff006e', width=2), name='Juliet'),
    row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(title='Romeo R', range=[-3,3],
    zerolinecolor='#808080', row=1, col=1)
fig.update_yaxes(title='Juliet J', range=[-3,3],
    zerolinecolor='#808080', scaleanchor='x', row=1, col=1)
fig.update_xaxes(title='Time', zerolinecolor='#808080',
    row=1, col=2)
fig.update_yaxes(title='Feelings', zerolinecolor='#808080',
    row=1, col=2)
fig.show()

import numpy as np
import plotly.graph_objects as go

# Parameter space map for symmetric model
na, nb = 100, 100
a_vals = np.linspace(-3, 2, na)
b_vals = np.linspace(-2, 3, nb)
z = np.zeros((nb, na))

for j, bv in enumerate(b_vals):
    for i, av in enumerate(a_vals):
        l1, l2 = av + bv, av - bv
        if l1 < 0 and l2 < 0:
            z[j, i] = 0  # stable node
        elif l1 > 0 and l2 > 0:
            z[j, i] = 2  # unstable node
        else:
            z[j, i] = 1  # saddle

fig = go.Figure()
fig.add_trace(go.Heatmap(
    z=z, x=a_vals, y=b_vals, opacity=0.5,
    colorscale=[[0, '#00f3ff'], [0.5, '#ff5722'], [1, '#ff006e']],
    showscale=False))

# Boundary lines: b = -a and b = a
fig.add_trace(go.Scatter(
    x=[-3, 2], y=[3, -2], mode='lines',
    line=dict(color='white', width=2, dash='dash'),
    name='b = −a (λ₁ = 0)'))
fig.add_trace(go.Scatter(
    x=[-3, 2], y=[-3, 2], mode='lines',
    line=dict(color='#ffbe0b', width=2, dash='dash'),
    name='b = a (λ₂ = 0)'))

fig.add_annotation(x=-2, y=0, text='Stable Node',
    font=dict(color='#00f3ff', size=13), showarrow=False)
fig.add_annotation(x=0, y=2, text='Saddle',
    font=dict(color='#ff5722', size=13), showarrow=False)
fig.add_annotation(x=1.5, y=1, text='Unstable\nNode',
    font=dict(color='#ff006e', size=12), showarrow=False)

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Cautiousness a', range=[-3, 2],
               zerolinecolor='#808080'),
    yaxis=dict(title='Responsiveness b', range=[-2, 3],
               zerolinecolor='#808080'),
    height=500, width=550)
fig.show()
