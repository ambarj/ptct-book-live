The Three Regimes of Damping

In the previous section we saw that damping makes oscillations fade. But there's more to the story. Increase the damping strength \( \gamma \) past a critical threshold, and something dramatic happens: oscillation ceases entirely. The system simply oozes back to equilibrium without ever crossing zero.

The mathematics reveals three qualitatively different regimes, each with distinct physical behavior. The boundary between them depends on a single number: the discriminant \( \Delta = \gamma^2 - \omega_0^2 \).

Learning Objectives
  • Classify damped motion as underdamped, critically damped, or overdamped from the characteristic equation
  • Connect the discriminant \( \gamma^2 - \omega_0^2 \) to the nature of the roots (complex, repeated, real)
  • Explain why critical damping gives the fastest return to equilibrium without overshoot
  • Read a parameter space map and predict behavior from (\( \gamma, \omega_0 \))

The key formula (from solving the damped oscillator equation):

$$ r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2} $$

Everything depends on what’s under the square root. Three cases:
γ < ω0 (light damping): the square root of a negative number gives oscillation → underdamped
γ = ω0 (boundary): the square root is zero → critically damped (fastest return without oscillating)
γ > ω0 (heavy damping): the square root is a real number → overdamped (sluggish, no oscillation)

Key Insight

The position of the roots tells you the whole story. If the roots are off the horizontal axis (complex), the solution oscillates — the height above the axis is the oscillation frequency ωd. If the roots sit on the horizontal axis (real), there’s no oscillation — just smooth exponential decay. In both cases, how far left the roots sit determines how fast the motion dies out.

Code It Yourself

Python 
import numpy as np
import plotly.graph_objects as go

def damped(t, A, gamma, omega0):
    disc = gamma**2 - omega0**2
    if disc < 0:  # underdamped
        wd = np.sqrt(-disc)
        return A * np.exp(-gamma*t) * (np.cos(wd*t) + gamma/wd * np.sin(wd*t))
    elif disc > 0:  # overdamped
        s = np.sqrt(disc)
        r1, r2 = -gamma + s, -gamma - s
        return A/(r2-r1) * (r2*np.exp(r1*t) - r1*np.exp(r2*t))
    else:  # critical
        return A * (1 + gamma*t) * np.exp(-gamma*t)

omega0 = 3.0
t = np.linspace(0, 12, 600)

fig = go.Figure()
for gamma, name, color in [
    (0.9, 'Underdamped', '#00f3ff'),
    (3.0, 'Critical', '#00ff9f'),
    (6.0, 'Overdamped', '#ff00ff')]:
    fig.add_trace(go.Scatter(x=t, y=damped(t, 2, gamma, omega0),
        name=f'{name} (γ={gamma})', line=dict(color=color, width=2)))

fig.update_layout(template='plotly_dark',
    title='Three Damping Regimes',
    xaxis=dict(title='Time (s)', range=[0, 12],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-1.5, 2.5],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

omega0 = 3.0
n = 50
gammas = np.linspace(0.1, 6, n)
omega0s = np.linspace(0.5, 5, n)

# Compute settling time for each (γ, ω₀)
settle = np.zeros((n, n))
for j, w in enumerate(omega0s):
    for i, g in enumerate(gammas):
        t = np.linspace(0, 20, 1000)
        disc = g**2 - w**2
        if disc < 0:
            wd = np.sqrt(-disc)
            x = 2*np.exp(-g*t)*(np.cos(wd*t) + g/wd*np.sin(wd*t))
        elif disc > 0:
            s = np.sqrt(disc)
            r1, r2 = -g+s, -g-s
            x = 2/(r2-r1)*(r2*np.exp(r1*t) - r1*np.exp(r2*t))
        else:
            x = 2*(1+g*t)*np.exp(-g*t)
        idx = np.where(np.abs(x) < 0.1)[0]
        settle[j,i] = t[idx[0]] if len(idx) > 0 else 20

fig = go.Figure(go.Heatmap(x=gammas, y=omega0s, z=settle,
    colorscale=[[0,'#00ff9f'],[0.3,'#00f3ff'],[0.6,'#ff00ff'],[1,'#ff6b6b']]))
fig.add_trace(go.Scatter(x=[0.5,5], y=[0.5,5], mode='lines',
    line=dict(color='yellow', dash='dash', width=2), name='γ=ω₀'))
fig.update_layout(template='plotly_dark', title='Parameter Space Map',
    xaxis=dict(title='γ'), yaxis=dict(title='ω₀'))
fig.show()
