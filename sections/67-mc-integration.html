Monte Carlo Integration Basics

In Section 6.1 you estimated π by throwing darts. That was the hit-or-miss method: random points, count the fraction inside. There’s a better way. The sample mean method directly averages the function values at random points — it’s simpler, more general, and converges faster. This section teaches you both methods and shows why sample mean wins.

Learning Objectives
  • Implement the hit-or-miss method: throw points in a bounding box, count hits under the curve
  • Implement the sample mean method: \( I \approx (b-a) \cdot \frac{1}{N}\sum f(x_i) \)
  • Understand why sample mean is more efficient (lower variance) than hit-or-miss
  • Apply MC integration to functions with known analytical answers and verify convergence

Two Monte Carlo Integration Methods:

Hit-or-miss:

$$ I \approx A_{\text{box}} \times \frac{N_{\text{under curve}}}{N_{\text{total}}} $$

Sample mean (preferred):

$$ I = \int_a^b f(x)\,dx \approx (b - a)\,\frac{1}{N}\sum_{i=1}^{N} f(x_i), \qquad x_i \sim \text{Uniform}(a, b) $$

Why Sample Mean Beats Hit-or-Miss

Hit-or-miss wastes information: each point only contributes a 0 or 1 (miss or hit). Sample mean uses the actual function value at each point, extracting more information per sample. The result: sample mean has lower variance and converges faster for the same number of random points. In practice, always use sample mean.

Select 1/(1+x) and sample 2,000 points. The sample mean estimate of \( \int_0^1 \frac{1}{1+x}\,dx \) is approximately . (The true value is ln(2) ≈ 0.6931)
Explanation: With 2,000 samples, the estimate should be within about 0.01–0.02 of the true value 0.6931. The exact number varies each run (randomness!), but it should be in the range 0.67–0.72 almost always.
The sample mean formula is \( I \approx (b-a) \cdot \frac{1}{N}\sum f(x_i) \). What role does the factor \( (b - a) \) play?
Explanation: The average of \( f(x_i) \) estimates the mean height of the function. To get the area (integral), you multiply by the width \( (b - a) \). Think of it as: area = average height × width. For [0, 1] the factor is 1, but for [0, π] it’s π.

import numpy as np
import plotly.graph_objects as go

def mc_integrate(f, a, b, N):
    """Monte Carlo integration using sample mean method."""
    x = np.random.uniform(a, b, N)
    f_vals = f(x)
    estimate = (b - a) * np.mean(f_vals)
    error = (b - a) * np.std(f_vals) / np.sqrt(N)
    return estimate, error

# Test: ∫₀¹ 1/(1+x) dx = ln(2)
f = lambda x: 1 / (1 + x)
true_val = np.log(2)

# Convergence study
Ns = [100, 500, 1000, 2000, 5000, 10000]
estimates, errors = [], []
for N in Ns:
    est, err = mc_integrate(f, 0, 1, N)
    estimates.append(est)
    errors.append(err)
    print(f'N={N:6d}: I = {est:.5f} ± {err:.5f}  '
          f'(true = {true_val:.5f})')

fig = go.Figure()
fig.add_trace(go.Scatter(
    x=Ns, y=estimates, mode='markers+lines',
    error_y=dict(type='data', array=errors, visible=True,
                 color='rgba(0,243,255,0.5)'),
    line=dict(color='#00f3ff', width=2),
    marker=dict(color='#00f3ff', size=8),
    name='MC estimate ± 1σ'))
fig.add_trace(go.Scatter(
    x=[Ns[0], Ns[-1]], y=[true_val, true_val],
    mode='lines',
    line=dict(color='white', width=2, dash='dash'),
    name=f'True = {true_val:.4f}'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='N (samples)', type='log',
               zerolinecolor='#808080'),
    yaxis=dict(title='Estimate', range=[0.6, 0.8],
               zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

def mc_hit_miss(f, a, b, f_max, N):
    """Monte Carlo integration using hit-or-miss method."""
    x = np.random.uniform(a, b, N)
    y = np.random.uniform(0, f_max, N)
    hits = np.sum(y <= f(x))
    box_area = (b - a) * f_max
    estimate = box_area * hits / N
    return estimate, x, y, y <= f(x)

# Compare both methods on sin(x) over [0, π]
f = lambda x: np.sin(x)
a, b, f_max = 0, np.pi, 1.0
true_val = 2.0
N = 5000

# Hit-or-miss
hm_est, x_hm, y_hm, inside = mc_hit_miss(f, a, b, f_max, N)

# Sample mean
x_sm = np.random.uniform(a, b, N)
sm_est = (b - a) * np.mean(f(x_sm))

print(f'Hit-or-miss: {hm_est:.4f}')
print(f'Sample mean: {sm_est:.4f}')
print(f'True value:  {true_val:.4f}')

# Visualize hit-or-miss
x_curve = np.linspace(a, b, 200)
fig = go.Figure()
fig.add_trace(go.Scatter(
    x=x_curve, y=f(x_curve), mode='lines',
    line=dict(color='white', width=2), name='sin(x)'))
fig.add_trace(go.Scatter(
    x=x_hm[inside], y=y_hm[inside], mode='markers',
    marker=dict(color='#00f3ff', size=2, opacity=0.5),
    name='Hits'))
fig.add_trace(go.Scatter(
    x=x_hm[~inside], y=y_hm[~inside], mode='markers',
    marker=dict(color='#ff006e', size=2, opacity=0.3),
    name='Misses'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='x', range=[0, np.pi],
               zerolinecolor='#808080'),
    yaxis=dict(title='y', range=[0, 1.1],
               zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
