Probability via Sampling

Here’s a question that connects Chapters 5 and 6: if you pick a 2×2 matrix at random, what kind of fixed point does it produce? Is it more likely to be a saddle, a spiral, or a node? There’s no simple analytical answer — but Monte Carlo gives you one in seconds. Generate thousands of random matrices, classify each on the τ-Δ plane, and count.

Learning Objectives
  • Use Monte Carlo to estimate probabilities by counting outcomes over many random trials
  • Generate random 2×2 matrices and classify their fixed points using τ and Δ
  • Build a 2D probability distribution (histogram) in the τ-Δ plane
  • Discover that saddles are surprisingly common among random matrices

MC Probability Estimation:

$$ P(\text{saddle}) \approx \frac{\text{Number of saddles}}{N_{\text{total}}}, \qquad A = \begin{pmatrix} a & b \\ c & d \end{pmatrix},\quad a,b,c,d \sim U(-R, R) $$

Generate \( N \) random matrices with entries uniformly distributed in \( [-R, R] \). For each, compute \( \tau = a + d \) and \( \Delta = ad - bc \). Classify using the τ-Δ plane. The fraction in each region estimates the probability.

Why Are Saddles So Common?

You might expect the five types (stable node, unstable node, stable spiral, unstable spiral, saddle) to be roughly equal — 20% each. But saddles dominate! The reason: \( \Delta = ad - bc \). For random entries, \( ad \) and \( bc \) are independent products of random numbers. The probability that \( ad - bc < 0 \) (saddle condition) is surprisingly high — about 50% for uniform entries. Half of all random linear systems are saddles!

Python Code

Python 

import numpy as np
import plotly.graph_objects as go

N = 100000
R = 1.0

# Generate random matrices
a = np.random.uniform(-R, R, N)
b = np.random.uniform(-R, R, N)
c = np.random.uniform(-R, R, N)
d = np.random.uniform(-R, R, N)

tau = a + d
delta = a * d - b * c
disc = tau**2 - 4 * delta

# Classify
types = []
for i in range(N):
    if delta[i] < 0:
        types.append('Saddle')
    elif abs(disc[i]) < 0.01:
        types.append('Star Node')
    elif disc[i] > 0:
        types.append('Stable Node' if tau[i] < 0 else 'Unstable Node')
    elif abs(tau[i]) < 0.01:
        types.append('Center')
    else:
        types.append('Stable Spiral' if tau[i] < 0 else 'Unstable Spiral')

# Count
from collections import Counter
counts = Counter(types)
for tp in ['Saddle', 'Stable Node', 'Unstable Node',
           'Stable Spiral', 'Unstable Spiral']:
    pct = counts.get(tp, 0) / N * 100
    print(f'{tp:20s}: {pct:.1f}%')

# Bar chart
labels = list(counts.keys())
vals = [counts[k]/N*100 for k in labels]
colors = {'Saddle': '#ff5722', 'Stable Node': '#00f3ff',
          'Unstable Node': '#ff006e', 'Stable Spiral': '#00ff88',
          'Unstable Spiral': '#bb86fc', 'Center': '#ffbe0b',
          'Star Node': '#ffbe0b'}

fig = go.Figure(go.Bar(
    x=labels, y=vals,
    marker_color=[colors.get(k, '#aaa') for k in labels]))
fig.update_layout(
    template='plotly_dark',
    yaxis=dict(title='Percentage (%)', zerolinecolor='#808080'),
    height=400, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

N = 50000
a = np.random.uniform(-1, 1, N)
b = np.random.uniform(-1, 1, N)
c = np.random.uniform(-1, 1, N)
d = np.random.uniform(-1, 1, N)

tau = a + d
delta = a * d - b * c

# 2D histogram
fig = go.Figure()
fig.add_trace(go.Histogram2d(
    x=tau, y=delta, nbinsx=60, nbinsy=60,
    colorscale='Viridis', showscale=True))

# Parabola boundary
t = np.linspace(-3, 3, 200)
fig.add_trace(go.Scatter(x=t, y=t**2/4, mode='lines',
    line=dict(color='white', width=2), name='τ²=4Δ'))
fig.add_trace(go.Scatter(x=[-3,3], y=[0,0], mode='lines',
    line=dict(color='#ffbe0b', width=1.5, dash='dash'),
    name='Δ=0'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='τ (trace)', range=[-3, 3],
               zerolinecolor='#808080'),
    yaxis=dict(title='Δ (determinant)', range=[-2, 3],
               zerolinecolor='#808080'),
    height=500, width=600)
fig.show()
