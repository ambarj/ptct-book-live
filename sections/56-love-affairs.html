Romeo & Juliet: Love in Phase Space

Can mathematics predict the course of true love? Steven Strogatz posed this playful question by modeling Romeo and Juliet’s feelings as a coupled dynamical system. The punchline: the mathematics of love affairs is identical to the physics of oscillators — and all the phase space tools you’ve learned (fixed points, eigenvalues, classification) predict whether a relationship thrives, fades, or cycles endlessly.

Learning Objectives
  • Model a romantic relationship as a 2D dynamical system and interpret the phase portrait as a “love story”
  • Connect the personality parameters \(a, b, c, d\) to eigenvalues, trace, and determinant
  • Predict relationship fate (eternal cycling, decay, explosion, or saddle sensitivity) from the fixed-point classification
  • Explore how the balance between cautiousness and responsiveness determines whether love survives

The Love Affair Model:

$$ \dot{R} = aR + bJ, \qquad \dot{J} = cR + dJ $$

where \( R(t) \) = Romeo’s feelings and \( J(t) \) = Juliet’s feelings. Positive means love, negative means hate, zero means indifference.

The parameters encode personality: \( a \) and \( d \) control self-response (positive = self-reinforcing, negative = cautious), while \( b \) and \( c \) control response to the other’s feelings.

Explorer: The Love Story

Start with the simplest model: \( \dot{R} = J \), \( \dot{J} = -R \). Romeo mirrors Juliet’s feelings, but Juliet is contrarian — the more Romeo loves her, the more she pulls away. Set initial feelings and watch the eternal cycle unfold.

The Story Behind the Cycle

Starting from \( R = 2, J = 0 \): Romeo loves Juliet, but she’s indifferent. His eagerness repels her (\( \dot{J} = -R < 0 \)), so she starts to hate him. Her coldness kills his love (\( \dot{R} = J < 0 \)). Now both hate each other — but her hate triggers a reversal (\( \dot{J} = -R > 0 \) since \( R < 0 \)). She starts to love again, he follows, and the cycle repeats. Only one quarter of the cycle is mutual love — a bittersweet prediction!

Explorer: Cautiousness vs Responsiveness

The symmetric “cautious lovers” model: both partners have the same cautiousness \( \alpha \) and responsiveness \( \beta \). The system \( \dot{R} = -\alpha R + \beta J,\; \dot{J} = \beta R - \alpha J \) has eigenvalues \( \lambda_1 = \beta - \alpha \) and \( \lambda_2 = -(\alpha + \beta) \). The critical question: does cautiousness or responsiveness win?

The Eigenvectors Tell the Story

The eigenvector for \( \lambda_1 = \beta - \alpha \) is \( (1, 1) \) — the “mutual feelings” direction where both love or both hate equally. The eigenvector for \( \lambda_2 = -(\alpha + \beta) \) is \( (1, -1) \) — the “opposite feelings” direction. Since \( \lambda_2 < 0 \) always, opposite feelings always decay. The entire fate hinges on \( \lambda_1 \): if \( \beta > \alpha \), mutual feelings grow (saddle — couples either fall deeply in love or sink into mutual hate); if \( \beta < \alpha \), mutual feelings decay (stable node — indifference wins).

Explanation: The eigenvalue \( \lambda_1 = \beta - \alpha \) controls the switch: for \( \beta < \alpha \) both eigenvalues are negative (stable node — all feelings decay), and for \( \beta > \alpha \) it turns positive (saddle — the outcome depends on where you start). So the transition sits exactly at \( \beta = \alpha = 1.5 \), where \( \lambda_1 = 0 \) and a whole line of fixed points appears along \( R = J \). The tipping point of the relationship is when responsiveness exactly matches cautiousness.
In the saddle regime (\( \beta > \alpha \)), couple A starts at \( (R, J) = (1, 1) \) and couple B at \( (1, -1) \). Whose feelings fade to indifference?
Explanation: The saddle has eigenvector \( (1, 1) \) (the \( R = J \) line) for the unstable eigenvalue \( \lambda_1 = \beta - \alpha > 0 \), and eigenvector \( (1, -1) \) (the \( R = -J \) line) for the stable eigenvalue \( \lambda_2 = -(\alpha + \beta) < 0 \). Couple B starts at \( (1, -1) \), exactly on the stable eigenvector, so their opposite feelings decay to indifference. Couple A sits on the unstable eigenvector: their mutual feelings amplify without bound. A saddle’s fate is all about which eigenvector you start on.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(f, x0, T, N):
    """RK4 for dx/dt = f(x). x is a 2-vector."""
    h = T / N
    x = np.array(x0, dtype=float)
    traj, times = [x.copy()], [0.0]
    for i in range(N):
        k1 = f(x); k2 = f(x + h/2*k1)
        k3 = f(x + h/2*k2); k4 = f(x + h*k3)
        x += h/6 * (k1 + 2*k2 + 2*k3 + k4)
        traj.append(x.copy())
        times.append((i+1)*h)
    return np.array(traj), np.array(times)

# Simple love model: R' = J, J' = -R
love = lambda x: np.array([x[1], -x[0]])
traj, t = rk4(love, [2, 0], 8, 2000)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Phase Portrait', 'The Love Story'])

fig.add_trace(go.Scatter(
    x=traj[:,0], y=traj[:,1], mode='lines',
    line=dict(color='#00f3ff', width=2),
    showlegend=False), row=1, col=1)
fig.add_trace(go.Scatter(
    x=[2], y=[0], mode='markers',
    marker=dict(color='#00f3ff', size=8,
        line=dict(color='white', width=2)),
    showlegend=False), row=1, col=1)

fig.add_trace(go.Scatter(
    x=t, y=traj[:,0], mode='lines',
    line=dict(color='#00f3ff', width=2),
    name='Romeo'), row=1, col=2)
fig.add_trace(go.Scatter(
    x=t, y=traj[:,1], mode='lines',
    line=dict(color='#ff006e', width=2),
    name='Juliet'), row=1, col=2)

fig.update_layout(template='plotly_dark',
    height=400, width=900)
fig.update_xaxes(title='Romeo R', range=[-3,3],
    zerolinecolor='#808080', row=1, col=1)
fig.update_yaxes(title='Juliet J', range=[-3,3],
    zerolinecolor='#808080', row=1, col=1)
fig.update_xaxes(title='Time', zerolinecolor='#808080',
    row=1, col=2)
fig.update_yaxes(title='Feelings', zerolinecolor='#808080',
    row=1, col=2)
fig.show()

import numpy as np
import plotly.graph_objects as go

def rk4_linear(a, b, c, d, x0, T, N):
    h = T / N
    x = np.array(x0, dtype=float)
    traj = [x.copy()]
    for i in range(N):
        def f(u): return np.array([a*u[0]+b*u[1], c*u[0]+d*u[1]])
        k1 = f(x); k2 = f(x+h/2*k1)
        k3 = f(x+h/2*k2); k4 = f(x+h*k3)
        x += h/6*(k1+2*k2+2*k3+k4)
        if np.linalg.norm(x) > 20: break
        traj.append(x.copy())
    return np.array(traj)

presets = {
    'Eternal Cycle': (0, 1, -1, 0),
    'Love Fades': (-2, 1, 1, -2),
    'Star-Crossed': (-1, 2, 2, -1),
    'Spiral Romance': (-0.3, 1, -1, -0.3),
}

colors = ['#00f3ff', '#ff006e', '#ffbe0b', '#00ff88',
          '#bb86fc', '#ff5722', '#76ff03', '#40c4ff']

for name, (a, b, c, d) in presets.items():
    fig = go.Figure()
    for k in range(8):
        th = k * np.pi / 4
        traj = rk4_linear(a, b, c, d,
            [1.5*np.cos(th), 1.5*np.sin(th)], 20, 2000)
        fig.add_trace(go.Scatter(
            x=traj[:,0], y=traj[:,1], mode='lines',
            line=dict(color=colors[k], width=1.5),
            showlegend=False))
    tau, delta = a+d, a*d-b*c
    fig.update_layout(
        template='plotly_dark',
        title=f'{name} (τ={tau:.1f}, Δ={delta:.1f})',
        xaxis=dict(title='Romeo', range=[-3,3],
                   zerolinecolor='#808080'),
        yaxis=dict(title='Juliet', range=[-3,3],
                   zerolinecolor='#808080'),
        height=450, width=500)
    fig.show()
