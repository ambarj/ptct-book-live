Statistics of Random Walks

Individual walks are unpredictable, but ensembles tell a clear story. In this section you’ll derive the two key statistical results for random walks: the mean displacement \( \langle x \rangle = 0 \) (no net drift) and the mean-squared displacement \( \langle x^2 \rangle = N \) (diffusive growth). The critical insight: the typical distance from the origin grows as \( \sqrt{N} \), not \( N \) — much slower than you might guess.

Learning Objectives
  • Compute the ensemble mean \( \langle x_N \rangle = N(p - q) \) and verify it with simulation
  • Compute the variance \( \langle x_N^2 \rangle - \langle x_N \rangle^2 = 4Npq \) and verify the linear-in-N growth
  • Understand the diffusive scaling law: RMS displacement \( \propto \sqrt{N} \), not \( N \)
  • Contrast diffusion (\( \sqrt{N} \)) with ballistic motion (\( N \)) and see why diffusion is slow

Random Walk Statistics (unbiased, \( p = q = 1/2 \)):

$$ \langle x_N \rangle = 0, \qquad \langle x_N^2 \rangle = N, \qquad \text{RMS} = \sqrt{\langle x_N^2 \rangle} = \sqrt{N} $$

General (biased, \( p \neq q \)):

$$ \langle x_N \rangle = N(p - q), \qquad \text{Var}(x_N) = 4Npq $$
Explorer: Ensemble Averages

Run many walks of the same length and compute the sample mean \( \bar{x} \) and mean-squared displacement \( \overline{x^2} \). Compare with the theoretical formulas. Watch the estimates converge as you increase the number of walkers.

Why ⟨x²⟩ = N (Derivation Sketch)

Each step \( s_i = \pm 1 \) is independent with \( \langle s_i \rangle = 0 \) and \( \langle s_i^2 \rangle = 1 \). Then \( \langle x_N^2 \rangle = \langle (\sum s_i)^2 \rangle = \sum \langle s_i^2 \rangle + \sum_{i \neq j} \langle s_i s_j \rangle \). The cross terms vanish (independence): \( \langle s_i s_j \rangle = \langle s_i \rangle \langle s_j \rangle = 0 \). So \( \langle x_N^2 \rangle = N \cdot 1 = N \). The variance grows linearly with the number of steps.

Python Code

Python 

import numpy as np
import plotly.graph_objects as go

# Ensemble of random walks
N, n_walkers = 200, 1000
finals = np.sum(np.random.choice([-1, 1], (n_walkers, N)), axis=1)

mean_x = np.mean(finals)
mean_x2 = np.mean(finals**2)
rms = np.sqrt(mean_x2)

print(f'N = {N} steps, {n_walkers} walkers:')
print(f'  ⟨x⟩   = {mean_x:.2f}   (theory: 0)')
print(f'  ⟨x²⟩  = {mean_x2:.1f}  (theory: {N})')
print(f'  RMS   = {rms:.2f}  (theory: √{N} = {np.sqrt(N):.2f})')

fig = go.Figure()
fig.add_trace(go.Histogram(x=finals, nbinsx=30,
    marker_color='#00f3ff', opacity=0.7, name='Final positions'))

# Gaussian overlay
x = np.linspace(-50, 50, 200)
gauss = n_walkers * (100/30) / np.sqrt(2*np.pi*N) * np.exp(-x**2/(2*N))
fig.add_trace(go.Scatter(x=x, y=gauss, mode='lines',
    line=dict(color='white', width=2, dash='dash'),
    name=f'Gaussian (σ=√{N}={np.sqrt(N):.1f})'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Final position', zerolinecolor='#808080'),
    yaxis=dict(title='Count', zerolinecolor='#808080'),
    height=400, width=550)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

n_walkers = 500
Ns = [10, 25, 50, 100, 200, 500, 1000, 2000]
x2_means, rms_vals = [], []

for N in Ns:
    finals = np.sum(np.random.choice([-1, 1], (n_walkers, N)), axis=1)
    x2_means.append(np.mean(finals**2))
    rms_vals.append(np.sqrt(np.mean(finals**2)))

fig = go.Figure()
fig.add_trace(go.Scatter(x=Ns, y=x2_means, mode='markers+lines',
    marker=dict(color='#00f3ff', size=10),
    line=dict(color='#00f3ff', width=2), name='MC ⟨x²⟩'))
fig.add_trace(go.Scatter(x=[0, 2000], y=[0, 2000], mode='lines',
    line=dict(color='white', width=2, dash='dash'), name='Theory: ⟨x²⟩ = N'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Steps N', zerolinecolor='#808080'),
    yaxis=dict(title='⟨x²⟩', zerolinecolor='#808080'),
    height=400, width=550)
fig.show()
