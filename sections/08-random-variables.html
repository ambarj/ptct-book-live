Random Variables & Their Combinations

Every measurement you make in the lab is a roll of the dice. Drop the same ball from the same height ten times, and you'll get ten slightly different readings. The question isn't "which one is right?" They all are. The real question is: what can you say about the distribution of those readings, and what happens when you start combining them?

Learning Objectives
  • Understand random variables as distributions, not single numbers
  • Discover the addition rules: \( E(S) = N\mu \) and \( \text{Var}(S) = N\sigma^2 \)
  • See the Central Limit Theorem in action
  • Learn why averaging reduces uncertainty by \( 1/\sqrt{N} \)

What Does a Random Variable Look Like?

A random variable isn't a single number — it's a recipe for generating numbers. Each time you "draw" from it, you get a different value, but the values follow a pattern called a distribution. Some values are more likely than others. The histogram below shows what happens when you draw many times from three different distributions.

Interactive: Random Variable Sampler

Every distribution is characterized by two key numbers — where it's centered and how spread out it is:

\[ \text{Mean: } \mu = E(X) \qquad \qquad \text{Variance: } \sigma^2 = E\!\left[(X - \mu)^2\right] \]

Key Insight

The magenta curve is the theoretical probability density function (PDF) — the "true shape" of the distribution. The cyan histogram is what you actually observe from finite samples. With few samples, the histogram is jagged and irregular. With many samples, it converges to the smooth theoretical curve. This convergence is not just a visual trick — it's the law of large numbers in action.

Adding Random Variables

Now the magic begins. Suppose you measure something \( N \) times and add up the results: \( S = X_1 + X_2 + \cdots + X_N \). What can you say about \( S \)? Remarkably, even without knowing the exact shape of the original distribution, you can predict the mean and spread of the sum.

Interactive: Sum of N Random Variables

The rules are beautifully simple. For independent random variables with the same distribution:

\[ E(S) = N\mu \qquad \qquad \text{Var}(S) = N\sigma^2 \qquad \qquad \sigma_S = \sigma\sqrt{N} \]

Key Insight

Watch what happens as you increase \( N \). Even when the original distribution is Uniform (flat!) or Exponential (skewed!), the sum becomes increasingly bell-shaped. This is the Central Limit Theorem — arguably the most important result in all of statistics. The sum of many independent random variables approaches a Gaussian, regardless of the original distribution. The cyan curve shows this Gaussian prediction.

Explanation
\( \sigma_S = \sigma\sqrt{N} = 2\sqrt{9} = 2 \times 3 = 6 \). Notice that the spread grows as \( \sqrt{N} \), not as \( N \). If each measurement fluctuates by ±2, nine measurements don't fluctuate by ±18. They fluctuate by ±6. The random fluctuations partially cancel because they're independent — some are high, some are low.

The Sample Mean: Why Averaging Works

Here's the payoff for all of physics. Instead of the sum, consider the average: \( \bar{X} = S/N \). Dividing by \( N \) doesn't just shift the mean back — it squeezes the distribution. The more measurements you average, the tighter the result clusters around the true value. This is why we repeat experiments.

Interactive: Sample Mean Explorer

The key formula — the one that justifies every error bar in every physics paper ever written:

\[ \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{N}} \]

Double the number of measurements, and you reduce your uncertainty by a factor of \( \sqrt{2} \approx 1.4 \). Want to halve your uncertainty? You need four times as many measurements. This \( 1/\sqrt{N} \) scaling governs how fast experimental precision improves — and it sets a practical limit on how much you can gain by simply repeating an experiment.

Key Insight

Each bar in the histogram represents one "experiment" — drawing \( N \) samples and computing their mean. With 500 experiments, you see the full distribution of possible outcomes. As \( N \) increases, this distribution gets narrower: the sample mean becomes an increasingly precise estimate of the true mean \( \mu \). The yellow curve shows the theoretical prediction \( \mathcal{N}(\mu, \sigma^2/N) \).

Python Code Examples

Here's the Python code that reproduces the key ideas from the explorers above. Run these in a Jupyter notebook to verify the formulas yourself.

Python 
import numpy as np
import plotly.graph_objects as go

# Draw 500 samples from three distributions
n = 500
uniform_samples = np.random.uniform(0, 10, n)
gaussian_samples = np.random.normal(5, 2, n)
exponential_samples = np.random.exponential(2, n)  # mean = 1/λ = 2

# Plot histograms with theoretical PDFs
x_pdf = np.linspace(-1, 12, 300)

fig = go.Figure()
fig.add_trace(go.Histogram(
    x=uniform_samples, histnorm='probability density',
    name='Uniform', marker_color='rgba(0, 243, 255, 0.5)',
    nbinsx=30))
fig.add_trace(go.Scatter(
    x=x_pdf,
    y=np.where((x_pdf >= 0) & (x_pdf <= 10), 0.1, 0),
    mode='lines', name='Uniform PDF',
    line=dict(color='#00f3ff', width=2)))

fig.update_layout(
    template='plotly_dark',
    title='Uniform Distribution: 500 Samples',
    xaxis_title='Value', yaxis_title='Probability Density',
    bargap=0.05)
fig.show()

# Check: sample statistics vs theory
print(f"Uniform:     mean = {uniform_samples.mean():.3f} (theory: 5)")
print(f"Gaussian:    mean = {gaussian_samples.mean():.3f} (theory: 5)")
print(f"Exponential: mean = {exponential_samples.mean():.3f} (theory: 2)")
Python 
import numpy as np
import plotly.graph_objects as go

# Sum of N exponential random variables (1000 trials)
N = 10
n_trials = 1000
lam = 0.5
mu, sigma = 1/lam, 1/lam  # mean=2, sigma=2

sums = np.array([
    np.sum(np.random.exponential(mu, N))
    for _ in range(n_trials)])

# Theory: E(S) = N*mu, sigma_S = sigma*sqrt(N)
E_S = N * mu
sigma_S = sigma * np.sqrt(N)

# CLT Gaussian overlay
x_theory = np.linspace(E_S - 4*sigma_S, E_S + 4*sigma_S, 200)
y_theory = (1 / (sigma_S * np.sqrt(2*np.pi))) * \
    np.exp(-0.5 * ((x_theory - E_S) / sigma_S)**2)

fig = go.Figure()
fig.add_trace(go.Histogram(
    x=sums, histnorm='probability density',
    name=f'Sum of {N}', marker_color='rgba(255, 0, 255, 0.5)',
    nbinsx=30))
fig.add_trace(go.Scatter(
    x=x_theory, y=y_theory, mode='lines',
    name=f'CLT: N({E_S:.1f}, {sigma_S:.2f}²)',
    line=dict(color='#00f3ff', width=2.5)))

fig.update_layout(
    template='plotly_dark',
    title=f'Sum of {N} Exponentials — Central Limit Theorem',
    xaxis_title='Sum S', yaxis_title='Probability Density')
fig.show()

print(f"Observed: E(S) = {sums.mean():.2f}, σ_S = {sums.std():.2f}")
print(f"Theory:   E(S) = {E_S:.2f}, σ_S = {sigma_S:.2f}")
Python 
import numpy as np
import plotly.graph_objects as go

# 500 experiments: each computes the mean of N samples
N_values = [1, 5, 25, 100]
n_experiments = 500
mu, sigma = 5, 2  # Gaussian source

fig = go.Figure()
colors = ['#00f3ff', '#ff00ff', '#00ff9f', '#ffff00']

for i, N in enumerate(N_values):
    means = np.array([
        np.mean(np.random.normal(mu, sigma, N))
        for _ in range(n_experiments)])

    sigma_xbar = sigma / np.sqrt(N)
    fig.add_trace(go.Histogram(
        x=means, histnorm='probability density',
        name=f'N={N} (σ/√N = {sigma_xbar:.2f})',
        marker_color=f'rgba({int(colors[i][1:3],16)},{int(colors[i][3:5],16)},{int(colors[i][5:7],16)},0.4)',
        nbinsx=25))

fig.update_layout(
    template='plotly_dark',
    title='Sample Mean Distribution: σ_X̄ = σ/√N',
    xaxis_title='Sample Mean X̄',
    yaxis_title='Probability Density',
    barmode='overlay',
    xaxis=dict(range=[0, 10]))
fig.show()

# Numerical verification
for N in N_values:
    means = [np.mean(np.random.normal(mu, sigma, N))
             for _ in range(5000)]
    print(f"N={N:3d}: observed σ_X̄ = {np.std(means):.3f}, "
          f"theory σ/√N = {sigma/np.sqrt(N):.3f}")
