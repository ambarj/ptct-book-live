From Discrete to Continuous

This is the climax of Chapter 7: a discrete random walk with step size \( a \) and time step \( \tau \) becomes, in the limit \( a \to 0 \) and \( \tau \to 0 \), a partial differential equation — the diffusion equation. Individual random steps, too small to see, collectively produce the smooth spreading of heat, ink in water, and perfume through a room. Microscopic randomness creates macroscopic law.

Learning Objectives
  • Understand the continuum limit: step size \( a \to 0 \), time step \( \tau \to 0 \), with \( D = a^2/(2\tau) \) held fixed
  • See how the discrete master equation becomes the diffusion PDE: \( \partial P/\partial t = D\,\partial^2 P/\partial x^2 \)
  • Connect the diffusion constant \( D \) to microscopic parameters: \( D = a^2/(2\tau) \)
  • Watch the discrete binomial distribution converge to the continuous Gaussian solution

The Continuum Limit:

$$ \underbrace{P(x, t+\tau)}_{\text{future}} = \tfrac{1}{2}\underbrace{P(x-a, t)}_{\text{left neighbor}} + \tfrac{1}{2}\underbrace{P(x+a, t)}_{\text{right neighbor}} $$

Taylor-expand both sides to second order. Cancel and collect:

$$ \frac{\partial P}{\partial t} = \frac{a^2}{2\tau}\frac{\partial^2 P}{\partial x^2} = D\frac{\partial^2 P}{\partial x^2} $$

The diffusion equation. The diffusion constant \( D = a^2/(2\tau) \) connects microscopic (step size, step time) to macroscopic (spreading rate).

Explorer: Watching the Limit

Start with a small random walk (large steps, few of them) and progressively refine: smaller steps, more of them, same total time. The binomial distribution converges to the smooth Gaussian — the diffusion equation’s solution.

The Key Trick: Hold D Fixed

As \( a \to 0 \) and \( \tau \to 0 \), the ratio \( D = a^2/(2\tau) \) must stay finite. If you shrink \( a \) by half, you must shrink \( \tau \) by a factor of 4 (since \( \tau \propto a^2 \)). This means more steps in the same time. The limiting distribution is the Gaussian \( P(x,t) = \frac{1}{\sqrt{4\pi Dt}} e^{-x^2/(4Dt)} \).

Python Code

Python 

import numpy as np
import plotly.graph_objects as go
from math import comb

D, T = 1.0, 1.0  # Diffusion constant and total time
x_cont = np.linspace(-5, 5, 500)
gauss = np.exp(-x_cont**2 / (4*D*T)) / np.sqrt(4*np.pi*D*T)

fig = go.Figure()

# Discrete walks at different refinements
for level, color in zip([1, 2, 4, 16], ['#ff006e', '#ffbe0b', '#00ff88', '#00f3ff']):
    a = 1.0 / level          # step size
    tau = a**2 / (2*D)       # time step
    N = int(T / tau)          # number of steps

    # Binomial distribution
    m_vals = np.arange(-N, N+1, 2)
    n_R = (m_vals + N) // 2
    probs = np.array([comb(N, int(nR)) * 0.5**N for nR in n_R])
    x_vals = m_vals * a       # physical position

    fig.add_trace(go.Bar(x=x_vals, y=probs / (2*a),  # density
        marker_color=color, opacity=0.5, width=1.8*a,
        name=f'a={a:.2f}, N={N}'))

# Gaussian limit
fig.add_trace(go.Scatter(x=x_cont, y=gauss, mode='lines',
    line=dict(color='white', width=3, dash='dash'),
    name='Gaussian limit'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Position x', range=[-5, 5],
        zerolinecolor='#808080'),
    yaxis=dict(title='P(x, T)', zerolinecolor='#808080'),
    barmode='overlay', height=450, width=650)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

D = 1.0
x = np.linspace(-6, 6, 500)

fig = go.Figure()
times = [0.1, 0.5, 1.0, 2.0, 5.0]
colors = ['#ff006e', '#ffbe0b', '#00f3ff', '#00ff88', '#bb86fc']

for t, color in zip(times, colors):
    P = np.exp(-x**2 / (4*D*t)) / np.sqrt(4*np.pi*D*t)
    fig.add_trace(go.Scatter(x=x, y=P, mode='lines',
        line=dict(color=color, width=2),
        name=f't = {t}'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='x', range=[-6, 6], zerolinecolor='#808080'),
    yaxis=dict(title='P(x, t)', range=[0, 1.5], zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
