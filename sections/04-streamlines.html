Streamlines and Flow Visualization

In Section 1.3, we learned to read vector fields through arrows and trace individual field lines. Now we'll see the complete picture: streamlines reveal the global flow pattern, showing how an entire fluid or field behaves across space. This is how physicists visualize everything from air flow around airplane wings to electric fields around circuits.

Learning Objectives
  • Visualize complete flow patterns using streamlines
  • Identify and classify fixed points: nodes, saddles, centers, and spirals
  • Understand the physical meaning of stable vs unstable equilibria
  • Combine multiple flow sources to create complex patterns
  • Connect flow visualization to physical systems (oscillators, fluid dynamics)

From Arrows to Streamlines

A streamline is a curve that is everywhere tangent to the velocity field. If you dropped a leaf into a steady flow, it would follow a streamline exactly. While arrows show the field at discrete points, streamlines show the continuous paths particles would take.

Streamline Definition:

$$ \frac{dx}{F_x} = \frac{dy}{F_y} $$

At every point on a streamline, the tangent direction equals the field direction.

Key Patterns to Notice
  • Uniform: Parallel lines - constant flow in one direction
  • Source/Sink: Radial lines diverging from or converging to a point
  • Vortex: Closed circles - pure rotation with no radial motion
  • Saddle: Hyperbolic curves - stable in one direction, unstable in another
  • Spirals: Combination of rotation and radial motion

Fixed Points and Stability

A fixed point (or equilibrium) is where the flow velocity is zero - a particle placed there would stay forever. But not all fixed points are equal! Some attract nearby particles (stable), some repel them (unstable), and some do both depending on direction.

The behavior near a fixed point is determined by the eigenvalues of the system. Don't worry about the math yet - let's build visual intuition first.

Radial component = energy gain/loss (friction, damping, driving force)

Combining Flow Patterns

Real physical situations often involve multiple sources or sinks. What happens when flows interact? Stagnation points emerge where opposing flows cancel out - places where the velocity is zero even though there's active flow all around.

Stagnation Points

Where streamlines meet or diverge, the flow velocity is zero. These stagnation points are critical in aerodynamics (where air splits around a wing), fluid mixing, and many other applications. In the dipole configuration, notice the stagnation point exactly between the source and sink!

Python Code Examples

Streamline plots in Python use the same field line tracing approach from Section 1.3, but we trace many lines to show the global pattern.

Python 
import numpy as np
import plotly.graph_objects as go

def trace_streamline(x0, y0, field_func, dt=0.02, steps=500):
    """Trace a single streamline using Euler integration."""
    x, y = [x0], [y0]

    for _ in range(steps):
        fx, fy = field_func(x[-1], y[-1])
        mag = np.sqrt(fx**2 + fy**2)
        if mag < 0.01:
            break
        x.append(x[-1] + dt * fx / mag)
        y.append(y[-1] + dt * fy / mag)
        if abs(x[-1]) > 5 or abs(y[-1]) > 5:
            break

    return x, y

# Vortex field
def vortex(x, y):
    r = np.sqrt(x**2 + y**2) or 0.01
    return -y/r, x/r

# Trace streamlines from circle of starting points
fig = go.Figure()
for angle in np.linspace(0, 2*np.pi, 12, endpoint=False):
    x0, y0 = 2*np.cos(angle), 2*np.sin(angle)
    x, y = trace_streamline(x0, y0, vortex)
    fig.add_trace(go.Scatter(x=x, y=y, mode='lines',
                             line=dict(color='#00f3ff', width=1.5),
                             showlegend=False))

fig.update_layout(
    template='plotly_dark',
    title='Vortex Streamlines',
    xaxis=dict(range=[-4, 4], scaleanchor='x', gridcolor='#2a2f4a', zerolinecolor='#808080'),
    yaxis=dict(range=[-4, 4], gridcolor='#2a2f4a', zerolinecolor='#808080')
)
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def make_linear_field(radial, rotation):
    """Create a linear field with given radial and rotational components."""
    def field(x, y):
        # Radial: (x, y) for growth, (-x, -y) for decay
        # Rotation: (-y, x) for CCW
        fx = radial * x - rotation * y
        fy = radial * y + rotation * x
        return fx, fy
    return field

def classify_fixed_point(radial, rotation):
    """Classify based on eigenvalue structure."""
    if abs(rotation) < 0.01:
        return "Stable Node" if radial < 0 else "Unstable Node"
    elif abs(radial) < 0.01:
        return "Center"
    elif radial < 0:
        return "Stable Spiral"
    else:
        return "Unstable Spiral"

# Example: Stable spiral (damped oscillator)
radial, rotation = -0.3, 1.0
field = make_linear_field(radial, rotation)
print(f"Classification: {classify_fixed_point(radial, rotation)}")

# Plot streamlines
fig = go.Figure()
for angle in np.linspace(0, 2*np.pi, 8, endpoint=False):
    x0, y0 = 3*np.cos(angle), 3*np.sin(angle)
    x, y = trace_streamline(x0, y0, field, steps=1000)
    fig.add_trace(go.Scatter(x=x, y=y, mode='lines',
                             line=dict(color='#ff00ff', width=1.5),
                             showlegend=False))

fig.update_layout(
    template='plotly_dark',
    title=f'{classify_fixed_point(radial, rotation)}: radial={radial}, rotation={rotation}',
    xaxis=dict(range=[-4, 4], scaleanchor='x'),
    yaxis=dict(range=[-4, 4])
)
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def dipole_field(x, y, separation=2):
    """Dipole: source at (-d/2, 0), sink at (+d/2, 0)."""
    d = separation / 2

    # Source contribution
    r1 = np.sqrt((x + d)**2 + y**2) or 0.01
    fx1, fy1 = (x + d) / r1, y / r1

    # Sink contribution (negative)
    r2 = np.sqrt((x - d)**2 + y**2) or 0.01
    fx2, fy2 = -(x - d) / r2, -y / r2

    return fx1 + fx2, fy1 + fy2

# Plot dipole streamlines
fig = go.Figure()

# Starting points: grid around the configuration
starts = []
for xi in np.linspace(-3, 3, 7):
    starts.append((xi, 3))
    starts.append((xi, -3))
for yi in np.linspace(-2, 2, 5):
    starts.append((-3, yi))
    starts.append((3, yi))

for x0, y0 in starts:
    x, y = trace_streamline(x0, y0, lambda x, y: dipole_field(x, y, 2), steps=800)
    fig.add_trace(go.Scatter(x=x, y=y, mode='lines',
                             line=dict(color='#00f3ff', width=1.5),
                             showlegend=False))

# Mark source and sink
fig.add_trace(go.Scatter(x=[-1, 1], y=[0, 0], mode='markers+text',
                         marker=dict(size=12, color=['#00ff9f', '#ff6b6b']),
                         text=['Source', 'Sink'], textposition='top center'))

fig.update_layout(
    template='plotly_dark',
    title='Dipole Flow (Source + Sink)',
    xaxis=dict(range=[-4, 4], scaleanchor='x'),
    yaxis=dict(range=[-4, 4])
)
fig.show()
