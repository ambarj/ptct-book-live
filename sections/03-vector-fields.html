Vector Fields and Field Lines

Have you ever watched a weather forecast showing wind patterns across a map? Those swirling arrows aren't just decoration—they're a vector field. At every point on the map, an arrow tells you which way the wind blows and how fast. This same visual language describes electric fields, magnetic fields, fluid flow, and countless other physical phenomena.

Learning Objectives
  • Understand what a vector field represents: a vector at every point in space
  • Read direction and magnitude from arrow plots
  • Trace field lines and understand their physical meaning
  • Recognize common field patterns: uniform, radial, and rotational
  • Combine simple fields to create complex flow patterns

What is a Vector Field?

A scalar function like \( f(x) = x^2 \) gives you one number at each point. A vector field gives you an arrow at each point—both a direction and a magnitude.

Mathematically, a 2D vector field assigns a vector \( \vec{F}(x, y) = (F_x(x,y), F_y(x,y)) \) to every point \( (x, y) \). But forget the formulas for a moment—let's build intuition visually first.

Vector Field Notation:

$$ \vec{F}(x, y) = F_x(x,y) \, \hat{i} + F_y(x,y) \, \hat{j} $$

At each point \( (x, y) \), there's an arrow with horizontal component \( F_x \) and vertical component \( F_y \).

Field Lines: Following the Flow

Arrows tell you what happens at a point. But what if you want to know the whole journey? Field lines (also called streamlines or flow lines) show the path a particle would take if it followed the arrows continuously.

Imagine dropping a leaf into a stream. The leaf doesn't teleport—it flows smoothly along the water. Field lines are the trajectories of such "test particles" in a vector field.

Key Insight: Field Lines Never Cross

At any point, there's only one direction the field points. If two field lines crossed, the field would have to point in two directions at once—impossible! When you see field lines getting closer together, it means the field is getting stronger (like water speeding up in a narrow channel).

Building Complex Fields: Superposition

Here's where things get interesting. Real physical systems rarely have just one type of field. The electric field around two charges combines contributions from both. Water draining in a river mixes bulk flow with rotation. The key principle is superposition: vector fields add.

What happens if you add a source and a vortex? You get a spiral—like water swirling down a drain, moving both around and toward the center!

Superposition Principle

When multiple fields are present, the total field at any point is the vector sum of the individual fields:

$$ \vec{F}_{total} = \vec{F}_1 + \vec{F}_2 + \vec{F}_3 + \ldots $$

This is why we can understand complex fields by breaking them into simpler components!

Python Code Examples

Let's create these vector field visualizations in Python using Plotly. The same concepts apply—we're just computing the field components programmatically.

Python 
import numpy as np
import plotly.figure_factory as ff
import plotly.graph_objects as go

# Create a grid of points
x = np.linspace(-3, 3, 15)
y = np.linspace(-3, 3, 15)
X, Y = np.meshgrid(x, y)

# Define vector field: Source (radial outward)
U = X  # x-component
V = Y  # y-component

# Normalize for consistent arrow lengths
magnitude = np.sqrt(U**2 + V**2)
magnitude[magnitude == 0] = 1  # Avoid division by zero
U_norm = U / magnitude
V_norm = V / magnitude

# Create quiver plot
fig = ff.create_quiver(
    X, Y, U_norm, V_norm,
    scale=0.2,
    arrow_scale=0.3,
    line=dict(color='#00f3ff', width=1.5)
)

# Styling
fig.update_layout(
    template='plotly_dark',
    title='Source Field: F(x,y) = (x, y)',
    xaxis=dict(
        range=[-4, 4],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080'
    ),
    yaxis=dict(
        range=[-4, 4],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080',
        scaleanchor='x'
    )
)

fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def trace_field_line(x0, y0, field_func, dt=0.05, steps=200):
    """Trace a field line using Euler integration."""
    x, y = [x0], [y0]

    for _ in range(steps):
        fx, fy = field_func(x[-1], y[-1])
        mag = np.sqrt(fx**2 + fy**2)
        if mag < 0.01:  # Stop at fixed points
            break
        # Normalize and step
        x.append(x[-1] + dt * fx / mag)
        y.append(y[-1] + dt * fy / mag)

        # Stop if out of bounds
        if abs(x[-1]) > 5 or abs(y[-1]) > 5:
            break

    return x, y

# Define vortex field
def vortex(x, y):
    return -y, x

# Trace several field lines
fig = go.Figure()

starting_points = [
    (1, 0), (2, 0), (0, 1), (0, 2),
    (-1, 0), (-2, 0), (0, -1), (0, -2)
]

colors = ['#00f3ff', '#ff00ff', '#ffff00', '#00ff9f',
          '#00f3ff', '#ff00ff', '#ffff00', '#00ff9f']

for (x0, y0), color in zip(starting_points, colors):
    x, y = trace_field_line(x0, y0, vortex, steps=500)
    fig.add_trace(go.Scatter(
        x=x, y=y,
        mode='lines',
        line=dict(color=color, width=2),
        showlegend=False
    ))

# Styling
fig.update_layout(
    template='plotly_dark',
    title='Vortex Field Lines (Circular Orbits)',
    xaxis=dict(
        range=[-3, 3],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080'
    ),
    yaxis=dict(
        range=[-3, 3],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080',
        scaleanchor='x'
    )
)

fig.show()
Python 
import numpy as np
import plotly.figure_factory as ff

# Create grid
x = np.linspace(-3, 3, 15)
y = np.linspace(-3, 3, 15)
X, Y = np.meshgrid(x, y)

# Combine fields: Sink + Vortex = Spiral inward
sink_strength = 1.0
vortex_strength = 1.0

U = -sink_strength * X - vortex_strength * Y
V = -sink_strength * Y + vortex_strength * X

# Normalize
magnitude = np.sqrt(U**2 + V**2)
magnitude[magnitude == 0] = 1
U_norm = U / magnitude
V_norm = V / magnitude

# Create quiver plot
fig = ff.create_quiver(
    X, Y, U_norm, V_norm,
    scale=0.2,
    arrow_scale=0.3,
    line=dict(color='#ff00ff', width=1.5)
)

# Styling
fig.update_layout(
    template='plotly_dark',
    title='Spiral Field: Sink + Vortex',
    xaxis=dict(
        range=[-4, 4],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080'
    ),
    yaxis=dict(
        range=[-4, 4],
        gridcolor='#2a2f4a',
        zerolinecolor='#808080',
        scaleanchor='x'
    )
)

fig.show()
