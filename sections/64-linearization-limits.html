When Linearization Fails

Linearization is powerful but not infallible. In the last section you learned the trust rule: hyperbolic fixed points are safe. This section explores what goes wrong at the boundary — non-hyperbolic fixed points where tiny nonlinear terms can qualitatively change the behavior. The most dramatic failure: linearization predicts a center, but the true system spirals.

Learning Objectives
  • See concrete examples where linearization succeeds (saddle, spiral) and where it fails (center → spiral)
  • Understand why centers are structurally unstable: any nonlinear perturbation can break closed orbits
  • Recognize the zero-eigenvalue case where linearization is completely inconclusive
  • Build a mental map of the τ-Δ plane showing which regions are safe and which require caution

The Classic Failure:

$$ \dot{r} = \mu r + r^3, \qquad \dot{\theta} = 1 $$

When \( \mu = 0 \), the Jacobian at the origin has eigenvalues \( \pm i \) — a center. But the \( r^3 \) term makes trajectories spiral outward. Linearization misses this entirely because \( r^3 \) vanishes at the origin.

Two systems with the same linearization (a center with λ = ±i) but different nonlinear terms. The left system has closed orbits (linearization succeeds); the right system spirals outward (linearization fails). Same Jacobian, different truth.

Why Centers are Fragile

A center has pure imaginary eigenvalues: \( \lambda = \pm i\omega \). The orbits are closed because the radial and angular dynamics perfectly balance. But any nonlinear term that gives a net radial push (inward or outward) breaks this balance. The \( \dot{r} = \mu r \) term from linearization is exactly zero at a center — so the leading-order radial behavior comes from nonlinear terms like \( r^3 \), which linearization cannot see. This is why centers are the one type you cannot trust from linearization alone.

Explanation:

  • Eigenvalues change: ✗ See above — the Jacobian is unchanged, so eigenvalues are always ±iω.

  • Only for large nonlinear terms: ✗ Even infinitesimally small \( \epsilon \neq 0 \) breaks the center into a spiral. The failure is qualitative, not quantitative.

Explanation: The trust criterion is hyperbolicity: all eigenvalues must have nonzero real part. This excludes only the τ = 0 axis (centers) and the Δ = 0 axis (zero eigenvalues). Everywhere else — nodes, spirals, saddles — linearization is guaranteed correct by the Hartman-Grobman theorem.

Explanation: A conserved quantity (like energy in a Hamiltonian system, or \( H = x - \ln x + y - \ln y \) in Lotka-Volterra) forces trajectories to stay on level curves — guaranteeing closed orbits. A Lyapunov function can prove stability without solving the ODE. Both go beyond what the Jacobian alone can tell you.
A student linearizes a nonlinear system and finds eigenvalues \( \lambda = -0.001 \pm 2i \). Should they trust this prediction of a stable spiral?
Explanation: Technically, Re(λ) = −0.001 ≠ 0, so the FP is hyperbolic and the Hartman-Grobman theorem applies. But practically, being so close to the imaginary axis means the system is “almost a center.” Nonlinear terms could easily dominate the tiny linear decay, making the true behavior differ from the linearized prediction at observable timescales. Mathematical rigor says “trust,” but physical intuition says “verify.”

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(f, g, x0, y0, T, N):
    h=T/N; X,Y=[x0],[y0]; x,y=x0,y0
    for _ in range(N):
        k1x,k1y=f(x,y),g(x,y)
        k2x,k2y=f(x+h/2*k1x,y+h/2*k1y),g(x+h/2*k1x,y+h/2*k1y)
        k3x,k3y=f(x+h/2*k2x,y+h/2*k2y),g(x+h/2*k2x,y+h/2*k2y)
        k4x,k4y=f(x+h*k3x,y+h*k3y),g(x+h*k3x,y+h*k3y)
        x+=h/6*(k1x+2*k2x+2*k3x+k4x)
        y+=h/6*(k1y+2*k2y+2*k3y+k4y)
        if x*x+y*y>100: break
        X.append(x); Y.append(y)
    return np.array(X), np.array(Y)

# System: ẋ = -y + ε·x·(x²+y²), ẏ = x + ε·y·(x²+y²)
# Jacobian at origin: [[0,-1],[1,0]] for ALL ε
# But ε>0 → unstable spiral, ε<0 → stable spiral

fig = make_subplots(1, 3, subplot_titles=[
    'ε=0 (Center)', 'ε=0.1 (Unstable spiral)', 'ε=−0.1 (Stable spiral)'])

colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88']
for col, eps in enumerate([0, 0.1, -0.1]):
    f = lambda x,y,e=eps: -y + e*x*(x*x+y*y)
    g = lambda x,y,e=eps:  x + e*y*(x*x+y*y)
    for k in range(4):
        th = k*np.pi/2
        X, Y = rk4(f, g, np.cos(th), np.sin(th), 15, 3000)
        fig.add_trace(go.Scatter(x=X, y=Y, mode='lines',
            line=dict(color=colors[k], width=1.5),
            showlegend=False), row=1, col=col+1)

for col in range(3):
    fig.update_xaxes(title='x', range=[-3,3],
        zerolinecolor='#808080', row=1, col=col+1)
    fig.update_yaxes(title='y', range=[-3,3],
        zerolinecolor='#808080', row=1, col=col+1)

fig.update_layout(template='plotly_dark', height=400, width=1000)
fig.show()

import numpy as np
import plotly.graph_objects as go

fig = go.Figure()
tau = np.linspace(-5, 5, 400)

# Parabola boundary
fig.add_trace(go.Scatter(x=tau, y=tau**2/4, mode='lines',
    line=dict(color='white', width=2), name='τ²=4Δ'))

# Trust regions
fig.add_shape(type='rect', x0=-5,x1=5,y0=-3,y1=0,
    fillcolor='rgba(0,255,136,0.1)', line=dict(width=0))
fig.add_shape(type='rect', x0=-5,x1=-0.1,y0=0,y1=7,
    fillcolor='rgba(0,255,136,0.08)', line=dict(width=0))
fig.add_shape(type='rect', x0=0.1,x1=5,y0=0,y1=7,
    fillcolor='rgba(0,255,136,0.08)', line=dict(width=0))

# Danger zones
fig.add_trace(go.Scatter(x=[0,0],y=[0,7], mode='lines',
    line=dict(color='#ffbe0b', width=4),
    name='τ=0 (DANGER)'))
fig.add_trace(go.Scatter(x=[-5,5],y=[0,0], mode='lines',
    line=dict(color='#ff5722', width=2, dash='dash'),
    name='Δ=0 (DANGER)'))

# Example systems
examples = [
    (-0.6, 2, 'Damped\nPendulum', '#00f3ff'),
    (0, 2, 'Lotka-\nVolterra', '#ffbe0b'),
    (-4, 3, 'Overdamped\nSHO', '#00f3ff'),
    (0.6, 2, 'Van der Pol\n(unstable)', '#ff006e'),
    (-1, -2, 'Competing\nSpecies', '#00ff88'),
]
for tau_v, delta_v, label, color in examples:
    fig.add_trace(go.Scatter(x=[tau_v],y=[delta_v],
        mode='markers+text', text=[label],
        textposition='top center',
        textfont=dict(color=color, size=10),
        marker=dict(color=color, size=12,
            line=dict(color='white', width=2)),
        showlegend=False))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='τ', range=[-5,5],
        zerolinecolor='#808080'),
    yaxis=dict(title='Δ', range=[-3,7],
        zerolinecolor='#808080'),
    height=550, width=650)
fig.show()
