The χ² Criterion: Finding Best Fit

You have data with error bars. You have a model with an unknown parameter. How do you find the "best" value? Eyeballing is subjective — χ² (chi-squared) gives you a number. The smaller χ² is, the better the model fits the data. The parameter value that minimises χ² is your best-fit estimate.

Learning Objectives
  • Define the χ² statistic: \( \chi^2 = \sum_i \frac{(y_i - f(x_i))^2}{\sigma_i^2} \)
  • Visualise χ² as a function of model parameters (the χ² landscape)
  • Understand why data points with smaller uncertainties get more weight
  • Find the best-fit parameter by locating the minimum of χ²

The χ² statistic:

$$ \chi^2(a) = \sum_{i=1}^{N} \frac{\big(y_i - f(x_i;\, a)\big)^2}{\sigma_i^2} $$

Each residual \( y_i - f(x_i;\,a) \) is the gap between data and model. Dividing by \( \sigma_i^2 \) gives more weight to precise measurements.

Why does the χ² formula divide each residual by \( \sigma_i^2 \)?
Explanation: Dividing by \( \sigma_i^2 \) means that a point with \( \sigma = 1 \) contributes 100× more to χ² than a point with \( \sigma = 10 \). This is physically sensible: you should trust your most precise measurements the most. (Making units cancel is a side benefit, not the main reason.)

Why Weighting Matters

Not all data points are created equal. A measurement with a tiny error bar should count more than one with a huge error bar. This explorer lets you toggle between weighted χ² (dividing by \( \sigma_i^2 \)) and unweighted (all residuals treated equally). Watch how the best-fit value changes.

Interactive: Weighting by Uncertainty
Key Insight

Weighting by \( 1/\sigma_i^2 \) matters most when uncertainties vary across data points. With relative noise (\( \sigma = 20\% \times d \)), early time points (small \( d \), small \( \sigma \)) get more weight than late ones. Unweighted fitting treats a measurement at \( t = 1 \) the same as one at \( t = 10 \), even though the latter has much larger absolute uncertainty.

Explanation:

  • True: With relative noise, early points (small \( d \)) have much smaller \( \sigma \) than late points, so weighting changes the fit significantly.
  • True: A few very precise points will dominate the weighted fit, pulling the curve toward them.
  • False: With only 2 points, any model with ≥2 parameters will fit perfectly regardless of weighting.

Python Code

Here's how to compute χ² and visualise the parameter landscape.

Python 

import numpy as np
import plotly.graph_objects as go

# Galileo's data: d = (g/2) * t^2, g = 9.8
g_true = 9.8
times = np.arange(1, 11)
d_true = 0.5 * g_true * times**2

# Generate noisy data (5 trials, 15% noise)
rng = np.random.default_rng(42)
N_trials = 5
noise_pct = 0.15
data = np.array([d_true + rng.normal(0, noise_pct * d_true)
                 for _ in range(N_trials)])
means = data.mean(axis=0)
stds = data.std(axis=0, ddof=1)
errors = stds / np.sqrt(N_trials - 1)

# Compute χ² for a range of parameter values
a_values = np.linspace(3.0, 7.0, 500)
chi2_values = np.array([
    np.sum(((means - a * times**2) / errors)**2)
    for a in a_values
])

# Find minimum
a_best = a_values[np.argmin(chi2_values)]
chi2_min = chi2_values.min()

# Plot
fig = go.Figure()
fig.add_trace(go.Scatter(
    x=a_values, y=chi2_values, mode='lines',
    line=dict(color='#00f3ff', width=2),
    name='χ²(a)'
))
fig.add_trace(go.Scatter(
    x=[a_best], y=[chi2_min], mode='markers',
    marker=dict(size=12, color='#ffff00', symbol='star'),
    name=f'Min: a = {a_best:.3f}'
))
fig.update_layout(
    template='plotly_dark',
    title=f'χ² landscape — best fit a = {a_best:.3f}',
    xaxis=dict(title='Parameter a', range=[3, 7],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080'),
    yaxis=dict(title='χ²', gridcolor='#2a2f4a',
               zerolinecolor='#808080', linecolor='#808080')
)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# Regenerate the dataset (same as Tab 1) so this script runs standalone
g_true = 9.8
times = np.arange(1, 11)
d_true = 0.5 * g_true * times**2
rng = np.random.default_rng(42)
N_trials, noise_pct = 5, 0.15
data = np.array([d_true + rng.normal(0, noise_pct * d_true)
                 for _ in range(N_trials)])
means = data.mean(axis=0)
stds = data.std(axis=0, ddof=1)
errors = stds / np.sqrt(N_trials - 1)

# Model: d = a + c * t^2 (offset + quadratic)
a_range = np.linspace(-20, 20, 100)
c_range = np.linspace(3.0, 7.0, 100)

# Compute χ² on 2D grid
chi2_grid = np.zeros((len(c_range), len(a_range)))
for i, c in enumerate(c_range):
    for j, a in enumerate(a_range):
        model = a + c * times**2
        chi2_grid[i, j] = np.sum(((means - model) / errors)**2)

# Find minimum
idx = np.unravel_index(chi2_grid.argmin(), chi2_grid.shape)
a_best = a_range[idx[1]]
c_best = c_range[idx[0]]

# Contour plot
fig = go.Figure(data=go.Contour(
    x=a_range, y=c_range, z=chi2_grid,
    colorscale='Viridis', ncontours=20,
    colorbar=dict(title='χ²')
))
fig.add_trace(go.Scatter(
    x=[a_best], y=[c_best], mode='markers',
    marker=dict(size=14, color='#ff00ff', symbol='x'),
    name=f'Min: ({a_best:.1f}, {c_best:.2f})'
))
fig.update_layout(
    template='plotly_dark',
    title=f'χ² Landscape — min at a={a_best:.1f}, c={c_best:.3f}',
    xaxis=dict(title='Offset a', range=[-20, 20],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080'),
    yaxis=dict(title='Coefficient c', range=[3, 7],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080')
)
fig.show()

3. Think
A good fit has \( \chi^2 / N_{\text{dof}} \approx 1 \), where \( N_{\text{dof}} = N_{\text{data}} - N_{\text{params}} \). If \( \chi^2 / N_{\text{dof}} \gg 1 \), the model doesn't fit the data. If \( \chi^2 / N_{\text{dof}} \ll 1 \), your error bars may be too large. Explain why in your own words.
