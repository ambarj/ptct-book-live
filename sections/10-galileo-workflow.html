Galileo's Experiment: Complete Workflow

Galileo drops a ball and times how far it falls. He repeats each measurement several times because no single trial is perfectly accurate. By the end of this section you will do exactly the same thing — virtually — and extract the acceleration due to gravity \( g \) from noisy data. This is the complete experimental workflow: generate data → compute statistics → plot with error bars → compare to theory.

Learning Objectives
  • Generate synthetic experimental data with controlled noise
  • Compute mean and error bar at each time point from repeated trials
  • Create an error-bar plot and overlay the theoretical curve \( d = \tfrac{1}{2}g\,t^2 \)
  • Judge whether your data is consistent with the known value \( g = 9.8\;\text{m/s}^2 \)

How Much Noise Can You Tolerate?

A measurement is only useful if the error bar is small enough to tell theory and falsehood apart. This explorer fixes \( N = 10 \) trials and lets you crank the noise up. The readout counts how many of the 10 time points have the theoretical curve inside their 1σ error bar. Statistially you expect about 7 out of 10 (68%).

If your error bars represent ±1 standard error (one σ of the mean's sampling distribution), what fraction of them should contain the true value (on average)?
Explanation: For a Gaussian distribution, roughly 68% of measurements fall within ±1σ of the mean. So about 68% of 1σ error bars should contain the true value. For 95% coverage you need ±2σ error bars.
With 10 time points and 1σ error bars, roughly how many points do you expect to miss the theoretical curve (i.e., the theory lies outside the error bar)?

Expected misses ≈ out of 10
Explanation: If 68% of error bars contain the true value, then 32% miss. Out of 10 points: \( 10 \times 0.32 \approx 3 \) misses. Click "New Data" several times — you'll see the count fluctuate around 2–4.
You run the experiment and find that 0 out of 10 error bars contain the theoretical curve \( d = \frac{1}{2}(9.8)\,t^2 \). What is the most likely explanation?
Explanation: The probability of 0 out of 10 error bars containing the true value (at 1σ) is \( (0.32)^{10} \approx 0.00001 \) — essentially impossible from random noise alone. When all points are off in the same direction, a systematic error (e.g., a miscalibrated timer, air resistance) is almost certainly to blame.

Extracting \( g \) from Your Data

The ultimate goal: fit \( d = \tfrac{1}{2}g\,t^2 \) to your data and extract the acceleration due to gravity. The explorer performs a least-squares fit (minimising the sum of squared residuals weighted by the error bars) and reports \( g_{\text{fit}} \). Is it consistent with 9.8? That depends on the uncertainty.

Key Insight

A single number is never the answer — the answer is always a number plus its uncertainty. Reporting \( g = 9.7 \) is meaningless; reporting \( g = 9.7 \pm 0.3 \;\text{m/s}^2 \) tells us the measurement is consistent with the known value 9.8. The complete workflow (data → statistics → error bars → fit → interpretation) is how real experimental physics works.

Python Code

Here's how to run Galileo's experiment computationally.

Python 

import numpy as np
import plotly.graph_objects as go

# Physical constants
g_true = 9.8          # m/s^2
times = np.arange(1, 11)  # t = 1, 2, ..., 10 seconds
d_true = 0.5 * g_true * times**2

# Experiment parameters
N_trials = 10         # measurements per time point
noise_pct = 0.20      # 20% relative noise

# Generate noisy measurements
rng = np.random.default_rng(42)
data = np.zeros((len(times), N_trials))
for i, t in enumerate(times):
    sigma = noise_pct * d_true[i]
    data[i, :] = d_true[i] + rng.normal(0, sigma, N_trials)

# Compute statistics at each time point
means = data.mean(axis=1)
stds  = data.std(axis=1, ddof=1)       # Bessel's correction
errors = stds / np.sqrt(N_trials - 1)  # standard error

# Plot all individual measurements
fig = go.Figure()
for j in range(N_trials):
    fig.add_trace(go.Scatter(
        x=times, y=data[:, j], mode='markers',
        marker=dict(size=4, color='rgba(0,243,255,0.3)'),
        showlegend=(j == 0),
        name='Individual trials' if j == 0 else None
    ))

# Overlay means with error bars
fig.add_trace(go.Scatter(
    x=times, y=means, mode='markers',
    error_y=dict(type='data', array=errors, visible=True,
                 color='#ffff00'),
    marker=dict(size=10, color='#ffff00', symbol='diamond'),
    name='Mean ± SE'
))

# Overlay theoretical curve
t_fine = np.linspace(0, 11, 200)
fig.add_trace(go.Scatter(
    x=t_fine, y=0.5 * g_true * t_fine**2,
    mode='lines', line=dict(color='#ff00ff', width=2),
    name='Theory: d = ½(9.8)t²'
))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Time (s)', range=[0, 11],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080'),
    yaxis=dict(title='Distance (m)', range=[0, 600],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080')
)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# Regenerate the dataset (same as Tab 1) so this script runs standalone
g_true = 9.8
times = np.arange(1, 11)
d_true = 0.5 * g_true * times**2
N_trials, noise_pct = 10, 0.20
rng = np.random.default_rng(42)
data = np.zeros((len(times), N_trials))
for i, t in enumerate(times):
    data[i, :] = d_true[i] + rng.normal(0, noise_pct * d_true[i], N_trials)
means = data.mean(axis=1)
stds = data.std(axis=1, ddof=1)
errors = stds / np.sqrt(N_trials - 1)

# Weighted least-squares fit for g
# Model: d = (g/2) * t^2  =>  g = 2d/t^2
# Weighted average: g_fit = sum(w_i * g_i) / sum(w_i)
# where g_i = 2*mean_i / t_i^2 and w_i = 1/sigma_g_i^2

g_estimates = 2 * means / times**2
sigma_g = 2 * errors / times**2           # error propagation
weights = 1.0 / sigma_g**2
g_fit = np.sum(weights * g_estimates) / np.sum(weights)
g_unc = 1.0 / np.sqrt(np.sum(weights))    # combined uncertainty

print(f"g_fit = {g_fit:.3f} ± {g_unc:.3f} m/s²")
print(f"|g_fit - 9.8| = {abs(g_fit - 9.8):.3f} m/s²")
print(f"Deviation in σ: {abs(g_fit - 9.8)/g_unc:.1f}")

# Plot: data + fit + true
fig = go.Figure()
fig.add_trace(go.Scatter(
    x=times, y=means, mode='markers',
    error_y=dict(type='data', array=errors, visible=True,
                 color='#ffff00'),
    marker=dict(size=10, color='#ffff00', symbol='diamond'),
    name='Data (mean ± SE)'
))

t_fine = np.linspace(0, 11, 200)
fig.add_trace(go.Scatter(
    x=t_fine, y=0.5 * g_fit * t_fine**2,
    mode='lines', line=dict(color='#00ff9f', width=2.5),
    name=f'Fit: g = {g_fit:.2f}'
))
fig.add_trace(go.Scatter(
    x=t_fine, y=0.5 * 9.8 * t_fine**2,
    mode='lines', line=dict(color='#ff00ff', width=2, dash='dash'),
    name='True: g = 9.80'
))

fig.update_layout(
    template='plotly_dark',
    title=f'g = {g_fit:.3f} ± {g_unc:.3f} m/s²',
    xaxis=dict(title='Time (s)', range=[0, 11],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080'),
    yaxis=dict(title='Distance (m)', range=[0, 600],
               gridcolor='#2a2f4a', zerolinecolor='#808080',
               linecolor='#808080')
)
fig.show()
Prompt for AI 

Simulate Galileo's free-fall experiment in Python with Plotly.

Setup:
- True g = 9.8 m/s², distance d = (1/2)g*t²
- 10 time points: t = 1, 2, ..., 10 seconds
- N repeated measurements at each time point
- Each measurement has Gaussian noise: σ = noise% × d_true(t)

Steps:
1. Generate N noisy measurements at each of 10 time points
2. Compute mean and standard error (s/√(N-1)) at each point
3. Plot all individual measurements as small dots (cyan, 30% opacity)
4. Overlay means with error bars (yellow diamonds)
5. Overlay theoretical curve d = (1/2)(9.8)t² (magenta line)
6. Fit g using weighted least-squares: g_i = 2*mean_i/t_i²
7. Report g_fit ± uncertainty and whether it's consistent with 9.8

Use dark theme, gray axes (#808080), fixed ranges: x=[0,11], y=[0,600].
Tips for Prompting
  • Specify the physics model explicitly — don't assume the AI knows
  • Be precise about noise model (Gaussian, relative vs absolute)
  • Ask for both the plot and numerical output
  • Iterate: adjust N and noise% to explore different scenarios
