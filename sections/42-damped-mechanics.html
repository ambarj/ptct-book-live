Mechanical Oscillators with Damping

In Section 4.8 you solved an LCR circuit and discovered that a single parameter \( w = L/(R^2C) \) controls everything. Now consider the mechanical version: a mass on a spring with friction. Non-dimensionalization reveals something remarkable — the same equation, the same code, the same solver applies to both systems.

Learning Objectives
  • Solve the damped spring-mass system numerically and compare with exact solutions
  • Verify the mechanical-electrical analogy computationally (same \( w \), same curves)
  • Discover Euler's method limitations for oscillatory systems (energy drift, phase error)

Damped spring-mass:

$$ m\ddot{x} + b\dot{x} + kx = 0 $$

Non-dimensionalize with \( \tau = t \cdot b/m \), and the equation becomes \( \ddot{x} + \dot{x} + wx = 0 \) with \( w = km/b^2 \) — identical to the LCR equation with \( w = L/(R^2C) \).

One Equation Rules Them All

Every second-order linear system with damping — springs, circuits, pendulums, acoustic resonators — reduces to \( \ddot{y} + \dot{y} + wy = 0 \) after non-dimensionalization. Master one, and you've mastered them all. Your Euler solver doesn't care whether \( y \) is charge, displacement, or angle.

Explorer 3: Euler's Limits

Euler's method is first-order accurate: errors grow with step size. For oscillatory systems, this manifests as energy drift — the numerical solution gains or loses energy that the real system conserves (or dissipates smoothly).

Which statements about Euler's method for oscillatory systems are correct? (Select all that apply)
Explanation:
  • Conserves energy: False — Euler systematically adds energy to oscillators. This was demonstrated in Section 3.12 and is visible in the energy drift plot.
  • Adds energy: True — forward Euler overshoots at each step, causing the numerical orbit to spiral outward.
  • Higher frequency needs smaller h: True — more steps per oscillation period are needed to track the curve accurately.
  • RK is better: True — RK2 has O(h²) error and RK4 has O(h&sup4;), allowing much larger step sizes for the same accuracy.

Python Implementation

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler_system(f, y0, t_max, h):
    """Vector Euler solver."""
    t = [0.0]
    Y = [np.array(y0, dtype=float)]
    y = np.array(y0, dtype=float)
    for _ in range(int(t_max / h)):
        y = y + h * np.array(f(y, t[-1]))
        t.append(t[-1] + h)
        Y.append(y.copy())
    return np.array(t), np.array(Y)

# Physical parameters
m, k, b = 1.0, 4.0, 1.0
w = k * m / b**2  # non-dimensional parameter

# Non-dimensional system: dy1/dt = y2, dy2/dt = -w*y1 - y2
def damped(y, t):
    return [y[1], -w * y[0] - y[1]]

t, Y = euler_system(damped, [1.0, 0.0], 15, 0.01)

# Exact solution (underdamped)
beta = np.sqrt(w - 0.25)
x_exact = np.exp(-t/2) * (np.cos(beta*t) + np.sin(beta*t)/(2*beta))

fig = make_subplots(rows=1, cols=2,
    subplot_titles=[f'x(t) — w={w:.1f}', 'Phase Portrait'])
fig.add_trace(go.Scatter(x=t, y=Y[:,0], name='Euler',
    line=dict(color='#00f3ff', width=2)), row=1, col=1)
fig.add_trace(go.Scatter(x=t, y=x_exact, name='Exact',
    line=dict(color='#808080', dash='dash', width=2)), row=1, col=1)
fig.add_trace(go.Scatter(x=Y[:,0], y=Y[:,1], name='(x, v)',
    line=dict(color='#00ff9f', width=2)), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler_system(f, y0, t_max, h):
    t = [0.0]
    Y = [np.array(y0, dtype=float)]
    y = np.array(y0, dtype=float)
    for _ in range(int(t_max / h)):
        y = y + h * np.array(f(y, t[-1]))
        t.append(t[-1] + h)
        Y.append(y.copy())
    return np.array(t), np.array(Y)

# Same w for both systems
w = 5.0

# Mechanical: m=1 kg, k=5 N/m, b=1 Ns/m → w = 5*1/1 = 5
# Electrical: L=5 mH, R=1 Ω, C=1 mF → w = 0.005/(1*0.001) = 5
def system(y, t):
    return [y[1], -w * y[0] - y[1]]

t, Y = euler_system(system, [1.0, 0.0], 15, 0.01)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Mechanical: x(t)', 'Electrical: Q(t)'])

# Same data, different labels!
fig.add_trace(go.Scatter(x=t, y=Y[:,0], name='Displacement',
    line=dict(color='#00f3ff', width=2)), row=1, col=1)
fig.add_trace(go.Scatter(x=t, y=Y[:,0], name='Charge',
    line=dict(color='#ff00ff', width=2)), row=1, col=2)

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='τ (mech)', linecolor='#808080'),
    xaxis2=dict(title='τ (elec)', linecolor='#808080'))
fig.show()

print(f"Both curves are identical — same w = {w}")
