Importance Sampling (Optional)

Uniform sampling treats all regions equally — but most integrands are not uniform. If the function is peaked in one region, most uniform samples land where the function is small, contributing little to the estimate. Importance sampling fixes this: sample more where the integrand is large, then reweight to correct for the bias. The result: dramatically lower variance for the same number of samples.

Learning Objectives
  • Understand why uniform sampling is inefficient for peaked integrands
  • Implement importance sampling: sample from \( p(x) \), estimate \( I = \frac{1}{N}\sum \frac{f(x_i)}{p(x_i)} \)
  • See that the optimal \( p(x) \propto |f(x)| \) minimizes variance
  • Compare variance reduction between uniform and importance sampling

Importance Sampling Formula:

$$ I = \int_a^b f(x)\,dx = \int_a^b \frac{f(x)}{p(x)}\,p(x)\,dx \approx \frac{1}{N}\sum_{i=1}^{N} \frac{f(x_i)}{p(x_i)}, \qquad x_i \sim p(x) $$

Instead of sampling \( x_i \) uniformly, draw them from a proposal distribution \( p(x) \). The ratio \( f(x)/p(x) \) corrects for the non-uniform sampling. When \( p(x) \propto |f(x)| \), the ratio is nearly constant and the variance is minimized.

The Intuition

Imagine searching for a needle in a haystack. Uniform sampling checks random locations — most searches find nothing. Importance sampling uses a metal detector (the proposal distribution \( p(x) \)) to focus the search where the needle is likely to be. You still need random samples, but you concentrate them where they count.

Look at the importance sampling result for the same peaked function. How does the convergence compare?
Explanation: Importance sampling concentrates samples near the peak, so every sample contributes meaningfully. The variance is dramatically reduced — often by a factor of 10–100×. The convergence plot shows the importance sampling estimate (green) settling much faster than uniform (cyan).
Why can’t you use the optimal \( p(x) \propto |f(x)| \) in practice?
Explanation: To sample from \( p(x) \propto |f(x)| \) you must first normalize it, which means dividing by \( \int|f| \) — and that integral is exactly the quantity you set out to compute. It’s a chicken-and-egg trap: the perfect proposal already contains the answer. So in practice you pick a proposal whose shape merely resembles \( |f(x)| \) (a Gaussian near the peak, say), which slashes the variance without needing the answer up front.

What is the key practical rule for choosing a proposal distribution?
Explanation: The danger is when \( p(x) \to 0 \) but \( f(x) \) is large — the ratio \( f/p \to \infty \). To prevent this, \( p(x) \) should have heavier tails than \( f(x) \): it’s better to slightly oversample the tails than to miss the peak entirely. A broader proposal is safer than a narrower one.

import numpy as np
import plotly.graph_objects as go

# Integrand: peaked Gaussian
f = lambda x: np.exp(-10*(x - 0.7)**2)
from scipy.special import erf
true_val = 0.5*np.sqrt(np.pi/10)*(erf(np.sqrt(10)*0.3) + erf(np.sqrt(10)*0.7))  # ≈ 0.5096

N = 5000

# Method 1: Uniform sampling
x_unif = np.random.uniform(0, 1, N)
est_unif = np.mean(f(x_unif))

# Method 2: Importance sampling with Gaussian proposal
mu, sigma = 0.7, 0.22
x_is = np.random.normal(mu, sigma, N)
# Keep only samples in [0, 1]
mask = (x_is >= 0) & (x_is <= 1)
x_is = x_is[mask]

# Proposal density (truncated Gaussian)
from scipy.stats import norm
p_is = norm.pdf(x_is, mu, sigma)
# Normalize for [0,1] truncation
Z = norm.cdf(1, mu, sigma) - norm.cdf(0, mu, sigma)
p_is /= Z

weights = f(x_is) / p_is
est_is = np.mean(weights)

print(f'Uniform:    {est_unif:.5f} ± {np.std(f(x_unif))/np.sqrt(N):.5f}')
print(f'Importance: {est_is:.5f} ± {np.std(weights)/np.sqrt(len(x_is)):.5f}')
print(f'True value: {true_val:.5f}')
print(f'Variance reduction: {np.var(f(x_unif))/np.var(weights):.1f}×')
Python 

import numpy as np
import plotly.graph_objects as go

f = lambda x: np.exp(-10*(x - 0.7)**2)

# Compare variance over 500 trials
n_trials, N = 500, 1000
unif_ests, is_ests = [], []

for _ in range(n_trials):
    # Uniform
    x = np.random.uniform(0, 1, N)
    unif_ests.append(np.mean(f(x)))

    # Importance (Gaussian at peak)
    x = np.clip(np.random.normal(0.7, 0.22, N), 0.001, 0.999)
    p = np.exp(-0.5*((x-0.7)/0.22)**2) / (0.22*np.sqrt(2*np.pi))
    is_ests.append(np.mean(f(x) / p))

fig = go.Figure()
fig.add_trace(go.Histogram(x=unif_ests, opacity=0.6,
    marker_color='#00f3ff', name='Uniform', nbinsx=30))
fig.add_trace(go.Histogram(x=is_ests, opacity=0.6,
    marker_color='#00ff88', name='Importance', nbinsx=30))

ratio = np.var(unif_ests) / np.var(is_ests)
fig.update_layout(
    template='plotly_dark',
    title=f'Variance reduction: {ratio:.0f}×',
    xaxis=dict(title='Estimate', zerolinecolor='#808080'),
    yaxis=dict(title='Count', zerolinecolor='#808080'),
    barmode='overlay', height=450, width=600)
fig.show()
