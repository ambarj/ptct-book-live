Biased Walks & Drift (Optional)

What happens when the coin is loaded? If \( p > 1/2 \), the walker drifts rightward at rate \( v = p - q \) per step. But diffusion still spreads the cloud at rate \( \sqrt{N} \). These two effects compete: drift is linear in N, diffusion is \( \sqrt{N} \). At long times, drift always wins — the signal-to-noise ratio grows as \( \sqrt{N} \).

Learning Objectives
  • Understand the biased walk: mean \( \langle x \rangle = N(p-q) \) (drift) and std \( \sigma = 2\sqrt{Npq} \) (spread)
  • See the competition: drift grows as N, spread grows as \( \sqrt{N} \) — drift eventually dominates
  • Compute the signal-to-noise ratio SNR \( = \langle x \rangle / \sigma = \sqrt{N}(p-q)/\sqrt{pq} \propto \sqrt{N} \)
  • Connect to physics: charged particles in fields, sedimentation, biased diffusion

Biased Walk Statistics:

$$ \langle x_N \rangle = N(p - q), \qquad \sigma = 2\sqrt{Npq}, \qquad \text{SNR} = \frac{\langle x \rangle}{\sigma} = \frac{(p-q)\sqrt{N}}{2\sqrt{pq}} $$

The SNR grows as \( \sqrt{N} \): with more steps, the drift becomes increasingly detectable above the noise. After \( N \sim (pq)/(p-q)^2 \) steps, SNR ≈ 1 and the drift first becomes visible.

Explorer: Drift vs Diffusion Race

Watch the competition unfold. The drift (yellow dashed line) grows linearly. The diffusion cloud (cyan band) grows as \( \sqrt{N} \). At short times, noise dominates; at long times, the drift pulls the cloud away from zero.

When Does Drift Become Visible?

The drift is “visible” when SNR ≈ 1, i.e., \( N \sim 4pq/(p-q)^2 \). For a slight bias p = 0.51: \( N \sim 4 \times 0.51 \times 0.49 / 0.02^2 \approx 2500 \) steps. For strong bias p = 0.7: \( N \sim 4 \times 0.21 / 0.16 \approx 5 \) steps. Stronger bias needs fewer steps to detect.

Python Code

Python 

import numpy as np
import plotly.graph_objects as go

p, N_max = 0.55, 1000
q = 1 - p
n = np.arange(1, N_max + 1)

drift = n * (2*p - 1)
spread = 2 * np.sqrt(n * p * q)

fig = go.Figure()
# Drift ± spread envelope
fig.add_trace(go.Scatter(x=n, y=drift + spread, mode='lines',
    line=dict(color='rgba(0,243,255,0.3)', width=0), showlegend=False))
fig.add_trace(go.Scatter(x=n, y=drift - spread, mode='lines',
    line=dict(color='rgba(0,243,255,0.3)', width=0),
    fill='tonexty', fillcolor='rgba(0,243,255,0.15)', name='±1σ band'))
fig.add_trace(go.Scatter(x=n, y=drift, mode='lines',
    line=dict(color='#ffbe0b', width=2.5), name=f'Drift: N×{2*p-1:.2f}'))

# A few sample walks
for w in range(5):
    steps = np.where(np.random.random(N_max) < p, 1, -1)
    fig.add_trace(go.Scatter(y=np.cumsum(steps), mode='lines',
        line=dict(color='#00f3ff', width=0.8), opacity=0.4, showlegend=False))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Steps N', zerolinecolor='#808080'),
    yaxis=dict(title='Position', zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

N = np.arange(1, 2001)
fig = go.Figure()

for p, color in [(0.51, '#00f3ff'), (0.55, '#ffbe0b'),
                  (0.6, '#ff006e'), (0.7, '#00ff88')]:
    q = 1 - p
    snr = (p - q) * np.sqrt(N) / (2 * np.sqrt(p * q))
    fig.add_trace(go.Scatter(x=N, y=snr, mode='lines',
        line=dict(color=color, width=2), name=f'p={p}'))

# SNR = 1 and 3 reference lines
fig.add_trace(go.Scatter(x=[0, 2000], y=[1, 1], mode='lines',
    line=dict(color='white', width=1, dash='dot'), name='SNR = 1'))
fig.add_trace(go.Scatter(x=[0, 2000], y=[3, 3], mode='lines',
    line=dict(color='white', width=1, dash='dash'), name='SNR = 3'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Steps N', zerolinecolor='#808080'),
    yaxis=dict(title='Signal-to-Noise Ratio', range=[0, 15],
        zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
