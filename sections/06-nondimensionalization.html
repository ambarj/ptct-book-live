Non-Dimensionalization: Making Physics Universal

Every physics problem hides a universal mathematical truth—buried under units of meters, kilograms, and seconds. Non-dimensionalization strips away this clutter to reveal the pure mathematics beneath. One dimensionless equation can describe every pendulum that ever swung, regardless of its mass, length, or what planet it's on.

Learning Objectives
  • Identify natural scales (length, time, energy) in physics problems
  • Transform dimensional equations into dimensionless form
  • Recognize that dimensionless solutions are universal—one plot covers all cases
  • Apply the "Define and Translate" stage of computational thinking

The Define → Translate Process

In the 4-step computational thinking approach, we follow: Define → Translate → Compute → Interpret. Non-dimensionalization is the heart of the first two steps:

  • Define: Identify all physical variables and their natural scales
  • Translate: Convert to dimensionless form by dividing by these scales
Why Non-Dimensionalize?

Consider the pendulum potential energy: \( V(\theta) = mg\ell(1 - \cos\theta) \). If you want to plot this, you need to pick values for \( m \), \( g \), and \( \ell \). But there are infinitely many combinations! Instead, define \( \bar{V} = V/(mg\ell) \), giving:

\( \bar{V}(\theta) = 1 - \cos\theta \)

This single curve describes ALL pendulums. One plot, infinite applicability.

Identifying Natural Scales

The key skill in non-dimensionalization is finding the natural scales. Every physics problem contains its own built-in measuring sticks:

For any physical quantity, find a combination of parameters with the same units:

  • Energy scale: Look for products like \( mg\ell \), \( \frac{1}{2}kx^2 \), \( \frac{1}{2}mv^2 \)
  • Length scale: Look for given lengths, or construct from \( v^2/g \), \( \sqrt{k/m} \cdot t \)
  • Time scale: Look for periods like \( \sqrt{\ell/g} \), \( \sqrt{m/k} \), \( v/g \)
⚠️
Dimensional Analysis Rule: You can only add or equate quantities with the same dimensions. If your scales have the wrong units, the resulting equations will be physically meaningless!

Explorer 2: Projectile on a Hill

A more complex example: A projectile is launched from height \( h \) above a hill with slope angle \( \phi \). It's launched at angle \( \theta \) with speed \( v \). Where does it land on the hill?

This problem has 5 dimensional parameters: \( \theta, \phi, v, h, g \). But we can reduce to 3 dimensionless parameters:

Dimensionless Parameters:

$$ \theta \text{ (launch angle)}, \quad \phi \text{ (hill slope)}, \quad \Gamma = \frac{gh}{v^2} \text{ (dimensionless height)} $$

The parameter \( \Gamma \) compares gravitational potential (\( gh \)) to kinetic energy (\( v^2 \)). Small \( \Gamma \) means high launch velocity; large \( \Gamma \) means gravity dominates.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# Physical parameters (these will vary)
m = 2.0   # mass (kg)

# Dimensionless potential (universal!)
V_bar = 1 - np.cos(theta)

# Create side-by-side comparison
fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Dimensional V(θ)', 'Dimensionless V̄(θ)'])

fig.add_trace(go.Scatter(
    x=theta * 180/np.pi, y=V_dim,
    mode='lines', line=dict(color='#00f3ff', width=2),
    name='V (Joules)'
), row=1, col=1)

fig.add_trace(go.Scatter(
    x=theta * 180/np.pi, y=V_bar,
    mode='lines', line=dict(color='#ff00ff', width=2),
    name='V̄ (dimensionless)'
), row=1, col=2)

fig.update_layout(
    template='plotly_dark',
    title=f'Pendulum Energy: m={m}kg, g={g}m/s², ℓ={l}m',

)

fig.update_xaxes(title_text='θ (degrees)', gridcolor='#2a2f4a')
fig.update_yaxes(gridcolor='#2a2f4a', zerolinecolor='#808080')

fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def projectile_on_hill(theta_deg, phi_deg, Gamma, n_points=100):
    """
    Compute dimensionless trajectory and find landing point.

    Parameters:
        theta_deg: Launch angle (degrees)
        phi_deg: Hill slope angle (degrees)
        Gamma: Dimensionless parameter gh/v²
        n_points: Number of trajectory points

    Returns:
        x_traj, y_traj: Trajectory coordinates (dimensionless)
        x_land, y_land: Landing point
    """
    theta = np.radians(theta_deg)
    phi = np.radians(phi_deg)

    # Trajectory: y = -Γx²/(2cos²θ) + x·tanθ + Γ
    # Hill: y = -x·tanφ + Γ
    # (using Γ as dimensionless starting height)

    # Find landing x by solving intersection
    # -Γx²/(2cos²θ) + x·tanθ + Γ = -x·tanφ + Γ
    # -Γx²/(2cos²θ) + x(tanθ + tanφ) = 0
    # x(-Γx/(2cos²θ) + tanθ + tanφ) = 0

    A = -Gamma / (2 * np.cos(theta)**2)
    B = np.tan(theta) + np.tan(phi)

    if abs(A) < 1e-10:
        x_land = 0
    else:
        x_land = -B / A  # x = 0 or x = -B/A

    x_land = max(0, x_land)  # Must be positive

    # Generate trajectory
    x_traj = np.linspace(0, x_land * 1.1, n_points)
    y_traj = A * x_traj**2 + np.tan(theta) * x_traj + Gamma

    # Hill line
    x_hill = np.linspace(0, x_land * 1.2, 50)
    y_hill = -np.tan(phi) * x_hill + Gamma

    # Landing point
    y_land = -np.tan(phi) * x_land + Gamma

    return x_traj, y_traj, x_hill, y_hill, x_land, y_land

# Example parameters
theta, phi, Gamma = 45, 20, 0.3

x_traj, y_traj, x_hill, y_hill, x_land, y_land = projectile_on_hill(theta, phi, Gamma)

fig = go.Figure()

# Trajectory
fig.add_trace(go.Scatter(
    x=x_traj, y=y_traj, mode='lines',
    line=dict(color='#00f3ff', width=2),
    name='Trajectory'
))

# Hill
fig.add_trace(go.Scatter(
    x=x_hill, y=y_hill, mode='lines',
    line=dict(color='#ffff00', width=2),
    name='Hill'
))

# Landing point
fig.add_trace(go.Scatter(
    x=[x_land], y=[y_land], mode='markers',
    marker=dict(color='#ff00ff', size=12),
    name='Landing'
))

fig.update_layout(
    template='plotly_dark',
    title=f'Projectile on Hill: θ={theta}°, φ={phi}°, Γ={Gamma}',
    xaxis=dict(title='x̄ (dimensionless)', gridcolor='#2a2f4a',
               scaleanchor='y', range=[-0.5, max(x_land*1.3, 2)]),
    yaxis=dict(title='ȳ (dimensionless)', gridcolor='#2a2f4a',
               range=[-0.5, Gamma*1.5]),
)

fig.show()

"""
General Non-Dimensionalization Workflow
"""

# Step 1: DEFINE - List all variables and their dimensions
variables = {
    'm': 'mass',        # [M]
    'g': 'acceleration', # [L/T²]
    'l': 'length',      # [L]
    'v': 'velocity',    # [L/T]
    't': 'time'         # [T]
}

# Step 2: IDENTIFY SCALES - Find combinations with correct units
scales = {
    'length': 'l or v²/g',
    'time': 'sqrt(l/g) or v/g',
    'energy': 'm*g*l or m*v²',
    'velocity': 'sqrt(g*l) or v'
}

# Step 3: TRANSLATE - Divide by scales
# x̄ = x / L_scale
# t̄ = t / T_scale
# V̄ = V / E_scale

# Step 4: COMPUTE - Solve the dimensionless equations
# These are universal - one solution fits all!

# Example: Damped Harmonic Oscillator
# Original: m*d²x/dt² = -k*x - b*dx/dt
# Variables: m, k, b, x, t (5 variables, 3 dimensions MLT)
# → 2 dimensionless parameters!

import numpy as np

# Natural scales
m, k, b = 1.0, 4.0, 0.5  # example values
omega_0 = np.sqrt(k/m)   # natural frequency
T_scale = 1/omega_0      # time scale
X_scale = 1.0            # arbitrary (set by initial conditions)

# Dimensionless damping parameter
zeta = b / (2 * np.sqrt(k * m))  # damping ratio

print(f"Natural frequency ω₀ = {omega_0:.3f} rad/s")
print(f"Time scale = {T_scale:.3f} s")
print(f"Damping ratio ζ = {zeta:.3f}")
print(f"System is: {'underdamped' if zeta < 1 else 'overdamped' if zeta > 1 else 'critically damped'}")
