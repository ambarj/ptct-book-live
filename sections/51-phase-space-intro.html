What is Phase Space?

In Chapter 3, we briefly saw that plotting \( (x, \dot{x}) \) turns oscillator motion into ellipses. That was a glimpse of something much deeper. Phase space is a geometric framework that lets you see every possible behavior of a system in a single picture — no equations to solve, no time axis needed.

Learning Objectives
  • Understand phase space: each point represents the complete state of a system
  • Read vector fields: arrows show where the system moves next
  • Trace trajectories: time evolution becomes a curve through phase space
  • Recognize the fundamental trajectory types: closed orbits, spirals, saddle paths

The idea is beautifully simple: if a system has two variables \( x \) and \( y \), then at any moment its state is a point \( (x, y) \). The differential equations \( \dot{x} = f(x,y) \) and \( \dot{y} = g(x,y) \) assign a velocity arrow to each point, telling the system where to go next. Follow the arrows, and you trace out a trajectory — the system's entire future (and past).

A 2D autonomous system:

$$ \dot{x} = f(x, y), \qquad \dot{y} = g(x, y) $$

At every point \( (x,y) \), the velocity vector is \( \bigl(f(x,y),\; g(x,y)\bigr) \). These arrows fill the plane — that's the vector field.

Why Phase Space?

A time-series plot of \( x(t) \) tells you what happens. A phase portrait tells you why — the geometry of the flow determines the dynamics. Once you learn to read phase portraits, you can predict qualitative behavior without solving a single equation.

  • Explicit time: FALSE — time is implicit in phase space. You lose the time axis but gain the inter-variable relationship.
  • Variable relationships: TRUE — you see how \( x \) and \( y \) relate to each other, which time-series plots cannot show directly.

The Phase Portrait: Many Trajectories, One Picture

A phase portrait is the complete collection of trajectories from all possible initial conditions. It's a map that tells you what happens no matter where the system starts. One of the most important properties: trajectories never cross. Why? Because at any point, the velocity is uniquely determined — the system can only go one direction. If two trajectories crossed, the system would face a choice at the intersection, violating the uniqueness theorem for differential equations.

Trajectories Never Cross!

This is a consequence of the uniqueness theorem for ODEs: if two trajectories met at a point, the system would have two different futures from the same state — impossible for a deterministic system. This constraint is what makes phase portraits so powerful.

Use the Trajectory Zoo above to answer these questions.

Why can two different trajectories never cross in phase space?
Explanation: The uniqueness theorem guarantees that given any initial condition, there is exactly one trajectory. If two trajectories met at a point \( (x^*, y^*) \), then that point would be an initial condition with two different futures — contradicting uniqueness. This applies to all autonomous systems, whether linear or nonlinear, conservative or dissipative.
Add several trajectories for each system type. Which system has trajectories that approach the origin along one direction but flee along another?
Explanation: The saddle point has this characteristic behavior: trajectories approach along one axis (the stable direction) and flee along the other (the unstable direction). This creates the distinctive hyperbolic portrait. In matrix language, the eigenvalues have opposite signs.
Which of the following can you determine from a phase portrait alone? (Select all that apply)
Explanation:
  • Periodic motion: TRUE — closed loops in phase space mean periodic motion.
  • Stability: TRUE — if trajectories converge to a fixed point, it's stable; if they diverge, it's unstable.
  • Exact orbit time: FALSE — phase portraits don't encode time directly. You need the equations to compute the period.
  • Dissipative: TRUE — spiraling inward means the system loses energy. Closed orbits mean energy is conserved.

import numpy as np
import plotly.figure_factory as ff

# Define the system: SHO (center)
# dx/dt = y,  dy/dt = -x
x = np.linspace(-4, 4, 20)
y = np.linspace(-4, 4, 20)
X, Y = np.meshgrid(x, y)
U = Y         # dx/dt = y
V = -X        # dy/dt = -x

# Create quiver (vector field) plot
fig = ff.create_quiver(X, Y, U, V,
    scale=0.15, arrow_scale=0.3,
    line=dict(color='#00f3ff', width=1))

fig.update_layout(
    template='plotly_dark',
    title='Phase Portrait: Simple Harmonic Oscillator',
    xaxis=dict(range=[-4, 4], title='x',
        zerolinecolor='#808080', linecolor='#808080',
        gridcolor='#2a2f4a'),
    yaxis=dict(range=[-4, 4], title='y = dx/dt',
        zerolinecolor='#808080', linecolor='#808080',
        gridcolor='#2a2f4a'),
    width=600, height=600
)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

def rk4_step(f, y, h):
    """Single RK4 step for system dy/dt = f(y)."""
    k1 = f(y)
    k2 = f(y + h/2 * k1)
    k3 = f(y + h/2 * k2)
    k4 = f(y + h * k3)
    return y + (h/6) * (k1 + 2*k2 + 2*k3 + k4)

# Stable spiral: dx/dt = -0.2x + y, dy/dt = -x - 0.2y
def f_spiral(y):
    return np.array([
        -0.2 * y[0] + y[1],
        -y[0] - 0.2 * y[1]
    ])

# Integrate from multiple ICs
fig = go.Figure()
colors = ['#00f3ff', '#ff006e', '#ffbe0b', '#00ff88']
ics = [(2, 0), (0, 2), (-2, 0), (0, -2)]

for ic, color in zip(ics, colors):
    y = np.array(ic, dtype=float)
    xs, ys = [y[0]], [y[1]]
    for _ in range(2000):
        y = rk4_step(f_spiral, y, 0.02)
        xs.append(y[0])
        ys.append(y[1])

    fig.add_trace(go.Scatter(
        x=xs, y=ys, mode='lines',
        line=dict(color=color, width=2),
        name=f'IC = {ic}'))

fig.update_layout(
    template='plotly_dark',
    title='Stable Spiral: Multiple Trajectories',
    xaxis=dict(range=[-3, 3], title='x',
        zerolinecolor='#808080', linecolor='#808080',
        gridcolor='#2a2f4a'),
    yaxis=dict(range=[-3, 3], title='y',
        zerolinecolor='#808080', linecolor='#808080',
        gridcolor='#2a2f4a'),
    width=600, height=600
)
fig.show()
