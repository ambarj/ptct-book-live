Automated Fitting: From Data to Physics

You've dragged sliders, swept parameters, and even played human optimizer. Now it's time to let the computer do the work. Automated fitting takes your data and model, minimises χ² in one shot, and hands you the best-fit parameters with uncertainties. This is the workhorse of experimental physics: from data to a number like \( g = 9.81 \pm 0.03 \; \text{m/s}^2 \).

Learning Objectives
  • Run an automated fit and interpret the output (parameters + uncertainties)
  • Extract a physical constant (\( g \)) from a fit coefficient
  • Understand what parameter uncertainties mean through repeated experiments
  • Use residual analysis to check whether a model is adequate

The fitting workflow:

$$ \text{Data} \; (t_i, d_i \pm \sigma_i) \;\xrightarrow{\text{minimise } \chi^2}\; \text{Parameters} \; (a \pm \delta a, \; b \pm \delta b, \; c \pm \delta c) \;\xrightarrow{\text{physics}}\; g = 2c \pm 2\delta c $$

The fitting algorithm finds the parameters that minimise χ². The covariance matrix gives uncertainties \( \delta a, \delta b, \delta c \). Physics maps the fit coefficient \( c \) to the acceleration \( g = 2c \).

Key Insight

Adding parameters always reduces χ² (or leaves it unchanged), because the simpler model is a special case of the more complex one (with extra parameters set to zero). But the improvement may be tiny. If going from 1-param to 3-param barely changes χ², the extra parameters aren't justified — they're just fitting noise. We'll formalise this in Section 2.8 (Model Selection).

From Fit Coefficient to Physical Constant

The fit gives \( c \pm \delta c \). Physics says \( g = 2c \), so \( g = 2c \pm 2\delta c \). But what does the uncertainty \( \delta g \) actually mean? This explorer runs many independent experiments, fits each one, and builds a histogram of extracted \( g \) values. The spread of the histogram should match the uncertainty from a single fit.

Interactive: Extracting g from Many Experiments
Key Insight

Compare std(g) (the actual scatter of extracted values) with Typical δg (the uncertainty from a single fit's covariance matrix). They should be approximately equal. This is the deep meaning of "uncertainty": if you report \( g = 9.8 \pm 0.3 \), it means that repeating the experiment many times would give values scattered with a standard deviation of about 0.3.

Are the Residuals Random?

After fitting, always check the residuals: the differences \( r_i = d_i - f(t_i) \) between data and model. If the fit is good, residuals should scatter randomly around zero with no systematic pattern. If you see a trend — the model is missing something. Use the offset slider to add a "hidden" constant to the data and watch how a too-simple model produces patterned residuals.

Interactive: Residual Inspector
Key Insight

With offset = 0 and the 1-param model, residuals are random — the model is correct. Now set offset = 15 and keep the 1-param model. The residuals show a clear systematic pattern (positive at early times, negative at late times) because \( d = ct^2 \) can't capture a constant offset. Switch to the 3-param model and the pattern vanishes: the model now has \( a \) to absorb the offset. Always check residuals before trusting a fit.

For a good fit (correct model, correct error bars), χ²/dof should be approximately:

χ²/dof ≈
Explanation
Each term \( (r_i/\sigma_i)^2 \) has an expected value of about 1 if the model is correct and errors are Gaussian. Summing \( N \) terms and subtracting the number of fitted parameters gives \( \langle\chi^2\rangle = N_{\text{dof}} \), so \( \chi^2/N_{\text{dof}} \approx 1 \). Values much larger than 1 signal a bad fit or underestimated errors.

Python Code

Here's the Python equivalent using scipy.optimize.curve_fit.

Python 
import numpy as np
from scipy.optimize import curve_fit
import plotly.graph_objects as go

# Galileo's data
g_true = 9.8
times = np.arange(1, 11, dtype=float)
d_true = 0.5 * g_true * times**2

# Noisy measurements (5 trials, 15% relative noise)
rng = np.random.default_rng(42)
data = np.array([d_true + rng.normal(0, 0.15*d_true)
                 for _ in range(5)])
means = data.mean(axis=0)
errors = data.std(axis=0, ddof=1) / np.sqrt(4)

# Define the model
def model(t, a, b, c):
    return a + b*t + c*t**2

# Fit with curve_fit (sigma = standard errors)
popt, pcov = curve_fit(model, times, means,
                       sigma=errors, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))

print("Fit results:")
print(f"  a = {popt[0]:.2f} ± {perr[0]:.2f}")
print(f"  b = {popt[1]:.3f} ± {perr[1]:.3f}")
print(f"  c = {popt[2]:.4f} ± {perr[2]:.4f}")
print(f"  g = 2c = {2*popt[2]:.2f} ± {2*perr[2]:.2f}")

# Compute χ²
residuals = means - model(times, *popt)
chi2 = np.sum((residuals / errors)**2)
dof = len(times) - 3
print(f"  χ²/dof = {chi2:.1f}/{dof} = {chi2/dof:.2f}")
Python 
import numpy as np
from scipy.optimize import curve_fit

# Run 200 independent experiments
g_values = []
for _ in range(200):
    data = np.array([0.5*9.8*t**2 + np.random.normal(0, 0.15*0.5*9.8*t**2)
                     for t in range(1, 11)])
    # Single-trial: error = noise level
    errs = 0.15 * 0.5 * 9.8 * np.arange(1,11)**2

    def quad(t, a, b, c):
        return a + b*t + c*t**2

    popt, pcov = curve_fit(quad, np.arange(1,11, dtype=float),
                           data, sigma=errs, absolute_sigma=True)
    g_values.append(2 * popt[2])

g_arr = np.array(g_values)
print(f"True g:     {9.8}")
print(f"Mean g:     {g_arr.mean():.3f}")
print(f"Std(g):     {g_arr.std():.3f}")
print(f"Expected δg: ~{2*np.sqrt(pcov[2,2]):.3f}")
print(f"Std ≈ δg?   {'Yes!' if abs(g_arr.std() - 2*np.sqrt(pcov[2,2])) < 0.5 else 'Close'}")

Tips for Prompting
  • Always specify absolute_sigma=True — without it, curve_fit rescales errors and uncertainties are wrong

  • Request the covariance matrix explicitly if you want correlations
