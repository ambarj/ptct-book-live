Error Bars in Fitting: Where Do They Come From?

You've used curve_fit and seen results like \( c = 4.91 \pm 0.03 \). But where does that \( \pm 0.03 \) come from? It's not magic — it comes from the covariance matrix, which encodes how uncertain each parameter is and how they're correlated. This section opens the hood on fitting uncertainties.

Learning Objectives
  • Read and interpret the covariance matrix from a fit
  • Understand parameter correlations and confidence ellipses
  • Propagate fit uncertainties to derived quantities (\( g = 2c \pm 2\delta c \))
  • Use bootstrap resampling as an independent check on uncertainties

The covariance matrix:

$$ \text{Cov} = \begin{pmatrix} \sigma_a^2 & \text{Cov}(a,b) & \text{Cov}(a,c) \\ \text{Cov}(b,a) & \sigma_b^2 & \text{Cov}(b,c) \\ \text{Cov}(c,a) & \text{Cov}(c,b) & \sigma_c^2 \end{pmatrix} $$

The diagonal gives parameter variances: \( \delta a = \sqrt{\sigma_a^2} \). Off-diagonal elements reveal correlations: if \( \text{Cov}(a,c) < 0 \), increasing \( a \) tends to decrease \( c \).

Inside the Covariance Matrix

The left panel shows the raw covariance matrix — numbers are hard to interpret, so the right panel shows the correlation matrix \( \rho_{ij} = \text{Cov}(i,j) / (\sigma_i \sigma_j) \), which ranges from −1 (perfectly anti-correlated) to +1 (perfectly correlated). Toggle absolute_sigma to see what happens when you let curve_fit rescale the error bars.

Interactive: Covariance Explorer
Key Insight

With absolute_sigma=True (the correct setting when you trust your error bars), the covariance matrix comes from inverting the normal equations matrix: Cov = M−1. With absolute_sigma=False, Python rescales by χ²/dof, which means it ignores your error bars and estimates uncertainties from the scatter alone. Always use absolute_sigma=True when you have genuine error estimates.

Confidence Regions in Parameter Space

Parameter uncertainties are not independent — the covariance matrix defines an ellipse in parameter space. The left panel shows the 1σ and 2σ confidence ellipses for \( (b, c) \). If the ellipse is tilted, the parameters are correlated. Yellow dots are results from repeated independent experiments — about 39% should fall inside the 1σ ellipse (it's a 2D region, so 39% not 68%).

Interactive: Confidence Ellipse
Key Insight

The ellipse is tilted because \( b \) and \( c \) are anti-correlated. If the noise pushes \( c \) up, the fit compensates by pulling \( b \) down (and vice versa). This is why reporting \( \delta b \) and \( \delta c \) separately overstates the uncertainty — the parameters can't vary independently. The ellipse captures the full picture. Note that ∼39% of yellow dots fall in the 1σ ellipse, not 68% — for a 2D Gaussian, the 1σ ellipse contains \( 1 - e^{-1/2} \approx 39\% \) of the probability.

Bootstrap: A Second Opinion on Uncertainties

The covariance matrix assumes your model is correct and errors are Gaussian. Bootstrapping is a model-free alternative: resample your data with replacement, refit each resample, and look at the scatter of fitted parameters. The bootstrap standard deviation should match the covariance matrix uncertainty — if it doesn't, something is wrong with your assumptions.

What does "resample with replacement" mean in bootstrapping?
Explanation
Bootstrapping draws N data points from the original N, with replacement. This means some original points appear multiple times in a resample while others are missing. Each resample is the same size as the original dataset but has a different composition. Fitting each resample gives a different set of parameters, and the scatter of these parameters estimates the uncertainty.
The stats show "Covariance δ" and "Bootstrap δ". When do these two methods agree?
Explanation
The covariance matrix assumes the model is correct and errors are Gaussian. Bootstrapping makes no such assumptions. When both give similar uncertainties, it means the covariance matrix assumptions are satisfied. If bootstrap gives much larger uncertainties, the model may be wrong (systematic errors) or the error bars may be underestimated.

Python Code

Here's the Python equivalent for covariance analysis and bootstrapping.

Python 
import numpy as np
from scipy.optimize import curve_fit

# Galileo data
rng = np.random.default_rng(42)
t = np.arange(1, 11, dtype=float)
d_true = 0.5 * 9.8 * t**2
noise = 0.15 * d_true
data = np.array([d_true + rng.normal(0, noise) for _ in range(5)])
means = data.mean(axis=0)
errors = data.std(axis=0, ddof=1) / np.sqrt(4)

def model(t, a, b, c):
    return a + b*t + c*t**2

# Fit with absolute_sigma=True
popt, pcov = curve_fit(model, t, means,
                       sigma=errors, absolute_sigma=True)

print("Covariance matrix:")
print(np.array2string(pcov, precision=4))

# Correlation matrix
perr = np.sqrt(np.diag(pcov))
corr = pcov / np.outer(perr, perr)
print("\nCorrelation matrix:")
print(np.array2string(corr, precision=3))

# Parameter uncertainties
print(f"\na = {popt[0]:.2f} ± {perr[0]:.2f}")
print(f"b = {popt[1]:.3f} ± {perr[1]:.3f}")
print(f"c = {popt[2]:.4f} ± {perr[2]:.4f}")
print(f"g = {2*popt[2]:.2f} ± {2*perr[2]:.2f}")
Python 
import numpy as np
from scipy.optimize import curve_fit

# Setup (same data as above)
rng = np.random.default_rng(42)
t = np.arange(1, 11, dtype=float)
d_true = 0.5 * 9.8 * t**2
noise = 0.15 * d_true
data = np.array([d_true + rng.normal(0, noise) for _ in range(5)])
means = data.mean(axis=0)
errors = data.std(axis=0, ddof=1) / np.sqrt(4)

def model(t, a, b, c):
    return a + b*t + c*t**2

# Original fit
popt, pcov = curve_fit(model, t, means,
                       sigma=errors, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))

# Bootstrap: resample with replacement
n_boot = 500
boot_params = []
for _ in range(n_boot):
    idx = rng.choice(len(t), size=len(t), replace=True)
    t_boot = t[idx]
    m_boot = means[idx]
    e_boot = errors[idx]
    try:
        p, _ = curve_fit(model, t_boot, m_boot,
                         sigma=e_boot, absolute_sigma=True)
        boot_params.append(p)
    except RuntimeError:
        pass

boot_params = np.array(boot_params)
boot_std = boot_params.std(axis=0)

print("          Covariance  Bootstrap")
for i, name in enumerate(['a', 'b', 'c']):
    print(f"  δ{name}:   {perr[i]:.4f}      {boot_std[i]:.4f}")
print(f"\n  δg:   {2*perr[2]:.4f}      {2*boot_std[2]:.4f}")
