Damped Harmonic Oscillator Revisited

In Chapter 3 you met the damped oscillator and learned that it has three regimes: underdamped, critically damped, and overdamped. Now you have the tools to see why. The oscillator is a 2D linear system, and its three regimes map directly onto three regions of the τ-Δ plane. Phase space makes the physics visible.

Learning Objectives
  • Write the damped oscillator \( m\ddot{x} + b\dot{x} + kx = 0 \) as a 2D linear system and identify its matrix
  • Compute \( \tau = -b/m \) and \( \Delta = k/m \), and locate the oscillator on the τ-Δ plane
  • Connect the three damping regimes (underdamped, critical, overdamped) to the node-spiral boundary \( \tau^2 = 4\Delta \)
  • Watch energy dissipation in phase space as trajectories spiral (or slide) toward the origin

The Oscillator as a Linear System:

$$ m\ddot{x} + b\dot{x} + kx = 0 \quad\Longrightarrow\quad \begin{pmatrix} \dot{x} \\ \dot{v} \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ -k/m & -b/m \end{pmatrix} \begin{pmatrix} x \\ v \end{pmatrix} $$

Trace: \( \tau = 0 + (-b/m) = -b/m \leq 0 \).   Determinant: \( \Delta = (0)(-b/m) - (1)(-k/m) = k/m > 0 \).

Since \( \tau \leq 0 \) and \( \Delta > 0 \), the oscillator always lives in the left half of the τ-Δ plane, above the Δ = 0 axis. It can never be a saddle or unstable!

The Three Regimes on the τ-Δ Plane

The oscillator sits at \( (\tau, \Delta) = (-b/m,\; k/m) \). Changing \( b \) moves the point horizontally (more damping → more negative τ). The parabola \( \tau^2 = 4\Delta \) is the boundary:

  • Inside the parabola (\( b^2 < 4mk \)): Underdamped — stable spiral, oscillations that decay
  • On the parabola (\( b^2 = 4mk \)): Critically damped — repeated eigenvalue, fastest non-oscillatory return
  • Outside the parabola (\( b^2 > 4mk \)): Overdamped — stable node, sluggish exponential decay

Trajectories are closed ellipses: the undamped simple harmonic oscillator conserves energy perfectly.
You need the system exactly critically damped at \( b = 2 \). Keeping \( m = 1 \), what spring constant \( k \) do you need? . (Set it and confirm the portrait sits right on the parabola.)
Explanation: Critical damping is the boundary where the discriminant vanishes: \( b^2 = 4mk \). Solving for \( k \) with \( b = 2 \) and \( m = 1 \) gives \( k = b^2 / (4m) = 4/4 = 1 \). At \( k = 1 \) the repeated eigenvalue is \( \lambda = -b/(2m) = -1 \), and the point lands exactly on the \( \tau^2 = 4\Delta \) parabola — the knife-edge between spiralling (underdamped) and non-oscillating (overdamped) decay.
Now increase damping to \( b = 6 \) (overdamped). How does the phase portrait differ from the underdamped case?
Explanation: With \( b = 6 > b_{\text{crit}} = 4 \), the eigenvalues are both real and negative. The system is a stable node: trajectories approach the origin along eigenvector directions without oscillating. The system is “too sluggish” to oscillate — damping overwhelms the restoring force.

Why Critical Damping is Special

Critical damping (\( b^2 = 4mk \)) gives the fastest return to equilibrium without oscillation. Underdamped systems oscillate (wasting time overshooting), while overdamped systems creep back slowly (too much friction). Critical damping is the sweet spot — the parabola boundary in the τ-Δ plane. This is why door closers, car suspensions, and galvanometers are designed to operate near critical damping.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(A, x0, T, N):
    h = T / N; x = np.array(x0, float)
    xs, ts = [x.copy()], [0.0]
    for i in range(N):
        f = lambda u: A @ u
        k1=f(x); k2=f(x+h/2*k1); k3=f(x+h/2*k2); k4=f(x+h*k3)
        x += h/6*(k1+2*k2+2*k3+k4)
        xs.append(x.copy()); ts.append((i+1)*h)
    return np.array(xs), np.array(ts)

m, k = 1.0, 4.0
b_crit = np.sqrt(4*m*k)  # = 4.0

fig = make_subplots(1, 2, subplot_titles=[
    'x(t) Time Series', 'Phase Portrait (x, v)'])

cases = [
    (0.5*b_crit, 'Underdamped', '#00f3ff'),
    (b_crit,     'Critical',    '#ffbe0b'),
    (1.5*b_crit, 'Overdamped',  '#ff006e'),
]

for b, label, color in cases:
    A = np.array([[0, 1], [-k/m, -b/m]])
    traj, t = rk4(A, [2.5, 0], 10, 2000)

    fig.add_trace(go.Scatter(
        x=t, y=traj[:,0], mode='lines',
        line=dict(color=color, width=2), name=label),
        row=1, col=1)
    fig.add_trace(go.Scatter(
        x=traj[:,0], y=traj[:,1], mode='lines',
        line=dict(color=color, width=1.5),
        showlegend=False), row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(title='Time', zerolinecolor='#808080', row=1, col=1)
fig.update_yaxes(title='x(t)', range=[-3, 3],
    zerolinecolor='#808080', row=1, col=1)
fig.update_xaxes(title='x', range=[-3, 3],
    zerolinecolor='#808080', row=1, col=2)
fig.update_yaxes(title='v', range=[-6, 6],
    zerolinecolor='#808080', scaleanchor='x2', row=1, col=2)

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(A, x0, T, N):
    h = T / N; x = np.array(x0, float)
    xs, ts = [x.copy()], [0.0]
    for i in range(N):
        f = lambda u: A @ u
        k1=f(x); k2=f(x+h/2*k1); k3=f(x+h/2*k2); k4=f(x+h*k3)
        x += h/6*(k1+2*k2+2*k3+k4)
        xs.append(x.copy()); ts.append((i+1)*h)
    return np.array(xs), np.array(ts)

m, k, b = 1.0, 4.0, 0.8
A = np.array([[0, 1], [-k/m, -b/m]])
traj, t = rk4(A, [2.5, 0], 15, 3000)

# Energy: E = 0.5*m*v² + 0.5*k*x²
E = 0.5*m*traj[:,1]**2 + 0.5*k*traj[:,0]**2

fig = make_subplots(1, 2, subplot_titles=[
    'Phase Space + Energy Contours', 'Energy E(t)'])

# Energy contours
for E_val in [1, 3, 6, 10, 15]:
    th = np.linspace(0, 2*np.pi, 200)
    xe = np.sqrt(2*E_val/k) * np.cos(th)
    ve = np.sqrt(2*E_val/m) * np.sin(th)
    fig.add_trace(go.Scatter(
        x=xe, y=ve, mode='lines',
        line=dict(color='rgba(100,100,100,0.3)', width=1),
        showlegend=False), row=1, col=1)

# Trajectory
fig.add_trace(go.Scatter(
    x=traj[:,0], y=traj[:,1], mode='lines',
    line=dict(color='#00f3ff', width=2), name='Trajectory'),
    row=1, col=1)

# Energy vs time
fig.add_trace(go.Scatter(
    x=t, y=E, mode='lines',
    line=dict(color='#ffbe0b', width=2), name='E(t)'),
    row=1, col=2)

# Exponential envelope
gamma = b / (2*m)
E_env = E[0] * np.exp(-2*gamma*t)
fig.add_trace(go.Scatter(
    x=t, y=E_env, mode='lines',
    line=dict(color='#ff006e', width=1.5, dash='dash'),
    name='e^(-2γt)'), row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(title='x', range=[-3, 3],
    zerolinecolor='#808080', row=1, col=1)
fig.update_yaxes(title='v', range=[-6, 6],
    zerolinecolor='#808080', row=1, col=1)
fig.update_xaxes(title='Time', zerolinecolor='#808080', row=1, col=2)
fig.update_yaxes(title='Energy', range=[0, 15],
    zerolinecolor='#808080', row=1, col=2)
fig.show()
