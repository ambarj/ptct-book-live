The Common Thread

Every MC application follows the same pattern: (1) define a random process, (2) run many trials, (3) average the results. Whether you’re estimating π from needle drops, pricing options from stock simulations, or computing magnetization from spin flips — it’s all sampling and averaging. The power of MC is that this simple recipe works for problems of arbitrary complexity.

Run Diffusion. What quantity does the random walk estimate?
Explanation: A random walk models diffusion: at each step, the particle moves randomly. The key statistical quantity is \( \langle x^2 \rangle \propto t \) — the diffusion law. MC simulates many walks and averages \( x^2 \) to estimate the diffusion coefficient.

Launch 20 walkers for 500 steps in 2D. The RMS distance plot shows \( \sqrt{\langle r^2 \rangle} \) vs step number. What shape is this curve?
Explanation: For a random walk, \( \langle r^2 \rangle = N \) (in appropriate units), so \( \sqrt{\langle r^2 \rangle} = \sqrt{N} \). This is the diffusion law: distance grows as the square root of time (steps). The same \( \sqrt{N} \) appears in MC error because MC is a random walk through sample space.
The average displacement \( \langle x \rangle \) of a symmetric random walk is (the walk is unbiased — equally likely to go left or right).
Explanation: A symmetric random walk has \( \langle x \rangle = 0 \) by symmetry. The walker is equally likely to be at +x as at −x. But the spread \( \sqrt{\langle x^2 \rangle} \) grows as \( \sqrt{N} \). Zero mean, growing variance — this is diffusion.
How is a random walk related to the Metropolis algorithm?
Explanation: Metropolis is a random walk in configuration space with a bias: downhill moves (lower energy) are always accepted, uphill moves are accepted with probability \( e^{-\Delta E/kT} \). This bias makes the walk spend more time in low-energy configurations, sampling the Boltzmann distribution. It’s a random walk with a purpose.

Which are valid reasons to choose Monte Carlo over deterministic methods? (Select all)
Explanation:
  • 15-digit 1D: ✗ Use Gaussian quadrature. MC converges as 1/√N — too slow for high precision.
  • 20 dimensions: ✓ Grid methods need \( n^{20} \) points. MC needs the same N regardless of dimension.
  • Complex distribution: ✓ Metropolis MCMC was designed exactly for this — sampling without knowing Z.
  • Irregular boundary: ✓ MC just needs a point-in-region test. No meshing needed.

Explanation: Error ∝ \( 1/\sqrt{N} \). Halve error: \( N \to 4N \) (×4). 10× better: \( N \to 100N \) (×100). This is the fundamental cost of MC: slow convergence, but dimension-independent.
What is the single most important computational thinking skill from Chapter 6?
Explanation: The core insight: randomness is a computational tool. When a problem is too complex for deterministic methods (high dimensions, complex boundaries, intractable sums), you can often reformulate it as “generate random samples and average.” This is the Monte Carlo philosophy, and it works across all of science.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# 2D Random Walk
n_walkers, n_steps = 20, 1000
fig = make_subplots(1, 2, subplot_titles=['2D Walks', 'RMS Distance'])

colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88','#bb86fc']

# Store all positions for RMS
all_r2 = np.zeros(n_steps + 1)

for w in range(n_walkers):
    steps = np.random.choice([-1, 1], (n_steps, 2))
    pos = np.cumsum(steps, axis=0)
    pos = np.vstack([[0, 0], pos])
    all_r2 += pos[:, 0]**2 + pos[:, 1]**2

    if w < 5:  # show first 5
        fig.add_trace(go.Scatter(
            x=pos[:, 0], y=pos[:, 1], mode='lines',
            line=dict(color=colors[w], width=1),
            showlegend=False), row=1, col=1)

# RMS distance
rms = np.sqrt(all_r2 / n_walkers)
steps_arr = np.arange(n_steps + 1)
fig.add_trace(go.Scatter(x=steps_arr, y=rms, mode='lines',
    line=dict(color='#00f3ff', width=2), name='MC RMS'), row=1, col=2)
fig.add_trace(go.Scatter(x=steps_arr, y=np.sqrt(steps_arr), mode='lines',
    line=dict(color='white', width=1.5, dash='dash'),
    name='√N theory'), row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(zerolinecolor='#808080', row=1, col=1)
fig.update_yaxes(zerolinecolor='#808080', row=1, col=1)
fig.update_xaxes(title='Steps', zerolinecolor='#808080', row=1, col=2)
fig.update_yaxes(title='RMS distance', zerolinecolor='#808080', row=1, col=2)
fig.show()
