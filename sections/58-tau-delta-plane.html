The τ-Δ Classification Framework

In the last section you saw that eigenvalues determine everything about a linear system. But computing eigenvalues requires solving a quadratic — is there a faster way to classify? Yes: the trace-determinant plane. Two numbers, \( \tau = a + d \) (trace) and \( \Delta = ad - bc \) (determinant), carve the plane into regions. Each region corresponds to a fixed-point type. One glance at where \( (\tau, \Delta) \) falls tells you the full story.

Learning Objectives
  • Compute the trace \( \tau = a + d \) and determinant \( \Delta = ad - bc \) of any 2×2 matrix
  • Map any linear system to a point in the \( (\tau, \Delta) \) plane and read off the classification
  • Understand the boundaries: \( \Delta = 0 \) (saddle boundary), \( \tau = 0 \) (stability boundary), \( \tau^2 = 4\Delta \) (node-spiral boundary)
  • Use the framework as a universal classification tool that works for any 2D linear system

The Classification Formula:

$$ \lambda_{1,2} = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2} $$

where \( \tau = \text{tr}(A) = a + d \) and \( \Delta = \det(A) = ad - bc \). The discriminant \( \tau^2 - 4\Delta \) determines whether eigenvalues are real or complex.

Reading the Map

The τ-Δ plane is divided into five regions by three curves:

  • \( \Delta = 0 \) (horizontal axis): Below this line, eigenvalues have opposite signs → saddle
  • \( \tau = 0 \) (vertical axis): Crossing this line flips stability (stable ↔ unstable)
  • \( \tau^2 = 4\Delta \) (parabola): Inside the parabola, eigenvalues are complex → spirals/centers. Outside, eigenvalues are real → nodes

What Happens on the Boundaries?

On \( \Delta = 0 \): One eigenvalue is zero. The system has a line of fixed points — an entire line where nothing moves. Trajectories approach or leave this line.

On \( \tau = 0 \) (inside parabola): Eigenvalues are pure imaginary (\( \pm i\omega \)). The fixed point is a center with closed orbits. Any perturbation of \( \tau \) away from zero breaks the center into a spiral.

On \( \tau^2 = 4\Delta \): The discriminant is zero, giving a repeated eigenvalue. This is the boundary between nodes (real eigenvalues) and spirals (complex eigenvalues). The system is a star node or degenerate node.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def classify_and_plot(A, name=''):
    """Classify matrix and show τ-Δ location + phase portrait."""
    a, b, c, d = A[0,0], A[0,1], A[1,0], A[1,1]
    tau = a + d
    delta = a*d - b*c
    disc = tau**2 - 4*delta

    # Classify
    if delta < 0:
        fp_type = 'Saddle'
    elif abs(disc) < 0.01:
        fp_type = 'Star/Degenerate Node'
    elif disc > 0:
        fp_type = 'Stable Node' if tau < 0 else 'Unstable Node'
    elif abs(tau) < 0.01:
        fp_type = 'Center'
    else:
        fp_type = 'Stable Spiral' if tau < 0 else 'Unstable Spiral'

    # RK4 solver
    def rk4(x0, T=10, N=2000):
        h = T/N; x = np.array(x0, float); traj = [x.copy()]
        for _ in range(N):
            f = lambda u: A @ u
            k1=f(x); k2=f(x+h/2*k1); k3=f(x+h/2*k2); k4=f(x+h*k3)
            x += h/6*(k1+2*k2+2*k3+k4)
            if np.linalg.norm(x) > 20: break
            traj.append(x.copy())
        return np.array(traj)

    fig = make_subplots(1, 2, subplot_titles=[
        f'τ-Δ Plane: {name}', f'Phase Portrait: {fp_type}'])

    # τ-Δ plane with regions
    t = np.linspace(-5, 5, 200)
    fig.add_trace(go.Scatter(x=t, y=t**2/4, mode='lines',
        line=dict(color='white', width=1.5), showlegend=False),
        row=1, col=1)
    fig.add_trace(go.Scatter(x=[-5,5], y=[0,0], mode='lines',
        line=dict(color='#ffbe0b', width=1, dash='dash'),
        showlegend=False), row=1, col=1)
    fig.add_trace(go.Scatter(x=[tau], y=[delta], mode='markers',
        marker=dict(color='#ff006e', size=14,
            line=dict(color='white', width=2)),
        showlegend=False), row=1, col=1)

    # Phase portrait
    colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88',
              '#bb86fc','#ff5722','#76ff03','#40c4ff']
    T = 5 if delta < 0 else 12
    for k in range(8):
        th = k*np.pi/4
        traj = rk4([1.5*np.cos(th), 1.5*np.sin(th)], T)
        fig.add_trace(go.Scatter(x=traj[:,0], y=traj[:,1],
            mode='lines', line=dict(color=colors[k], width=1.5),
            showlegend=False), row=1, col=2)

    fig.update_layout(template='plotly_dark', height=400, width=900)
    fig.update_xaxes(title='τ', range=[-5,5],
        zerolinecolor='#808080', row=1, col=1)
    fig.update_yaxes(title='Δ', range=[-3,7],
        zerolinecolor='#808080', row=1, col=1)
    fig.update_xaxes(title='x', range=[-3,3],
        zerolinecolor='#808080', row=1, col=2)
    fig.update_yaxes(title='y', range=[-3,3],
        zerolinecolor='#808080', scaleanchor='x2', row=1, col=2)
    fig.show()
    print(f'{name}: τ={tau:.2f}, Δ={delta:.2f} → {fp_type}')

# Test with various systems
classify_and_plot(np.array([[0,1],[-1,0]]), 'SHO')
classify_and_plot(np.array([[-0.5,1],[-1,-0.5]]), 'Damped SHO')
classify_and_plot(np.array([[1,1],[0,-2]]), 'Saddle')
classify_and_plot(np.array([[-2,0.5],[0.5,-1]]), 'Stable Node')
