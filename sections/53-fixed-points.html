Finding Fixed Points

Every phase portrait is organized around its fixed points — the equilibria where the system doesn't move. At a fixed point \( (x^*, y^*) \), the velocity is zero: \( f(x^*, y^*) = 0 \) and \( g(x^*, y^*) = 0 \). Find the fixed points, and you've found the skeleton of the dynamics.

Learning Objectives
  • Find fixed points by solving \( \dot{x} = 0 \) and \( \dot{y} = 0 \) simultaneously
  • Use nullclines to locate fixed points graphically — even for nonlinear systems
  • Read the flow direction in each region between nullclines
  • Test stability by perturbing fixed points and observing the response

For linear systems, the origin is always the only fixed point (assuming \( \det \mathbf{A} \neq 0 \)). But for nonlinear systems, there can be many fixed points, and finding them is the first step in understanding the behavior. The graphical tool for this is nullclines.

Nullclines:

$$ \text{x-nullcline: } f(x,y) = 0 \quad (\text{where } \dot{x} = 0) $$ $$ \text{y-nullcline: } g(x,y) = 0 \quad (\text{where } \dot{y} = 0) $$

Fixed points are where nullclines intersect — both velocity components vanish simultaneously.

Explorer: Nullcline Finder

The cyan curves are the x-nullcline (\( \dot{x} = 0 \)) and the magenta curves are the y-nullcline (\( \dot{y} = 0 \)). Fixed points (yellow dots) appear wherever these curves cross. Gray streamlines show the actual flow.

Key Insight

Nullclines organize the flow. On the x-nullcline, the velocity has no horizontal component — arrows point purely vertically. On the y-nullcline, arrows point purely horizontally. Between nullclines, the flow direction stays consistent. This makes nullclines a powerful tool for sketching phase portraits by hand.

Reading the Flow Between Nullclines

Nullclines divide the phase plane into regions. Within each region, the signs of \( \dot{x} \) and \( \dot{y} \) are constant — so you know the qualitative flow direction without solving anything. The color code below shows four possible combinations:

  • Green (↗): \( \dot{x} > 0 \) and \( \dot{y} > 0 \) — moving right and up
  • Blue (↘): \( \dot{x} > 0 \) and \( \dot{y} < 0 \) — moving right and down
  • Yellow (↖): \( \dot{x} < 0 \) and \( \dot{y} > 0 \) — moving left and up
  • Magenta (↙): \( \dot{x} < 0 \) and \( \dot{y} < 0 \) — moving left and down

Stable or Unstable?

Finding fixed points is step one. Step two: what happens nearby? If you nudge the system slightly away from a fixed point, does it return (stable), escape (unstable), or orbit (center)? This is the stability question, which we'll formalize in the next section. For now, let's test it experimentally.

Explanation:

  • Saddle is stable: FALSE. A saddle is stable along one direction but unstable along another — overall it's classified as unstable.
  • Center orbits: TRUE. At a center, trajectories form closed loops — they stay nearby but never actually converge to the fixed point. This is "neutrally stable."

import numpy as np
import plotly.graph_objects as go

# Simple pendulum: dx/dt = y, dy/dt = -sin(x)
x = np.linspace(-7, 7, 200)
y = np.linspace(-3, 3, 200)
X, Y = np.meshgrid(x, y)
F = Y                  # dx/dt
G = -np.sin(X)         # dy/dt

fig = go.Figure()

# x-nullcline: dx/dt = y = 0 → horizontal line
fig.add_trace(go.Contour(
    z=F, x=x, y=y,
    contours=dict(start=0, end=0, coloring='none'),
    line=dict(color='#00f3ff', width=3),
    showscale=False, name='ẋ = 0'))

# y-nullcline: dy/dt = -sin(x) = 0 → vertical lines at nπ
fig.add_trace(go.Contour(
    z=G, x=x, y=y,
    contours=dict(start=0, end=0, coloring='none'),
    line=dict(color='#ff006e', width=3),
    showscale=False, name='ẏ = 0'))

# Mark fixed points
fp_x = [-2*np.pi, -np.pi, 0, np.pi, 2*np.pi]
fp_y = [0, 0, 0, 0, 0]
fig.add_trace(go.Scatter(
    x=fp_x, y=fp_y, mode='markers',
    marker=dict(color='#ffbe0b', size=12, symbol='circle',
                line=dict(color='white', width=1)),
    name='Fixed points'))

fig.update_layout(
    template='plotly_dark',
    title='Pendulum Nullclines and Fixed Points',
    xaxis=dict(range=[-7, 7], title='θ',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    yaxis=dict(range=[-3, 3], title='dθ/dt',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    width=700, height=500)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

def rk4_step(f, y, h):
    k1 = f(y)
    k2 = f(y + h/2 * k1)
    k3 = f(y + h/2 * k2)
    k4 = f(y + h * k3)
    return y + (h/6) * (k1 + 2*k2 + 2*k3 + k4)

# Pendulum system
def pendulum(y):
    return np.array([y[1], -np.sin(y[0])])

# Perturb fixed point (0,0) in 8 directions
fig = go.Figure()
fp = np.array([0.0, 0.0])
eps = 0.3
colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88',
          '#bb86fc','#ff5722','#76ff03','#40c4ff']

for k in range(8):
    theta = k * np.pi / 4
    y0 = fp + eps * np.array([np.cos(theta), np.sin(theta)])
    ys = [y0.copy()]
    for _ in range(3000):
        y0 = rk4_step(pendulum, y0, 0.01)
        ys.append(y0.copy())
    ys = np.array(ys)
    fig.add_trace(go.Scatter(
        x=ys[:,0], y=ys[:,1], mode='lines',
        line=dict(color=colors[k], width=1.5),
        showlegend=False))

# Mark fixed point
fig.add_trace(go.Scatter(
    x=[0], y=[0], mode='markers',
    marker=dict(color='#ffbe0b', size=12, symbol='circle'),
    name='Fixed point'))

fig.update_layout(
    template='plotly_dark',
    title='Stability Test: Pendulum at (0,0) → Center',
    xaxis=dict(range=[-1.5, 1.5], title='θ',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    yaxis=dict(range=[-1.5, 1.5], title='dθ/dt',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    width=600, height=600)
fig.show()
