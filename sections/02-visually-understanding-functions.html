Visually Understanding Functions

Here's a challenge: look at the function \( f(x) = \frac{x^2 - 4}{x - 3} \). Can you sketch its graph without plotting hundreds of points? By the end of this section, you'll be able to do exactly that — and you'll wonder why you ever plotted functions the hard way!

The secret? Every function's shape is determined by just a few special points. Find these points, and you understand the entire function. It's like knowing the plot twists of a movie — suddenly the whole story makes sense.

Learning Objectives
  • Find where functions equal zero (zeros or roots)
  • Identify where functions blow up to infinity (divergences or poles)
  • Locate turning points (extrema: minima and maxima)
  • Understand long-range behavior (asymptotes)
  • Use these four properties to sketch any function systematically

The Four Properties That Define Any Function

Think of these four properties as the "vital signs" of a function. Just like a doctor checks your heart rate, blood pressure, and temperature to understand your health, we check these four properties to understand a function's behavior:

  1. Zeros — Where does the function cross the x-axis?
  2. Divergences — Where does the function explode to infinity?
  3. Extrema — Where are the peaks and valleys?
  4. Asymptotes — What happens when x gets really big (or really small)?

Let's explore each one with interactive tools. Get ready to play!

1. Zeros: Where Functions Cross Zero

Zeros (also called roots) are the x-values where the function equals zero: \( f(x^*) = 0 \). On a graph, these are the points where the curve crosses the x-axis.

Why do we care? In physics, zeros often represent equilibrium points, nodes in standing waves, or times when something returns to its starting position. Finding zeros is one of the most common tasks in science!

Example: The Quadratic \( f(x) = x^2 - 3x + 2 \)

This function can be factored as \( f(x) = (x - 1)(x - 2) \). The factored form immediately tells us the zeros: \( x = 1 \) and \( x = 2 \). Why? Because when \( x = 1 \), the first factor becomes zero, making the whole product zero. Same logic for \( x = 2 \).

Interactive: Zero Finder
Discriminant: 1.00 | Two real zeros
The Discriminant Tells All

For a quadratic \( ax^2 + bx + c \), the discriminant is \( \Delta = b^2 - 4ac \). It tells you how many zeros exist:

  • \( \Delta > 0 \): Two real zeros (parabola crosses x-axis twice)
  • \( \Delta = 0 \): One real zero (parabola just touches x-axis)
  • \( \Delta < 0 \): No real zeros (parabola never crosses x-axis)

Try adjusting the sliders to see each case! Watch how the discriminant value changes.

2. Divergences: Where Functions Blow Up

Sometimes functions don't just get big — they explode to infinity. These points are called divergences (or singularities or poles). They happen when you try to divide by zero.

Here's the key insight: divergences occur where the denominator equals zero. If \( f(x) = \frac{1}{g(x)} \), then f(x) blows up wherever g(x) = 0.

Example: The Reciprocal Function \( f(x) = \frac{1}{(x-1)(x-2)} \)

Notice something cool? The denominator is the same polynomial we just studied! It has zeros at x = 1 and x = 2. So our new function has divergences at exactly those points.

The zeros of the denominator become the poles of the function. It's like flipping a function upside down — what was zero becomes infinity!

Interactive: Divergence Visualizer
Common Pitfall: Division by Zero

In mathematics, we say the function "diverges" or "goes to infinity." But on a computer, dividing by zero gives an error, not infinity! That's why in the plot above, we carefully avoid plotting exactly at the poles. Always check your denominators before computing!

Which Way Does It Blow Up?

Near a pole, the function can go to \( +\infty \) or \( -\infty \) depending on which side you approach from. Watch the graph as you move the poles — notice how the curve shoots up on one side and down on the other!

The vertical dashed lines mark the vertical asymptotes — the function gets infinitely close to these lines but never crosses them.

3. Extrema: The Peaks and Valleys

Extrema are the turning points of a function — the places where it switches from going up to going down (a maximum) or from going down to going up (a minimum).

Here's the mathematical key: at an extremum, the slope is zero. The function is momentarily "flat" before changing direction. In calculus language: \( f'(x^*) = 0 \).

Same Function, New Perspective

Let's look at \( f(x) = x^2 - 3x + 2 \) again — but now we want its minimum, not its zeros.

Here's a neat trick called completing the square:

$$ f(x) = x^2 - 3x + 2 = \left(x - \frac{3}{2}\right)^2 - \frac{1}{4} $$

This form tells us the minimum is at \( x = \frac{3}{2} = 1.5 \), with value \( f(1.5) = -0.25 \).

One Function, Multiple Lenses

The same function reveals different secrets through different techniques:

  • Factoring \( (x-1)(x-2) \) → reveals the zeros
  • Completing the square \( (x-1.5)^2 - 0.25 \) → reveals the extremum

This is a powerful lesson: when solving problems, try different approaches to uncover different insights!

4. Asymptotes: Behavior at Infinity

What happens to a function when x gets really, really big? Or really, really negative? Asymptotes describe this long-range behavior — lines that the function approaches but never quite reaches.

We've already seen vertical asymptotes at divergence points. Now let's explore horizontal asymptotes — what happens as \( x \to \pm\infty \).

The Classic Example: \( f(x) = \frac{1}{x} \)

As x gets larger and larger (1, 10, 100, 1000...), what happens to 1/x? It gets smaller and smaller (1, 0.1, 0.01, 0.001...), approaching zero but never reaching it.

The line y = 0 (the x-axis) is a horizontal asymptote.

Interactive: Asymptote Analyzer
Horizontal asymptote: y = 0 | Vertical asymptote: x = 0
Finding Horizontal Asymptotes

For a rational function \( \frac{P(x)}{Q(x)} \), compare the degrees of the polynomials:

  • deg(P) < deg(Q): Horizontal asymptote at y = 0
  • deg(P) = deg(Q): Horizontal asymptote at y = (leading coeff of P)/(leading coeff of Q)
  • deg(P) > deg(Q): No horizontal asymptote (function grows without bound)

Try the different functions in the dropdown and zoom out to see the asymptotic behavior!

Explanation

Statement 2 (TRUE): Vertical asymptotes mark where the function blows up to infinity.

Statement 3 (TRUE): When deg(P) > deg(Q), the function grows without bound.

Statement 4 (FALSE): Functions CAN cross horizontal asymptotes! For example, \( \frac{\sin x}{x} \) crosses y = 0 infinitely many times while approaching it.

The Analysis Workflow

When you encounter any function, follow this systematic approach:

  1. Find zeros: Set numerator = 0 and solve
  2. Find divergences: Set denominator = 0 and solve
  3. Find extrema: Set derivative = 0 and solve
  4. Find asymptotes: Check behavior as x → ±∞

With these four pieces of information, you can sketch the function accurately without plotting every point!

Python Code Examples

Let's see how to identify these properties computationally. Remember: same Plotly library you've been seeing in the interactive plots!

Python 
import numpy as np
import plotly.graph_objects as go

# Find zeros of a polynomial: x² - 3x + 2
coefficients = [1, -3, 2]  # [a, b, c] for ax² + bx + c
zeros = np.roots(coefficients)
print(f"Zeros: {zeros}")  # Output: [2. 1.]

# Plot the function with zeros marked
x = np.linspace(-1, 4, 200)
y = x**2 - 3*x + 2

fig = go.Figure()

# Plot the curve
fig.add_trace(go.Scatter(
    x=x, y=y, mode='lines',
    name='f(x) = x² - 3x + 2',
    line=dict(color='#00f3ff', width=2)
))

# Mark the zeros
fig.add_trace(go.Scatter(
    x=zeros, y=[0, 0], mode='markers',
    name='Zeros',
    marker=dict(color='#ff00ff', size=12, symbol='circle')
))

fig.update_layout(
    template='plotly_dark',
    title='Finding Zeros',
    xaxis=dict(zeroline=True, zerolinecolor='#808080'),
    yaxis=dict(zeroline=True, zerolinecolor='#808080')
)
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

# Function with divergences: f(x) = 1/[(x-1)(x-2)]
poles = [1, 2]  # Divergence points

# Create x values, carefully avoiding poles
x = np.linspace(-1, 4, 500)
y = 1 / ((x - 1) * (x - 2))

# Clip extreme values for cleaner plotting
y = np.clip(y, -20, 20)
y[np.abs(y) > 15] = np.nan  # Hide near-pole values

fig = go.Figure()

# Plot the function
fig.add_trace(go.Scatter(
    x=x, y=y, mode='lines',
    name='f(x) = 1/[(x-1)(x-2)]',
    line=dict(color='#00f3ff', width=2)
))

# Add vertical asymptotes
for pole in poles:
    fig.add_vline(x=pole, line=dict(color='#ff00ff', dash='dash'),
                  annotation_text=f'x = {pole}')

fig.update_layout(
    template='plotly_dark',
    title='Visualizing Divergences',
    yaxis=dict(range=[-15, 15])
)
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go
from scipy.optimize import minimize_scalar

# Find extremum of f(x) = x² - 6x + 5
def f(x):
    return x**2 - 6*x + 5

# Find minimum using optimization
result = minimize_scalar(f, bounds=(-10, 10), method='bounded')
x_min = result.x
y_min = result.fun

print(f"Minimum at x = {x_min:.2f}, f(x) = {y_min:.2f}")

# Plot with extremum marked
x = np.linspace(-2, 8, 200)
y = f(x)

fig = go.Figure()

fig.add_trace(go.Scatter(
    x=x, y=y, mode='lines',
    name='f(x) = x² - 6x + 5',
    line=dict(color='#00f3ff', width=2)
))

fig.add_trace(go.Scatter(
    x=[x_min], y=[y_min], mode='markers',
    name=f'Minimum ({x_min:.1f}, {y_min:.1f})',
    marker=dict(color='#00ff9f', size=14, symbol='triangle-down')
))

fig.update_layout(
    template='plotly_dark',
    title='Finding Extrema',
    xaxis=dict(zeroline=True, zerolinecolor='#808080'),
    yaxis=dict(zeroline=True, zerolinecolor='#808080')
)
fig.show()

Summary

You've learned to analyze any function using four key properties:

  • Zeros — where f(x) = 0 (graph crosses x-axis)
  • Divergences — where f(x) → ±∞ (denominator = 0)
  • Extrema — where f'(x) = 0 (peaks and valleys)
  • Asymptotes — long-range behavior as x → ±∞

These four properties are like a function's fingerprint — they uniquely identify its shape and behavior. Master them, and you'll never need to plot hundreds of points again!
