The Euler Method Formula

In Section 4.1, you watched a dot step through a slope field, following the arrows one hop at a time. That was Euler’s method in spirit. Now let’s make it precise.

The idea is disarmingly simple. A differential equation \(\dot{x} = f(x, t)\) tells you the slope of the solution at every point. If you know where you are right now, you can draw the tangent line and walk along it for a small distance \(h\). You won’t land exactly on the true curve — but you’ll be close. Then you read the slope again, draw a new tangent, and repeat.

Learning Objectives
  • State the Euler method formula: \(x_{n+1} = x_n + h\,f(x_n, t_n)\)
  • Understand its geometric meaning: walking along tangent lines
  • Execute the algorithm by hand for a simple ODE
  • See how the step size \(h\) controls accuracy

The Euler Method — from calculus to arithmetic in one line:

$$ x_{n+1} \;=\; x_n \;+\; h\;\cdot f(x_n,\, t_n) $$

where \(h\) is the step size (a small time interval you choose), \(f(x_n, t_n)\) is the slope at the current point, and \(t_{n+1} = t_n + h\).

Why does this work? Taylor-expand the true solution about \(t_n\):

$$ x(t_n + h) = x(t_n) + h\,\underbrace{x'(t_n)}_{=\,f(x_n,\,t_n)} + \underbrace{\tfrac{h^2}{2}\,x''(t_n) + \cdots}_{\text{truncated}} $$

Euler’s method keeps the first two terms and throws away the rest. The error in each step is \(\mathcal{O}(h^2)\) — small when \(h\) is small.

Key Insight

Halving the step size roughly halves the final error. This is because Euler’s method is first-order accurate: the global error is \(\mathcal{O}(h)\). To get 10× better accuracy, you need 10× more steps. (In Section 4.11, you’ll meet methods that do much better.)

Explanation: Going from 0.2 to \(2 \times 10^{-4}\) is a 1000× reduction in error. Because Euler is first-order (error ∝ h), that demands \(h\) be 1000× smaller — and since \(N = T/h\), the same time interval now needs 1000× more steps: from 10 to 10,000. The key takeaway: first-order methods are expensive — every factor of accuracy costs the same factor in work, which is why higher-order methods are worth learning.

The beauty of Euler’s method is that the formula doesn’t care what \(f\) is. Linear, nonlinear, simple, complicated — you always do the same thing: read the slope, step, repeat. Try it on three different equations below.

Python Code Examples

Python 
import numpy as np
import plotly.graph_objects as go

# ODE: dx/dt = -2x,  x(0) = 1
# Exact solution: x(t) = exp(-2t)
def f(x, t):
    return -2 * x

# Euler's method — just three lines of logic!
h = 0.5
t, x = [0.0], [1.0]
while t[-1] < 3.0:
    x_new = x[-1] + h * f(x[-1], t[-1])
    t.append(t[-1] + h)
    x.append(x_new)

# Exact solution for comparison
t_exact = np.linspace(0, 3, 300)
x_exact = np.exp(-2 * t_exact)

fig = go.Figure()
fig.add_trace(go.Scatter(x=t_exact, y=x_exact,
    mode='lines', name='Exact: exp(-2t)',
    line=dict(color='#808080', width=2, dash='dash')))
fig.add_trace(go.Scatter(x=t, y=x,
    mode='lines+markers', name=f'Euler (h={h})',
    line=dict(color='#00f3ff', width=2),
    marker=dict(size=6)))

fig.update_layout(
    template='plotly_dark',
    title='Euler Method: dx/dt = -2x',
    xaxis=dict(title='t', range=[0, 3],
        gridcolor='#2a2f4a', zerolinecolor='#808080',
        linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-0.5, 1.2],
        gridcolor='#2a2f4a', zerolinecolor='#808080',
        linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

def f(x, t):
    return -2 * x

def euler(h, t_end=3.0):
    t, x = [0.0], [1.0]
    while t[-1] < t_end - 1e-10:
        x.append(x[-1] + h * f(x[-1], t[-1]))
        t.append(t[-1] + h)
    return t, x

fig = go.Figure()

# Exact
t_ex = np.linspace(0, 3, 300)
fig.add_trace(go.Scatter(x=t_ex, y=np.exp(-2*t_ex),
    mode='lines', name='Exact',
    line=dict(color='#808080', width=2, dash='dash')))

# Four step sizes
colors = ['#ff6b6b', '#ffff00', '#ff00ff', '#00f3ff']
for h, c in zip([1.0, 0.5, 0.2, 0.05], colors):
    t, x = euler(h)
    err = abs(x[-1] - np.exp(-2*t[-1]))
    fig.add_trace(go.Scatter(x=t, y=x,
        mode='lines+markers', name=f'h={h} (err={err:.4f})',
        line=dict(color=c, width=2),
        marker=dict(size=4)))

fig.update_layout(
    template='plotly_dark',
    title='Step Size Showdown',
    xaxis=dict(title='t', range=[0, 3],
        gridcolor='#2a2f4a', zerolinecolor='#808080',
        linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-0.5, 1.2],
        gridcolor='#2a2f4a', zerolinecolor='#808080',
        linecolor='#808080'))
fig.show()
