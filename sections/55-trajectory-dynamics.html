Trajectory Exploration

You can now classify fixed points and read phase portraits. But there’s a deeper structure at work: trajectories themselves obey powerful rules. Every initial condition launches exactly one trajectory. Different trajectories never cross. And the plane partitions into basins of attraction — regions of initial conditions that share the same long-term fate.

Learning Objectives
  • Launch trajectories from different initial conditions and observe how the starting point determines the entire future
  • Understand the uniqueness theorem: two distinct trajectories can never occupy the same point
  • Map basins of attraction — regions of initial conditions that share the same long-term fate
  • Watch how a cloud of nearby initial conditions deforms over time, revealing stretching and compression
The Uniqueness Theorem

If \( f \) and \( g \) are smooth, then through every point \( (x_0, y_0) \) there passes exactly one trajectory. Two different trajectories can never intersect, merge, or cross. This seemingly simple fact has profound consequences: it means the phase portrait is a collection of non-intersecting curves that fill the entire plane.

When a system has multiple attractors, the plane splits into basins of attraction — regions colored by which attractor each initial condition eventually reaches. The boundary between basins passes through saddle points.

Basins and Separatrices

The boundary between basins is called a separatrix. It typically consists of the stable manifold of a saddle point — the set of initial conditions that approach the saddle as \( t \to \infty \). Points on one side of the separatrix go to one attractor; points on the other side go to the other. The saddle point itself sits on the boundary, attracting along one direction and repelling along the other.

import numpy as np
import plotly.graph_objects as go

def rk4_solve(f, x0, T, N):
    """RK4 for dx/dt = f(x). x is a 2-vector."""
    h = T / N
    x = np.array(x0, dtype=float)
    traj = [x.copy()]
    for _ in range(N):
        k1 = f(x)
        k2 = f(x + h/2 * k1)
        k3 = f(x + h/2 * k2)
        k4 = f(x + h * k3)
        x += h/6 * (k1 + 2*k2 + 2*k3 + k4)
        if np.linalg.norm(x) > 20: break
        traj.append(x.copy())
    return np.array(traj)

# Predator-prey system
def lotka_volterra(x):
    return np.array([x[0]*(2 - x[1]),
                     x[1]*(-1 + x[0])])

fig = go.Figure()
colors = ['#00f3ff', '#ff006e', '#ffbe0b', '#00ff88',
          '#bb86fc', '#ff5722', '#76ff03', '#40c4ff']

# Launch from several initial conditions
ics = [(2, 1), (3, 3), (0.5, 0.5), (1, 4),
       (3, 1), (0.3, 3), (2, 0.5), (1.5, 3.5)]

for i, ic in enumerate(ics):
    traj = rk4_solve(lotka_volterra, ic, 15, 2000)
    fig.add_trace(go.Scatter(
        x=traj[:, 0], y=traj[:, 1], mode='lines',
        line=dict(color=colors[i % len(colors)], width=1.5),
        name=f'IC = {ic}'))

# Fixed point
fig.add_trace(go.Scatter(
    x=[1], y=[2], mode='markers',
    marker=dict(color='#ffbe0b', size=10,
                line=dict(color='white', width=2)),
    name='Fixed point'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Prey', range=[0, 4.5],
               zerolinecolor='#808080'),

import numpy as np
import plotly.graph_objects as go

def competition(x):
    """Competing species: x'=x(3-x-2y), y'=y(2-x-y)"""
    return np.array([x[0]*(3 - x[0] - 2*x[1]),
                     x[1]*(2 - x[0] - x[1])])

def rk4_endpoint(f, x0, T, N):
    """RK4 — return only final point."""
    h = T / N
    x = np.array(x0, dtype=float)
    for _ in range(N):
        k1 = f(x); k2 = f(x + h/2*k1)
        k3 = f(x + h/2*k2); k4 = f(x + h*k3)
        x += h/6 * (k1 + 2*k2 + 2*k3 + k4)
    return x

# Compute basin map on a grid
nx, ny = 80, 60
xs = np.linspace(0.01, 3.99, nx)
ys = np.linspace(0.01, 2.99, ny)
basin = np.zeros((ny, nx))

attractors = [np.array([3, 0]), np.array([0, 2])]

for j, y0 in enumerate(ys):
    for i, x0 in enumerate(xs):
        endpoint = rk4_endpoint(competition, [x0, y0], 30, 500)
        dists = [np.linalg.norm(endpoint - a)
                 for a in attractors]
        basin[j, i] = np.argmin(dists)

fig = go.Figure()
fig.add_trace(go.Heatmap(
    z=basin, x=xs, y=ys, opacity=0.6,
    colorscale=[[0, '#00f3ff'], [1, '#ff006e']],
    showscale=False))

# Fixed points
fps = [(3, 0, 'Stable'), (0, 2, 'Stable'),
       (1, 1, 'Saddle'), (0, 0, 'Unstable')]
for x, y, label in fps:
    fig.add_trace(go.Scatter(
        x=[x], y=[y], mode='markers+text',
        marker=dict(color='#ffbe0b', size=10,
                    line=dict(color='white', width=2)),
        text=[label], textposition='top center',
        textfont=dict(color='white', size=10),
        showlegend=False))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Species 1', range=[0, 4],
               zerolinecolor='#808080'),
    yaxis=dict(title='Species 2', range=[0, 3],
               zerolinecolor='#808080'),
    height=500, width=600)
fig.show()
