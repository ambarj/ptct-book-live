Polar Coordinates (Optional)

Section 5.14 showed that linearization cannot distinguish a true center from a spiral. How do you resolve the ambiguity? For systems with radial symmetry, the answer is elegant: switch to polar coordinates. The equations for \( r \) and \( \theta \) often decouple, turning a hard 2D problem into a simple 1D problem for the radius.

Learning Objectives
  • Transform a 2D Cartesian system \( (\dot{x}, \dot{y}) \) into polar form \( (\dot{r}, \dot{\theta}) \)
  • Recognize when radial symmetry causes the \( r \) and \( \theta \) equations to decouple
  • Analyze the 1D radial equation \( \dot{r} = h(r) \) to find limit cycles and resolve center/spiral ambiguity
  • Understand limit cycles as isolated closed orbits at radii where \( \dot{r} = 0 \)

The Polar Transformation:

$$ x = r\cos\theta, \quad y = r\sin\theta $$ $$ \dot{r} = \frac{x\dot{x} + y\dot{y}}{r}, \qquad \dot{\theta} = \frac{x\dot{y} - y\dot{x}}{r^2} $$

If the system has radial symmetry (terms involving only \( r^2 = x^2 + y^2 \)), then \( \dot{r} \) depends only on \( r \) and \( \dot{\theta} \) depends only on \( r \). The equations decouple: solve the radius first, then the angle follows.

Why Polar Coordinates Work

In Cartesian coordinates, \( \dot{x} = -y + \epsilon x(x^2+y^2) \) looks complicated. In polar: \( \dot{r} = \epsilon r^3 \) and \( \dot{\theta} = 1 \). The radial equation is now a simple 1D ODE! If \( \epsilon > 0 \), \( r \) grows (unstable spiral). If \( \epsilon < 0 \), \( r \) shrinks (stable spiral). If \( \epsilon = 0 \), \( r \) is constant (true center). The ambiguity is completely resolved.

Limit Cycles

A limit cycle is an isolated closed orbit. Unlike a center (where every orbit is closed), a limit cycle is a single special orbit that attracts (stable) or repels (unstable) nearby trajectories. In polar coordinates, limit cycles appear as zeros of \( h(r) \) where the sign of \( h \) changes. If \( h \) goes from + to −, the limit cycle is stable (trajectories converge to it from both sides).

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4(f, g, x0, y0, T, N):
    h=T/N; X,Y=[x0],[y0]; x,y=x0,y0
    for _ in range(N):
        k1x,k1y=f(x,y),g(x,y)
        k2x,k2y=f(x+h/2*k1x,y+h/2*k1y),g(x+h/2*k1x,y+h/2*k1y)
        k3x,k3y=f(x+h/2*k2x,y+h/2*k2y),g(x+h/2*k2x,y+h/2*k2y)
        k4x,k4y=f(x+h*k3x,y+h*k3y),g(x+h*k3x,y+h*k3y)
        x+=h/6*(k1x+2*k2x+2*k3x+k4x);y+=h/6*(k1y+2*k2y+2*k3y+k4y)
        if x*x+y*y>100: break
        X.append(x); Y.append(y)
    return np.array(X), np.array(Y)

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# Limit cycle system: ṙ = r(1-r²), θ̇ = 1
f = lambda x,y: -y + x*(1-(x**2+y**2))
g = lambda x,y:  x + y*(1-(x**2+y**2))

def rk4(f, g, x0, y0, T, N):
    h=T/N; X,Y=[x0],[y0]; x,y=x0,y0
    for _ in range(N):
        k1x,k1y=f(x,y),g(x,y)
        k2x,k2y=f(x+h/2*k1x,y+h/2*k1y),g(x+h/2*k1x,y+h/2*k1y)
        k3x,k3y=f(x+h/2*k2x,y+h/2*k2y),g(x+h/2*k2x,y+h/2*k2y)
        k4x,k4y=f(x+h*k3x,y+h*k3y),g(x+h*k3x,y+h*k3y)
        x+=h/6*(k1x+2*k2x+2*k3x+k4x);y+=h/6*(k1y+2*k2y+2*k3y+k4y)
        X.append(x); Y.append(y)
    return np.array(X), np.array(Y)

fig = make_subplots(1, 2, subplot_titles=[
    'Phase Portrait', 'Radial equation ṙ = r(1−r²)'])

# Trajectories from inside and outside
for r0, col in [(0.2,'#00f3ff'),(0.5,'#ffbe0b'),(1.5,'#ff006e'),(2.5,'#bb86fc')]:
    X, Y = rk4(f, g, r0, 0, 25, 5000)
    fig.add_trace(go.Scatter(x=X,y=Y,mode='lines',
        line=dict(color=col,width=1.5),
        name=f'r₀={r0}'), row=1, col=1)

# Limit cycle circle
th = np.linspace(0, 2*np.pi, 200)
fig.add_trace(go.Scatter(x=np.cos(th),y=np.sin(th),mode='lines',
    line=dict(color='white',width=2,dash='dash'),
    name='Limit cycle r=1'), row=1, col=1)

# ṙ vs r
r = np.linspace(0, 2.5, 200)
rdot = r*(1 - r**2)
fig.add_trace(go.Scatter(x=r,y=rdot,mode='lines',
    line=dict(color='#00f3ff',width=2.5),
    name='ṙ = r(1−r²)'), row=1, col=2)
fig.add_trace(go.Scatter(x=[0,2.5],y=[0,0],mode='lines',
    line=dict(color='#808080',width=1,dash='dot'),
    showlegend=False), row=1, col=2)
fig.add_trace(go.Scatter(x=[1],y=[0],mode='markers',
    marker=dict(color='white',size=12,line=dict(color='white',width=2)),
    name='Stable LC'), row=1, col=2)

fig.update_layout(template='plotly_dark', height=400, width=900)
fig.update_xaxes(range=[-3,3],zerolinecolor='#808080',row=1,col=1)
fig.update_yaxes(range=[-3,3],zerolinecolor='#808080',row=1,col=1)
fig.update_xaxes(title='r',range=[0,2.5],zerolinecolor='#808080',row=1,col=2)
fig.update_yaxes(title='ṙ',range=[-3,1],zerolinecolor='#808080',row=1,col=2)
fig.show()
