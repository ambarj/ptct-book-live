Adding Air Resistance

Real rockets don't fly through vacuum. Earth's atmosphere exerts drag that opposes motion and decays exponentially with altitude (air gets thinner as you go up). This is a problem with no analytical solution — the only way forward is numerical.

Learning Objectives
  • Model atmospheric drag as \( F_{\text{drag}} = -\alpha\,e^{-\beta(X-1)}\,V \) with two dimensionless parameters
  • See how drag steals energy and prevents escape at \( V_0 = \sqrt{2} \)
  • Use RK4 + bisection to find the new escape velocity — a problem with no analytical answer
  • Explore how drag strength (\( \alpha \)) and atmosphere thickness (\( \beta \)) affect escape

In dimensionless units, the ODE becomes:

Escape with air resistance:

$$ \ddot{X} = -\frac{1}{X^2} \;-\; \alpha\,e^{-\beta(X-1)}\,\dot{X} $$

where \( \alpha = \tfrac{k}{m}\sqrt{R/g} \) controls drag strength, and \( \beta = \lambda R \) controls atmosphere thickness. At \( X = 1 \) (surface), drag is \( \alpha V \). At altitude, it decays as \( e^{-\beta(X-1)} \).

Why This Matters

No analytical solution exists. The energy trick from Section 4.14 fails because drag is velocity-dependent and dissipative — energy is not conserved. The only way forward is numerical: RK4 to compute trajectories, bisection to find the new escape threshold. This is exactly the workflow real engineers use.

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def rk4_step(f, y, t, h):
    k1 = f(y, t)
    k2 = f(y + h/2 * k1, t + h/2)
    k3 = f(y + h/2 * k2, t + h/2)
    k4 = f(y + h * k3, t + h)
    return y + (h/6) * (k1 + 2*k2 + 2*k3 + k4)

def make_ode(alpha, beta):
    def f(y, t):
        X, V = y
        gravity = -1 / X**2
        drag = -alpha * np.exp(-beta * (X - 1)) * V
        return np.array([V, gravity + drag])
    return f

def solve(V0, alpha, beta, T=20, N=1000):
    f = make_ode(alpha, beta)
    h = T / N
    t = np.zeros(N+1); Y = np.zeros((N+1, 2))
    Y[0] = [1, V0]
    for i in range(N):
        Y[i+1] = rk4_step(f, Y[i], t[i], h)
        t[i+1] = t[i] + h
        if Y[i+1, 0] < 0.01 or Y[i+1, 0] > 50:
            break
    return t[:i+2], Y[:i+2]

# Compare with and without drag
alpha, beta = 1.0, 1.0
V0 = 1.8

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['X(T) Trajectory', 'V(T) Velocity'])

for a, label, color in [(0, 'No drag', '#00f3ff'),
                          (alpha, f'α={alpha}, β={beta}', '#ff6b6b')]:
    t, Y = solve(V0, a, beta)
    fig.add_trace(go.Scatter(x=t, y=Y[:,0], name=f'{label}',

    fig.add_trace(go.Scatter(x=t, y=Y[:,1], name=f'{label}',

import numpy as np

def rk4_step(f, y, t, h):
    k1 = f(y, t)
    k2 = f(y + h/2 * k1, t + h/2)
    k3 = f(y + h/2 * k2, t + h/2)
    k4 = f(y + h * k3, t + h)
    return y + (h/6) * (k1 + 2*k2 + 2*k3 + k4)

def escapes(V0, alpha, beta, T=30, N=1500, X_thresh=10):
    def f(y, t):
        X, V = y
        return np.array([V, -1/X**2 - alpha*np.exp(-beta*(X-1))*V])
    h = T / N
    y = np.array([1.0, V0])
    for i in range(N):
        y = rk4_step(f, y, i*h, h)
        if y[0] > X_thresh: return True
        if y[0] < 0.01: return False
    return False

# Bisection for escape velocity
def find_vesc(alpha, beta, lo=1.0, hi=4.0, steps=25):
    for _ in range(steps):
        mid = (lo + hi) / 2
        if escapes(mid, alpha, beta):
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2

# Sweep alpha
print(f"{'alpha':>6s}  {'beta':>5s}  {'v_esc':>8s}  {'v_esc/√2':>8s}")
print("-" * 32)
for alpha in np.arange(0, 3.5, 0.5):
    ve = find_vesc(alpha, beta=1.0)
    print(f"{alpha:6.1f}  {1.0:5.1f}  {ve:8.3f}  {ve/np.sqrt(2):8.3f}")
