The Metropolis Algorithm

The previous section showed that brute-force enumeration fails for large systems. The Metropolis algorithm solves this brilliantly: instead of sampling all configurations, it performs a random walk through configuration space that automatically spends more time in low-energy states. The result: thermal averages from a manageable number of samples, even when \( 2^N \) is astronomically large.

Learning Objectives
  • Understand the Metropolis algorithm: propose a change, accept or reject based on energy difference
  • Implement the accept/reject rule: always accept \( \Delta E < 0 \); accept \( \Delta E > 0 \) with probability \( e^{-\Delta E/k_BT} \)
  • Watch a Metropolis simulation equilibrate and understand when to start measuring
  • See how temperature controls the acceptance rate and the equilibrium properties

The Metropolis Rule:

$$ P(\text{accept}) = \begin{cases} 1 & \text{if } \Delta E \leq 0 \\ e^{-\Delta E / k_BT} & \text{if } \Delta E > 0 \end{cases} $$

Propose flipping one spin. If it lowers the energy, always accept. If it raises the energy by \( \Delta E \), accept with probability \( e^{-\Delta E / k_BT} \). At low T, uphill moves are rare (system freezes into order). At high T, most moves are accepted (disorder).

Why It Works: Detailed Balance

The Metropolis rule satisfies detailed balance: the rate of transitions from configuration A to B equals the rate from B to A (weighted by their Boltzmann probabilities). This guarantees that after enough steps, the random walk samples configurations with the correct thermal probabilities — without ever computing the partition function Z.

import numpy as np

def metropolis_ising_1d(N, T, n_steps, J=1):
    """Metropolis MC for 1D Ising model."""
    spins = np.random.choice([-1, 1], N)
    E = -J * np.sum(spins[:-1] * spins[1:])

    energies = [E]
    accepted = 0

    for step in range(n_steps):
        # Propose: flip random spin
        i = np.random.randint(N)

        # Compute ΔE (only neighbors matter)
        dE = 0
        if i > 0:   dE += 2 * J * spins[i] * spins[i-1]
        if i < N-1: dE += 2 * J * spins[i] * spins[i+1]

        # Accept/reject
        if dE <= 0 or np.random.random() < np.exp(-dE / T):
            spins[i] *= -1
            E += dE
            accepted += 1

        energies.append(E)

    return energies, accepted / n_steps, spins

# Run
N, T, n_steps = 50, 1.0, 5000
energies, acc_rate, final_spins = metropolis_ising_1d(N, T, n_steps)

# Thermal average (skip burn-in)
burn_in = 1000
avg_E = np.mean(energies[burn_in:])
print(f'⟨E⟩/N = {avg_E/N:.3f} J')
print(f'Acceptance rate: {acc_rate:.1%}')
print(f'Exact: ⟨E⟩/N = {-np.tanh(1/T):.3f} J')

import numpy as np
import plotly.graph_objects as go

N, n_steps = 50, 5000
Ts = np.linspace(0.2, 5, 25)
mc_E, mc_acc, exact_E = [], [], []

for T in Ts:
    energies, acc, _ = metropolis_ising_1d(N, T, n_steps)
    mc_E.append(np.mean(energies[1000:]) / N)
    mc_acc.append(acc)
    exact_E.append(-np.tanh(1/T))

fig = go.Figure()
fig.add_trace(go.Scatter(x=Ts, y=mc_E, mode='markers',
    marker=dict(color='#00f3ff', size=8),
    name='MC ⟨E⟩/N'))
fig.add_trace(go.Scatter(x=Ts, y=exact_E, mode='lines',
    line=dict(color='white', width=2, dash='dash'),
    name='Exact: −tanh(J/T)'))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='T/J', zerolinecolor='#808080'),
    yaxis=dict(title='⟨E⟩/NJ', range=[-1.1, 0.1],
        zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
