Vector Fields & Streamlines

In Section 5.1, we explored phase portraits for pre-built systems. Now let's see how the vector field is constructed. For a linear system \( \dot{\mathbf{x}} = \mathbf{A}\mathbf{x} \), the matrix \( \mathbf{A} \) completely determines the flow. Every arrow in the field comes from one matrix-vector multiplication.

Learning Objectives
  • Build a vector field from the system matrix — see how \( \mathbf{A} = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \) creates the flow
  • Compare arrows and streamlines as two representations of the same dynamics
  • Read flow speed from a phase portrait — fast regions, slow regions, and fixed points
  • Connect matrix parameters (trace, determinant) to qualitative field behavior

Linear system in components:

$$ \dot{x} = ax + by, \qquad \dot{y} = cx + dy $$

At each point \( (x,y) \), the velocity vector is \( (ax+by,\; cx+dy) \). Change the matrix entries → the entire flow changes.

Key Insight

Two numbers summarize the entire matrix: the trace \( \tau = a + d \) and determinant \( \Delta = ad - bc \). These determine the eigenvalues \( \lambda = \tfrac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2} \), which in turn determine the qualitative behavior. You'll explore this classification fully in Section 5.8.

Two Views of the Same Flow

A quiver plot (arrows) and a streamline plot (continuous curves) are two ways to visualize the same vector field. Arrows show the velocity at discrete sample points; streamlines connect them into continuous flow lines. Each streamline is tangent to the arrows everywhere — it's what you'd get by releasing a particle and letting it follow the flow.

Arrows vs Streamlines

Arrows are easy to compute (one evaluation per point) but can be hard to read when the field is complex. Streamlines require numerical integration (each curve is a trajectory) but reveal the global flow pattern at a glance. In practice, physicists use both: arrows for local detail, streamlines for the big picture.

  • Pattern changes: FALSE. The vector field is defined by the equations, not by how densely you sample it. More arrows just give better resolution.
  • Clearer picture: TRUE. More sample points help you see the direction more accurately, especially in regions where the flow changes rapidly.
  • Smoother streamlines: FALSE. Streamlines are computed by integrating the actual equations, not by interpolating between arrows. They don't depend on arrow density at all.

How Fast Does the Flow Go?

Arrows and streamlines show direction, but the speed matters too. At each point, the speed is the magnitude of the velocity vector: \( |\mathbf{v}| = \sqrt{(\dot{x})^2 + (\dot{y})^2} \). Near a fixed point, speed approaches zero — the system barely moves. Far from the fixed point, speed increases. The speed map below uses color to show where the flow is fast (bright) and slow (dark).

Explorer: Speed Map

The background color encodes flow speed: bright = fast, dark = slow. White streamlines show the flow direction. Notice how the darkest region (near-zero speed) always surrounds the fixed point at the origin.

⚠️
Don't confuse speed with direction!

Equal-length arrows (common in textbooks) hide speed information to emphasize direction. Real velocity vectors vary in length — arrows near a source are short at the origin and long far away. The speed map makes this explicit. In later sections, speed differences will help us distinguish node from spiral behavior.

Python 

import numpy as np
import plotly.figure_factory as ff
import plotly.graph_objects as go

# Matrix for a stable spiral
a, b, c, d = -0.2, 1.0, -1.0, -0.2

# Create grid
x = np.linspace(-4, 4, 16)
y = np.linspace(-4, 4, 16)
X, Y = np.meshgrid(x, y)

# Compute velocity field from matrix
U = a * X + b * Y
V = c * X + d * Y

# Create quiver plot
fig = ff.create_quiver(X, Y, U, V,
    scale=0.08, arrow_scale=0.3,
    line=dict(color='#00f3ff', width=1))

# Mark the fixed point
fig.add_trace(go.Scatter(
    x=[0], y=[0], mode='markers',
    marker=dict(color='#ff006e', size=10, symbol='x'),
    name='Fixed point'))

tau = a + d
delta = a * d - b * c
fig.update_layout(
    template='plotly_dark',
    title=f'Stable Spiral (τ={tau:.1f}, Δ={delta:.2f})',
    xaxis=dict(range=[-4, 4], title='x',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    yaxis=dict(range=[-4, 4], title='y',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    width=600, height=600
)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# System: saddle point
a, b, c, d = 1, 0, 0, -1

# Speed heatmap
x = np.linspace(-4, 4, 100)
y = np.linspace(-4, 4, 100)
X, Y = np.meshgrid(x, y)
U = a * X + b * Y
V = c * X + d * Y
speed = np.sqrt(U**2 + V**2)

fig = go.Figure()

# Heatmap
fig.add_trace(go.Heatmap(
    z=speed, x=x, y=y,
    colorscale='Viridis', showscale=True,
    colorbar=dict(title='Speed')))

# Add streamlines via RK4
def rk4_trajectory(x0, y0, dt=0.02, steps=500):
    xs, ys = [x0], [y0]
    xc, yc = x0, y0
    for _ in range(steps):
        k1x, k1y = a*xc + b*yc, c*xc + d*yc
        k2x, k2y = a*(xc+dt/2*k1x) + b*(yc+dt/2*k1y), c*(xc+dt/2*k1x) + d*(yc+dt/2*k1y)
        k3x, k3y = a*(xc+dt/2*k2x) + b*(yc+dt/2*k2y), c*(xc+dt/2*k2x) + d*(yc+dt/2*k2y)
        k4x, k4y = a*(xc+dt*k3x) + b*(yc+dt*k3y), c*(xc+dt*k3x) + d*(yc+dt*k3y)
        xc += dt/6 * (k1x + 2*k2x + 2*k3x + k4x)
        yc += dt/6 * (k1y + 2*k2y + 2*k3y + k4y)
        if abs(xc) > 5 or abs(yc) > 5: break
        xs.append(xc); ys.append(yc)
    return xs, ys

# Launch from all four edges (left-edge-only starts exit
# immediately for the saddle, leaving no visible streamlines)
starts  = [(-4, t) for t in np.linspace(-3, 3, 5)]
starts += [( 4, t) for t in np.linspace(-3, 3, 5)]
starts += [( t, -4) for t in np.linspace(-3, 3, 5)]
starts += [( t,  4) for t in np.linspace(-3, 3, 5)]
for start in starts:
    sx, sy = rk4_trajectory(*start)
    fig.add_trace(go.Scatter(x=sx, y=sy, mode='lines',
        line=dict(color='white', width=1.5),
        showlegend=False))

fig.update_layout(
    template='plotly_dark', title='Speed Map: Saddle Point',
    xaxis=dict(range=[-4,4], title='x',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    yaxis=dict(range=[-4,4], title='y',
        zerolinecolor='#808080', gridcolor='#2a2f4a'),
    width=600, height=600
)
fig.show()
