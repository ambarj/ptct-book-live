Programming Loops for Iteration

In the previous section you learned the Euler formula: \( x_{n+1} = x_n + h \cdot f(x_n, t_n) \). You could execute it by hand for a few steps — but what about 100 steps? 10,000? That’s where loops come in. A loop is the computer’s way of saying “repeat this recipe N times.” Every numerical method you’ll meet — Euler, Runge–Kutta, Monte Carlo — lives inside a loop. Master the loop, and numerical computing opens up.

Learning Objectives
  • Understand the anatomy of a for loop: initialize, update, store
  • Build arrays step-by-step inside loops and watch values accumulate
  • Recognize the update recipe pattern x = x + h * f(x) as the engine behind Euler’s method

Key Insight: The Update Recipe Determines Everything

All three curves come from the same loop structure:

for i in range(N):
    x = [update rule]
    t = t + h

The loop is just plumbing — it repeats the recipe. The physics lives in the update rule. In Euler’s method, that rule is \(x + h \cdot f(x, t)\).

Explorer 3: The Update Recipe — Bridge to Euler

Now we use the exact loop pattern behind Euler’s method: x = x + h * f(x, t). Choose different f(x, t) and watch the loop build the numerical solution step by step.

The Euler Loop Recipe:

$$ \boxed{ \begin{aligned} &\texttt{for } i = 0, 1, \ldots, N-1: \\ &\quad x_{i+1} = x_i + h \cdot f(x_i,\, t_i) \\ &\quad t_{i+1} = t_i + h \end{aligned} } $$

The left panel shows the numerical solution (cyan) vs. the exact answer (gray dashed). The right panel shows how the error at each step grows — smaller \(h\) means smaller error.

⚠️
Watch for instability! Try setting the growth ODE (\(dx/dt = x\)) with \(h = 0.8\). The numerical solution overshoots wildly. Euler’s method can blow up when \(h\) is too large relative to the rate of change. This is the stability limit you’ll study in Section 4.5.

Python: Writing Your Own Loops

Python 

# The anatomy of a for loop
# Initialize → Loop → Store

import numpy as np

# Initialize
x = 0.0
h = 0.5
x_list = [x]       # store initial value

# Loop: repeat 10 times
for i in range(10):
    x = x + h       # update rule (additive)
    x_list.append(x) # store new value

# Result
t = np.arange(0, len(x_list)) * h
print("Steps:", len(x_list) - 1)
print("Final value:", x_list[-1])
print("All values:", [round(v, 2) for v in x_list])

import numpy as np
import plotly.graph_objects as go

h, N = 0.3, 20

# Three update rules, same loop structure
t_arr = [0.0]
x_add = [0.0]   # x = x + 1
x_mult = [1.0]  # x = (1+h) * x
x_quad = [0.0]  # x = x + t

for i in range(N):
    t_new = t_arr[-1] + h
    x_add.append(x_add[-1] + 1.0)
    x_mult.append((1 + h) * x_mult[-1])
    x_quad.append(x_quad[-1] + t_arr[-1] * h)
    t_arr.append(t_new)

fig = go.Figure()
fig.add_trace(go.Scatter(x=t_arr, y=x_add, name='x + 1 (linear)',
    line=dict(color='#00f3ff', width=2), mode='lines+markers'))
fig.add_trace(go.Scatter(x=t_arr, y=x_mult, name='(1+h)·x (exponential)',
    line=dict(color='#ff00ff', width=2), mode='lines+markers'))
fig.add_trace(go.Scatter(x=t_arr, y=x_quad, name='x + t·h (quadratic)',
    line=dict(color='#ffff00', width=2), mode='lines+markers'))

fig.update_layout(
    template='plotly_dark',
    title='Three Growth Patterns from the Same Loop',
    xaxis=dict(title='t', range=[0, N*h],
               gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[0, max(x_mult)*1.1],
               gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# --- The Euler loop recipe ---
def euler_solve(f, x0, t_max, h):
    """Solve dx/dt = f(x, t) using Euler's method."""
    t_list = [0.0]
    x_list = [x0]

    t, x = 0.0, x0
    N = int(t_max / h)

    for i in range(N):
        x = x + h * f(x, t)   # THE update recipe
        t = t + h
        t_list.append(t)
        x_list.append(x)

    return np.array(t_list), np.array(x_list)

# Solve dx/dt = -2x  (exact: exp(-2t))
f = lambda x, t: -2 * x
t_euler, x_euler = euler_solve(f, x0=1.0, t_max=3.0, h=0.2)

# Exact solution for comparison
t_exact = np.linspace(0, 3, 300)
x_exact = np.exp(-2 * t_exact)

fig = go.Figure()
fig.add_trace(go.Scatter(x=t_exact, y=x_exact, name='Exact: exp(-2t)',
    line=dict(color='#808080', width=2, dash='dash')))
fig.add_trace(go.Scatter(x=t_euler, y=x_euler, name='Euler (h=0.2)',
    line=dict(color='#00f3ff', width=2), mode='lines+markers',
    marker=dict(size=6)))

fig.update_layout(
    template='plotly_dark',
    title='Euler Loop in Action: dx/dt = -2x',
    xaxis=dict(title='t', range=[0, 3],
               gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-0.2, 1.2],
               gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
)
fig.show()
