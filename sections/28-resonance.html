Resonance: When Small Forces Win

A child pumps a swing at just the right rhythm. An opera singer shatters a wine glass with a sustained note. A gust of wind topples a suspension bridge. In every case, a small periodic force produces a huge response — because the force is tuned to the system's natural frequency. This is resonance, one of the most powerful and universal phenomena in all of physics.

In the previous section, you saw the amplitude response curve \( A(\omega_d) \) and noticed a peak near \( \omega_0 \). Now we explore that peak in detail: how tall it gets, how sharp it is, and what controls its shape. The answer lies in a single number: the quality factor \( Q \).

Learning Objectives
  • Identify the resonance frequency and explain why the amplitude peaks there
  • Describe how damping controls the height and width of the resonance peak
  • Calculate the quality factor \( Q = \omega_0 / (2\gamma) \) and interpret it physically
  • Read the phase response curve and explain the 90° crossing at resonance

Resonance essentials:

$$ A(\omega_d) = \frac{F_0/m}{\sqrt{(\omega_0^2 - \omega_d^2)^2 + (2\gamma\omega_d)^2}} $$

Resonance frequency: \( \omega_{\text{res}} = \sqrt{\omega_0^2 - 2\gamma^2} \approx \omega_0 \) for small damping
Peak amplitude: \( A_{\text{peak}} \approx \displaystyle\frac{F_0}{2m\gamma\omega_0} \) (inversely proportional to damping)
Quality factor: \( Q = \displaystyle\frac{\omega_0}{2\gamma} = \frac{\omega_0}{\Delta\omega} \approx 2\pi \times \frac{\text{energy stored}}{\text{energy lost per cycle}} \)

Damping Shapes the Peak

The resonance peak isn't fixed — damping controls both its height and width. Light damping (small \( \gamma \)) produces a tall, narrow peak: the system is very selective about which frequency excites it. Heavy damping (large \( \gamma \)) produces a short, broad peak: the system responds similarly to a wide range of frequencies.

The right panel shows the phase response — how much the response lags behind the driving force. At low frequencies the response is nearly in phase (\( \delta \approx 0 \)). At resonance it lags by exactly 90°. Above resonance it approaches 180° (antiphase). Sharper resonances have steeper phase transitions.

Explorer 2: Damping Controls the Resonance
Key Insight

The bandwidth Δω (yellow dashed line) is the width of the peak — specifically, the range of driving frequencies where the response is at least 70% of the peak height (the “half-power” level, since power goes as amplitude squared: 0.7² ≈ 0.5). It turns out that Δω ≈ 2γ. This means Q = ω0/Δω: a high-Q system has a narrow, sharp peak (responds to one frequency and ignores everything else), while a low-Q system has a broad, flat peak.

The Quality Factor Q

The quality factor \( Q \) is the single number that characterizes a resonance. It tells you three things at once:

  • Sharpness of the peak: \( Q = \omega_0 / \Delta\omega \) — a high Q means a narrow, selective peak
  • Amplification at resonance: The peak amplitude is roughly Q times larger than the gentle-push response — resonance amplifies!
  • How long it rings: A high-Q system stores a lot of energy and releases it slowly — it oscillates for about Q cycles after you stop driving it

Key Insight

Real-world Q values span an enormous range. A car suspension has \( Q \approx 2\text{--}5 \) (broad response, quickly settling). A guitar string has \( Q \approx 1000 \) (rings for seconds). An atomic transition has \( Q \sim 10^8 \) (incredibly sharp frequency). A laser cavity can reach \( Q \sim 10^{11} \). The higher the Q, the more precisely the system selects one frequency from all others.

Code It Yourself

Python 
import numpy as np
import plotly.graph_objects as go

def amplitude(F0m, omega0, wd, gamma):
    return F0m / np.sqrt((omega0**2 - wd**2)**2 + (2*gamma*wd)**2)

omega0, F0m = 3.0, 1.0
wd = np.linspace(0.1, 6, 500)

fig = go.Figure()
for gamma, color, label in [
    (0.10, '#00f3ff', 'γ=0.10 (Q=15)'),
    (0.30, '#00ff9f', 'γ=0.30 (Q=5)'),
    (1.00, '#ff00ff', 'γ=1.00 (Q=1.5)')]:
    A = amplitude(F0m, omega0, wd, gamma)
    fig.add_trace(go.Scatter(x=wd, y=A, name=label,
        line=dict(color=color, width=2.5)))

fig.update_layout(template='plotly_dark',
    title='Resonance Curves at Different Damping',
    xaxis=dict(title='ω_d (rad/s)', range=[0, 6],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='Amplitude A', range=[0, 10],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

omega0, F0m = 3.0, 1.0
wd = np.linspace(0.1, 6, 500)

# Amplitude and phase for several Q values
fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Amplitude Response', 'Phase Response'])

for Q, color in [(1, '#ff6b6b'), (5, '#ffff00'), (15, '#00f3ff'), (30, '#00ff9f')]:
    gamma = omega0 / (2*Q)
    A = F0m / np.sqrt((omega0**2 - wd**2)**2 + (2*gamma*wd)**2)
    phase = np.arctan2(2*gamma*wd, omega0**2 - wd**2) * 180/np.pi

    fig.add_trace(go.Scatter(x=wd, y=A, name=f'Q={Q}',
        line=dict(color=color, width=2)), row=1, col=1)
    fig.add_trace(go.Scatter(x=wd, y=phase, showlegend=False,
        line=dict(color=color, width=2)), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.update_xaxes(title='ω_d', gridcolor='#2a2f4a', linecolor='#808080')
fig.update_yaxes(gridcolor='#2a2f4a', linecolor='#808080')
fig.update_yaxes(title='Amplitude', row=1, col=1)
fig.update_yaxes(title='Phase (°)', row=1, col=2)
fig.show()

Pro Tips for Prompting
  • Always specify \( Q = \omega_0 / (2\gamma) \), not \( Q = \omega_0 / \gamma \) (a common confusion)
  • Ask for both amplitude AND phase response — they contain complementary information
  • Request normalized frequency axis (\( \omega_d / \omega_0 \)) for universal curves
