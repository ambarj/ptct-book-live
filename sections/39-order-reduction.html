From Second-Order to First-Order

Your Euler solver handles \(dx/dt = f(x, t)\) beautifully. But the most important equation in physics — Newton’s second law — is second-order. The trick is old and powerful: introduce velocity as a new variable. One second-order equation becomes two first-order equations — and your Euler solver can handle both simultaneously.

Learning Objectives
  • Convert a second-order ODE into a pair of coupled first-order ODEs using the substitution \(v = dx/dt\)
  • Understand the state vector \([x, v]\) as the complete description of a system
  • Apply Euler’s method to the reduced system and recover familiar oscillator behavior
$$ m\frac{d^2x}{dt^2} = F(x, \dot{x}, t) $$

Two time derivatives, not one. Euler can’t handle this directly.

The Universal Recipe

For any second-order ODE \(\ddot{x} = F(x, \dot{x}, t)\):

$$ \boxed{ \text{Define } v = \frac{dx}{dt}, \quad \text{then:} \quad \begin{cases} \dfrac{dx}{dt} = v \\[6pt] \dfrac{dv}{dt} = F(x, v, t) \end{cases} } $$

The state vector \(\mathbf{y} = [x, v]\) contains everything you need to know about the system at any instant. Position and velocity together determine the future.

In the Euler update for a two-equation system, which statement is correct?
Explanation: In the standard Euler method, you compute all derivatives at time \(t_n\) using the current state \((x_n, v_n)\), then update both simultaneously: \(x_{n+1} = x_n + h \cdot v_n\) and \(v_{n+1} = v_n + h \cdot F(x_n, v_n, t_n)\). Using old values for both updates is crucial — mixing old and new gives a different (symplectic Euler) method.
Which of the following can be solved by reducing to first-order and applying Euler? (Select all that apply.)
Explanation:
  • SHO: Yes — \(dx/dt = v\), \(dv/dt = -\omega^2 x\).
  • Pendulum: Yes — the \(\sin\theta\) makes it analytically unsolvable, but numerically trivial.
  • Algebraic: No — this isn’t a differential equation! No time derivatives.
  • Driven oscillator: Yes — \(dx/dt = v\), \(dv/dt = -2\gamma v - \omega_0^2 x + F_0\cos(\omega_d t)\).

Python: Euler for Second-Order ODEs

Python 

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# --- The Reduction ---
# Original: d²x/dt² = -ω²x  (SHO)
# Reduced:  dx/dt = v
#           dv/dt = -ω²x

omega = 2.0
x0, v0 = 1.0, 0.0    # Initial: displaced, at rest
h = 0.01
t_max = 10.0
N = int(t_max / h)

# Euler loop for TWO equations
t_list, x_list, v_list = [0.0], [x0], [v0]
x, v, t = x0, v0, 0.0

for i in range(N):
    # Compute BOTH derivatives using OLD values
    dx = v
    dv = -omega**2 * x

    # Update BOTH simultaneously
    x = x + h * dx
    v = v + h * dv
    t = t + h

    t_list.append(t)
    x_list.append(x)
    v_list.append(v)

# Exact solution for comparison
t_ex = np.linspace(0, t_max, 1000)
x_ex = np.cos(omega * t_ex)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Time Series', 'Phase Portrait'])

fig.add_trace(go.Scatter(x=t_ex, y=x_ex, name='Exact',
    line=dict(color='#808080', dash='dash')), row=1, col=1)
fig.add_trace(go.Scatter(x=t_list, y=x_list, name='Euler x(t)',
    line=dict(color='#00f3ff', width=1.5)), row=1, col=1)

fig.add_trace(go.Scatter(x=x_list, y=v_list, name='Phase',
    line=dict(color='#ff00ff', width=1.5), mode='lines'), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

def euler_system(f, y0, t_max, h):
    """Euler for a system: y' = f(y, t), y = [x, v, ...]"""
    t_list = [0.0]
    y_list = [np.array(y0)]
    y, t = np.array(y0, dtype=float), 0.0

    for i in range(int(t_max / h)):
        dy = np.array(f(y, t))  # Derivatives at current state
        y = y + h * dy           # Update ALL components
        t = t + h
        t_list.append(t)
        y_list.append(y.copy())

    return np.array(t_list), np.array(y_list)

# Damped oscillator: ω₀=2, γ=0.3
omega0, gamma = 2.0, 0.3

def damped_osc(y, t):
    x, v = y
    return [v, -2*gamma*v - omega0**2 * x]

t, Y = euler_system(damped_osc, [1.0, 0.0], 15.0, 0.01)

fig = go.Figure()
fig.add_trace(go.Scatter(x=Y[:,0], y=Y[:,1], name='Phase',
    line=dict(color='#ff00ff', width=1.5), mode='lines'))
fig.update_layout(
    template='plotly_dark',
    title='Damped Oscillator Phase Portrait',
    xaxis=dict(title='x', gridcolor='#2a2f4a',
        zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='v', gridcolor='#2a2f4a',
        zerolinecolor='#808080', linecolor='#808080'),
)
fig.show()
