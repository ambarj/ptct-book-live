1D Linearization: The Basics

So far you’ve analyzed linear systems where everything is determined by eigenvalues. But most real systems are nonlinear. The key insight: near a fixed point, every smooth system looks linear. Zoom in close enough, and curves become straight lines. This is linearization — the most powerful tool in dynamical systems. We start with the simplest case: one dimension.

Learning Objectives
  • Find fixed points of a 1D system \( \dot{x} = f(x) \) by solving \( f(x_0) = 0 \)
  • Linearize near a fixed point using Taylor expansion: \( f(x) \approx f'(x_0)(x - x_0) \)
  • Determine stability from the sign of \( \lambda = f'(x_0) \): negative → stable, positive → unstable
  • Understand when linearization fails: far from the fixed point, or when \( f'(x_0) = 0 \)

The Linearization Recipe (1D):

$$ \dot{x} = f(x) \quad\xrightarrow{\text{near } x_0}\quad \dot{y} \approx \lambda\, y $$

where \( y = x - x_0 \) is the deviation from the fixed point and \( \lambda = f'(x_0) \) is the derivative evaluated at the fixed point. The solution is \( y(t) = y_0\, e^{\lambda t} \) — exponential growth (\( \lambda > 0 \)) or decay (\( \lambda < 0 \)).

Why Linearization Works

Taylor’s theorem says \( f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{1}{2}f''(x_0)(x - x_0)^2 + \cdots \). At a fixed point, \( f(x_0) = 0 \). If \( x \) is close to \( x_0 \), the \( (x - x_0)^2 \) and higher terms are tiny compared to \( (x - x_0) \). So \( f(x) \approx f'(x_0)(x - x_0) \) — the system is effectively linear. The approximation breaks down when \( |x - x_0| \) is large enough that quadratic terms matter.

Which statements about 1D linearization are true? (Select all)
Explanation:
  • Only stable/unstable: ✓ In 1D there’s only one eigenvalue \( \lambda = f'(x_0) \). It’s either positive (unstable), negative (stable), or zero (indeterminate). No room for spirals or saddles.
  • Always correct when f' = 0: ✗ When \( f'(x_0) = 0 \), the linear term vanishes. You need higher-order terms to determine stability. Linearization is inconclusive.
  • Exact for polynomials: ✗ The linearization drops quadratic and higher terms, even for polynomials. It’s only exact for truly linear systems \( f(x) = \lambda x \).
  • Decay rate: ✓ Near the fixed point, \( y(t) \approx y_0 e^{\lambda t} \). The timescale is \( \tau = 1/|\lambda| \). Larger \( |\lambda| \) = faster return.

When Linearization Fails

Linearization tells you the local behavior near a fixed point. It fails in two situations:

  • Too far from the fixed point: Nonlinear terms dominate. The comparison plot shows this — increase the deviation and watch the linearized prediction diverge from reality.
  • \( f'(x_0) = 0 \): The linear term vanishes, and the quadratic or higher terms determine stability. This is a non-hyperbolic fixed point — linearization is inconclusive.

What is the practical takeaway of linearization?
Explanation: Linearization doesn’t replace simulation — it complements it. Its power is in classification: a single derivative \( f'(x_0) \) tells you whether a fixed point is stable or unstable, without solving any ODE. For the full trajectory far from the fixed point, you still need numerical methods.

import numpy as np
import plotly.graph_objects as go

# Logistic equation: ẋ = rx(1 - x/K)
r, K = 2.0, 5.0
f = lambda x: r * x * (1 - x / K)
fp = lambda x: r * (1 - 2 * x / K)  # f'(x)

x = np.linspace(-1, 7, 400)

fig = go.Figure()

# f(x) — the velocity function
fig.add_trace(go.Scatter(
    x=x, y=f(x), mode='lines',
    line=dict(color='#00f3ff', width=2.5), name='f(x)'))

# Zero line
fig.add_trace(go.Scatter(
    x=[-1, 7], y=[0, 0], mode='lines',
    line=dict(color='#808080', width=1, dash='dot'),
    showlegend=False))

# Fixed points and their linearizations
fps = [0, K]
colors = ['#ff006e', '#00ff88']
for x0, col in zip(fps, colors):
    lam = fp(x0)
    label = f'x₀={x0}, λ={lam:.1f}'
    # Tangent line
    x_lin = np.linspace(x0 - 2, x0 + 2, 100)
    fig.add_trace(go.Scatter(
        x=x_lin, y=lam * (x_lin - x0), mode='lines',
        line=dict(color=col, width=2, dash='dash'),
        name=f'Linear: {label}'))
    # Fixed point marker
    fig.add_trace(go.Scatter(
        x=[x0], y=[0], mode='markers',
        marker=dict(color=col, size=12,
            symbol='circle' if lam < 0 else 'circle-open',
            line=dict(color='white', width=2)),
        name='Stable' if lam < 0 else 'Unstable'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='x', range=[-1, 7],
               zerolinecolor='#808080'),
    yaxis=dict(title='f(x) = ẋ', range=[-5, 5],
               zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# Compare exact vs linearized near stable FP
r, K = 2.0, 5.0
f = lambda x: r * x * (1 - x / K)
lam = -r  # f'(K) = -r

# Euler solver for 1D
def solve_1d(f, x0, T, N):
    h = T / N; xs, ts = [x0], [0.0]
    x = x0
    for i in range(N):
        k1 = f(x); k2 = f(x + h/2*k1)
        k3 = f(x + h/2*k2); k4 = f(x + h*k3)
        x += h/6*(k1 + 2*k2 + 2*k3 + k4)
        xs.append(x); ts.append((i+1)*h)
    return np.array(ts), np.array(xs)

fig = go.Figure()
deviations = [0.3, 1.0, 2.0, 4.0]
colors = ['#00f3ff', '#ffbe0b', '#ff006e', '#ff5722']

for y0, col in zip(deviations, colors):
    x0 = K + y0
    t, x_exact = solve_1d(f, x0, 5, 1000)
    x_linear = K + y0 * np.exp(lam * t)

    fig.add_trace(go.Scatter(
        x=t, y=x_exact, mode='lines',
        line=dict(color=col, width=2),
        name=f'Exact (y₀={y0})'))
    fig.add_trace(go.Scatter(
        x=t, y=x_linear, mode='lines',
        line=dict(color=col, width=1.5, dash='dash'),
        name=f'Linear (y₀={y0})'))

# K reference
fig.add_trace(go.Scatter(
    x=[0, 5], y=[K, K], mode='lines',
    line=dict(color='#808080', width=1, dash='dot'),
    showlegend=False))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='Time', range=[0, 5],
               zerolinecolor='#808080'),
    yaxis=dict(title='x(t)', range=[0, 10],
               zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
