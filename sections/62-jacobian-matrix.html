Jacobian Matrix for 2D Systems

In 1D, linearization meant computing one derivative: \( \lambda = f'(x_0) \). In 2D, you have two functions \( f(x,y) \) and \( g(x,y) \), each depending on two variables. The derivative becomes a matrix of partial derivatives — the Jacobian. It plays exactly the same role as the matrix \( A \) in linear systems: its eigenvalues determine stability.

Learning Objectives
  • Compute the Jacobian matrix \( J = \begin{pmatrix} \partial f/\partial x & \partial f/\partial y \\ \partial g/\partial x & \partial g/\partial y \end{pmatrix} \) for a 2D system
  • Evaluate \( J \) at a fixed point to obtain the linearization matrix
  • Understand that near a fixed point, \( \dot{\mathbf{Y}} \approx J\,\mathbf{Y} \) — the nonlinear system looks linear
  • Connect the Jacobian’s eigenvalues to the τ-Δ classification from Section 5.8

The 2D Linearization Recipe:

$$ \dot{x} = f(x,y),\quad \dot{y} = g(x,y) \quad\xrightarrow{\text{near } (x_0, y_0)}\quad \dot{\mathbf{Y}} \approx J\,\mathbf{Y} $$

where \( \mathbf{Y} = (x - x_0,\; y - y_0) \) and the Jacobian is:

$$ J = \begin{pmatrix} \dfrac{\partial f}{\partial x} & \dfrac{\partial f}{\partial y} \\[6pt] \dfrac{\partial g}{\partial x} & \dfrac{\partial g}{\partial y} \end{pmatrix}\Bigg|_{(x_0, y_0)} $$

Reading the Jacobian

Each entry of \( J \) answers a specific question:

  • \( \partial f/\partial x \): How does the x-velocity change when x increases? (Self-feedback in x)
  • \( \partial f/\partial y \): How does the x-velocity change when y increases? (Cross-coupling: y affects x)
  • \( \partial g/\partial x \): How does the y-velocity change when x increases? (Cross-coupling: x affects y)
  • \( \partial g/\partial y \): How does the y-velocity change when y increases? (Self-feedback in y)

The diagonal entries are self-effects; the off-diagonal entries are interactions.

Select Lotka-Volterra and the fixed point at the origin (0, 0). What type of fixed point is it?
Explanation: At (0, 0) the Jacobian for the standard Lotka-Volterra system gives eigenvalues with opposite signs (one positive, one negative). This is a saddle: the extinction equilibrium is unstable. Any small population of prey grows (positive eigenvalue), but predators without prey die (negative eigenvalue).
Now select the coexistence fixed point of Lotka-Volterra. What type is it?
Explanation: At the coexistence point, the Jacobian has \( \tau = 0 \) (trace zero) and \( \Delta > 0 \). This sits on the τ = 0 axis inside the parabola — a center. The linearization predicts eternal oscillation. (For the full nonlinear system, these are indeed closed orbits.)
For the Lotka–Volterra system \( \dot{x} = x(2 - y) \), \( \dot{y} = y(-1 + x) \), which Jacobian entries vanish at the coexistence point \( (1, 2) \)?
Explanation: The Jacobian is \( J = \begin{pmatrix} 2 - y & -x \\ y & -1 + x \end{pmatrix} \). At \( (1, 2) \) the diagonal entries \( 2 - y = 0 \) and \( -1 + x = 0 \) both vanish — the self-feedback terms — while the off-diagonals stay \( -x = -1 \) and \( y = 2 \). So \( J = \begin{pmatrix} 0 & -1 \\ 2 & 0 \end{pmatrix} \), giving \( \tau = 0 \) and \( \Delta = 2 > 0 \). That zero trace is exactly why the linearization predicts a center — the undamped oscillation of predator and prey.

Python Code

Python 

import numpy as np

# Lotka-Volterra: ẋ = x(2 - y), ẏ = y(-1 + x)
# f(x,y) = x(2 - y),  g(x,y) = y(-1 + x)

# Jacobian (by hand):
# J = [[∂f/∂x, ∂f/∂y], [∂g/∂x, ∂g/∂y]]
#   = [[2 - y,  -x  ],  [y,    -1 + x]]

def jacobian_lv(x, y):
    return np.array([[2 - y, -x],
                     [y, -1 + x]])

# Fixed points: f = g = 0
# x(2-y)=0 → x=0 or y=2
# y(-1+x)=0 → y=0 or x=1
# FP1: (0,0), FP2: (1,2)

fps = [(0, 0), (1, 2)]
for x0, y0 in fps:
    J = jacobian_lv(x0, y0)
    tau = np.trace(J)
    delta = np.linalg.det(J)
    evals = np.linalg.eigvals(J)
    print(f'\nFixed point ({x0}, {y0}):')
    print(f'  J = {J.tolist()}')
    print(f'  τ = {tau:.2f}, Δ = {delta:.2f}')
    print(f'  λ = {evals}')
    if delta < 0:
        print('  → Saddle')
    elif abs(tau) < 0.01:
        print('  → Center')
    elif tau < 0:
        print('  → Stable (spiral or node)')
    else:
        print('  → Unstable')

import numpy as np
import plotly.graph_objects as go

def rk4(f, g, x0, y0, T, N):
    h = T/N; X, Y = [x0], [y0]; x, y = x0, y0
    for _ in range(N):
        k1x, k1y = f(x,y), g(x,y)
        k2x, k2y = f(x+h/2*k1x,y+h/2*k1y), g(x+h/2*k1x,y+h/2*k1y)
        k3x, k3y = f(x+h/2*k2x,y+h/2*k2y), g(x+h/2*k2x,y+h/2*k2y)
        k4x, k4y = f(x+h*k3x,y+h*k3y), g(x+h*k3x,y+h*k3y)
        x += h/6*(k1x+2*k2x+2*k3x+k4x)
        y += h/6*(k1y+2*k2y+2*k3y+k4y)
        if abs(x)>20 or abs(y)>20: break
        X.append(x); Y.append(y)
    return np.array(X), np.array(Y)

# Competing species: ẋ=x(3-x-2y), ẏ=y(2-x-y)
f = lambda x,y: x*(3-x-2*y)
g = lambda x,y: y*(2-x-y)

# Fixed points: (0,0), (3,0), (0,2), (1,1)
fps = [(0,0,'Origin'), (3,0,'Species 1 wins'),
       (0,2,'Species 2 wins'), (1,1,'Coexistence')]

fig = go.Figure()
colors = ['#00f3ff','#ff006e','#ffbe0b','#00ff88',
          '#bb86fc','#ff5722','#76ff03','#40c4ff']

for k in range(8):
    th = k*np.pi/4
    X, Y = rk4(f, g, 0.1+1.5*np.cos(th), 0.1+1.5*np.sin(th), 15, 3000)
    fig.add_trace(go.Scatter(x=X, y=Y, mode='lines',
        line=dict(color=colors[k], width=1.5), showlegend=False))

for x0, y0, label in fps:
    J = np.array([[3-2*x0-2*y0, -2*x0], [-y0, 2-x0-2*y0]])
    delta = np.linalg.det(J)
    sym = 'circle' if delta > 0 and np.trace(J) < 0 else 'circle-open'
    fig.add_trace(go.Scatter(x=[x0], y=[y0], mode='markers+text',
        marker=dict(color='#ffbe0b', size=10, symbol=sym,
            line=dict(color='white', width=2)),
        text=[label], textposition='top center',
        textfont=dict(color='white', size=9), showlegend=False))

fig.update_layout(template='plotly_dark',
    xaxis=dict(title='Species 1', range=[-0.5, 4],
        zerolinecolor='#808080'),
    yaxis=dict(title='Species 2', range=[-0.5, 3],
        zerolinecolor='#808080'),
    height=500, width=600)
fig.show()
