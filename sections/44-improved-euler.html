Improved Euler Method (RK2)

Euler's method uses the slope at the start of each interval to predict where to go next. That's like driving with your eyes fixed on the road right in front of you — it works, but you drift. What if you could peek ahead to see where the road is going?

Learning Objectives
  • Understand the core idea: evaluating the slope at the midpoint cancels the leading error term
  • Implement the RK2 (midpoint method) recipe and compare it to Euler
  • Verify second-order convergence \( O(h^2) \) — halving \( h \) reduces error by 4×
  • See how RK2 conserves energy far better than Euler for oscillatory systems

The Improved Euler Method (also called the Midpoint Method or RK2) does exactly this:

The RK2 Recipe:

$$ \begin{aligned} k_1 &= f(t_n,\, y_n) & &\text{(slope at start)} \\[4pt] k_2 &= f\!\left(t_n + \tfrac{h}{2},\, y_n + \tfrac{h}{2}\,k_1\right) & &\text{(slope at midpoint)} \\[4pt] y_{n+1} &= y_n + h\,k_2 & &\text{(step using midpoint slope)} \end{aligned} $$

Two evaluations of \( f \) per step instead of one, but the payoff is enormous: the global error drops from \( O(h) \) to \( O(h^2) \).

Think of it as a scout-and-step strategy: use Euler to scout to the midpoint, read the slope there, then go back and take the full step with the improved slope.

Why the Midpoint?

The Taylor expansion of the exact solution involves both \( f \) and \( f' \). By evaluating \( f \) at the midpoint, the RK2 formula automatically captures the first correction term — no derivatives needed! This is the magic of Runge-Kutta methods: they trade extra function evaluations for higher-order accuracy without computing any derivatives of \( f \).

Measuring the Improvement

In Section 4.10 you learned to measure convergence order with log-log plots. Now let's see how RK2 compares to Euler on the same plot. The slope tells the story:

Convergence Orders:

$$ \text{Euler: error} \propto h^1 \quad(\text{slope = 1}) \qquad \text{RK2: error} \propto h^2 \quad(\text{slope = 2}) $$

This means halving \( h \) reduces Euler's error by 2× but RK2's error by 4×.

RK2 isn't perfect either:

RK2 doesn't exactly conserve energy — a tiny drift (of order \( h^4 \) per step for the SHO) remains. import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler(f, y0, T, h):
    """Euler method for systems: y' = f(t, y)."""
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0)))
    y[0] = y0
    for i in range(len(t) - 1):
        y[i+1] = y[i] + h * np.array(f(t[i], y[i]))
    return t, y

def rk2(f, y0, T, h):
    """RK2 (midpoint method) for systems: y' = f(t, y)."""
    t = np.arange(0, T + h/2, h)
    y = np.zeros((len(t), len(y0)))
    y[0] = y0
    for i in range(len(t) - 1):
        k1 = np.array(f(t[i], y[i]))
        k2 = np.array(f(t[i] + h/2, y[i] + h/2 * k1))
        y[i+1] = y[i] + h * k2
    return t, y

# Simple harmonic oscillator: x'' = -x
# System: dx/dt = v, dv/dt = -x
f_sho = lambda t, y: [y[1], -y[0]]

h = 0.15
T = 30
t_euler, y_euler = euler(f_sho, [1, 0], T, h)
t_rk2, y_rk2 = rk2(f_sho, [1, 0], T, h)
t_exact = np.linspace(0, T, 1000)
x_exact = np.cos(t_exact)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Position vs Time', 'Phase Portrait'])

fig.add_trace(go.Scatter(x=t_exact, y=x_exact, name='Exact',
    line=dict(color='#808080', dash='dash')), row=1, col=1)
fig.add_trace(go.Scatter(x=t_euler, y=y_euler[:,0], name='Euler',
    line=dict(color='#00f3ff')), row=1, col=1)
fig.add_trace(go.Scatter(x=t_rk2, y=y_rk2[:,0], name='RK2',
    line=dict(color='#00ff9f')), row=1, col=1)

fig.add_trace(go.Scatter(x=y_euler[:,0], y=y_euler[:,1],

import numpy as np
import plotly.graph_objects as go

def euler_scalar(f, y0, T, h):
    t = np.arange(0, T + h/2, h)
    y = np.zeros(len(t)); y[0] = y0
    for i in range(len(t) - 1):
        y[i+1] = y[i] + h * f(t[i], y[i])
    return t, y

def rk2_scalar(f, y0, T, h):
    t = np.arange(0, T + h/2, h)
    y = np.zeros(len(t)); y[0] = y0
    for i in range(len(t) - 1):
        k1 = f(t[i], y[i])
        k2 = f(t[i] + h/2, y[i] + h/2 * k1)
        y[i+1] = y[i] + h * k2
    return t, y

# Test: dy/dt = -y, exact: y = exp(-t)
f = lambda t, y: -y
T = 5.0

h_values = np.logspace(-4, 0, 30)
euler_errs, rk2_errs = [], []

for h in h_values:
    _, ye = euler_scalar(f, 1.0, T, h)
    _, yr = rk2_scalar(f, 1.0, T, h)
    exact = np.exp(-T)
    euler_errs.append(abs(ye[-1] - exact))
    rk2_errs.append(abs(yr[-1] - exact))

fig = go.Figure()
fig.add_trace(go.Scatter(x=h_values, y=euler_errs,
    name='Euler O(h)', mode='markers+lines',
    line=dict(color='#00f3ff')))
fig.add_trace(go.Scatter(x=h_values, y=rk2_errs,
    name='RK2 O(h²)', mode='markers+lines',
    line=dict(color='#00ff9f')))

# Reference lines
fig.add_trace(go.Scatter(x=[1e-4, 1], y=[1e-4, 1],
    name='slope=1', line=dict(color='#808080', dash='dot')))
fig.add_trace(go.Scatter(x=[1e-4, 1], y=[1e-8, 1],
    name='slope=2', line=dict(color='#ff00ff', dash='dot')))

fig.update_layout(template='plotly_dark',
    xaxis=dict(type='log', title='Step size h',
               gridcolor='#2a2f4a', linecolor='#808080'),
    yaxis=dict(type='log', title='|Error at t=T|',
               gridcolor='#2a2f4a', linecolor='#808080'),
    title='Euler vs RK2 Convergence')
fig.show()
