Lissajous Figures

So far we've added waves that move in the same direction. What happens when two oscillations act perpendicularly — one driving \( x(t) \) and the other driving \( y(t) \)? The result is a Lissajous figure: a parametric curve in the \( x \)-\( y \) plane whose shape encodes the frequency ratio and phase relationship. These patterns appear everywhere — on oscilloscopes, in laser shows, and even in planetary orbits.

Learning Objectives
  • Generate Lissajous figures from perpendicular oscillations \( x(t) \) and \( y(t) \)
  • Predict the shape from the frequency ratio and phase difference
  • Distinguish closed curves (rational \( \omega_x/\omega_y \)) from space-filling trajectories (irrational ratio)
  • Identify classic patterns: line, circle, ellipse, figure-8, trefoil

Perpendicular oscillations:

$$ x(t) = A_x\cos(\omega_x\, t + \phi_x), \qquad y(t) = A_y\cos(\omega_y\, t + \phi_y) $$

The trajectory \( (x(t),\, y(t)) \) traces a curve that depends on three things: the frequency ratio \( \omega_x/\omega_y \), the phase difference \( \Delta\phi = \phi_y - \phi_x \), and the amplitude ratio \( A_x/A_y \).

Interactive: Lissajous Generator
Key Insight

When \( \omega_x = \omega_y \) (1:1 ratio), the Lissajous figure is always an ellipse (or degenerate cases: a circle at \( \Delta\phi = 90° \), a straight line at \( \Delta\phi = 0° \) or \( 180° \)). The math behind this is the equation \( x^2/A_x^2 + y^2/A_y^2 - 2xy\cos(\Delta\phi)/(A_x A_y) = \sin^2(\Delta\phi) \), which is always an ellipse. Try sweeping φy from 0° to 360° with \( \omega_x = \omega_y = 1 \) to watch the ellipse rotate and degenerate.

Set ωx = 1, ωy = 1, φx = 0, φy = 90°. What shape do you see?
Explanation
With equal frequencies and a 90° phase difference, \( x = \cos(t) \) and \( y = \cos(t + \pi/2) = -\sin(t) \). This gives \( x^2 + y^2 = 1 \) — a perfect circle! The two perpendicular oscillations are "in quadrature," each reaching its peak when the other crosses zero.
Set ωx = 1, ωy = 2, φy = 90°. How many lobes does the figure have?
Explanation
With \( \omega_y = 2\omega_x \), the \( y \)-oscillation completes two full cycles for every one \( x \)-cycle. At \( \phi_y = 90^\circ \) this traces a figure-8 with two lobes. (At \( \phi_y = 0 \) the same 1:2 ratio collapses onto the parabola \( y = 2x^2 - 1 \) — try it!) In general, the number of lobes stacked in the \( y \)-direction equals \( \omega_y/\omega_x \) when the ratio is a simple fraction.
Set ωx = 2, ωy = 3. Count the number of times the curve touches the right edge (x = 1).

Explanation
The curve touches \( x = 1 \) whenever \( \cos(\omega_x t) = 1 \). Over one closed period of the pattern that happens \( \omega_x/\gcd(\omega_x,\omega_y) = 2 \) times — so the right edge is touched 2 times. (The top edge, by the same argument with \( y \), is touched \( \omega_y/\gcd = 3 \) times.) Counting edge touches is the classic trick for reading a frequency ratio off an oscilloscope.

Closed or Open?

The deepest question about Lissajous figures: does the curve close? If \( \omega_x/\omega_y \) is a rational number (a ratio of integers), the curve eventually returns to its starting point and closes. If it's irrational (like \( \sqrt{2} \) or \( \pi \)), the curve never closes — given enough time, it fills the entire rectangle \( [-1,1] \times [-1,1] \). This is called ergodic behaviour: the trajectory explores all accessible space.

Interactive: Rational vs Irrational
Key Insight

Start with the default ratio \( \sqrt{2} \approx 1.414 \) (irrational) and increase the cycles to 50. The curve fills the rectangle more and more densely — it never closes. Now click Snap: ON to round \( \sqrt{2} \) to the nearest simple fraction (probably 7/5 = 1.40). Instantly the curve closes! The green start dot and red end cross nearly overlap. This demonstrates the fundamental difference: rational ratios give periodic, closed trajectories; irrational ratios give quasi-periodic, space-filling ones.

  • True: This is the ergodic hypothesis. The Lissajous figure with irrational ratio is a beautiful 2D example: the trajectory explores all of the accessible \( [-1,1] \times [-1,1] \) region, just as a gas molecule explores all of phase space.

Python Code

Here's the Python equivalent for generating and exploring Lissajous figures.

Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

t = np.linspace(0, 40*np.pi, 5000)
wx, wy = 1, 2         # frequency ratio 1:2
phi_x, phi_y = 0, 0   # phase difference = 0

x = np.cos(wx*t + phi_x)
y = np.cos(wy*t + phi_y)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Lissajous Figure', 'Time Domain'])

# Parametric plot
fig.add_trace(go.Scatter(x=x, y=y, mode='lines',
    line=dict(color='#00f3ff', width=1.5), showlegend=False), row=1, col=1)

# Time domain
fig.add_trace(go.Scatter(x=t[:500], y=x[:500], name='x(t)',
    line=dict(color='#00f3ff', width=1.5)), row=1, col=2)
fig.add_trace(go.Scatter(x=t[:500], y=y[:500], name='y(t)',
    line=dict(color='#ff00ff', width=1.5)), row=1, col=2)

fig.update_xaxes(gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080')
fig.update_yaxes(gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080')
fig.update_xaxes(scaleanchor='y', row=1, col=1)
fig.update_layout(template='plotly_dark', height=450,
    title=f'Lissajous: ωx:ωy = {wx}:{wy}, Δφ = {np.degrees(phi_y-phi_x):.0f}°')
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

t = np.linspace(0, 40*np.pi, 5000)

# Classic Lissajous patterns
patterns = [
    (1, 1, 0,        'Line (1:1, 0°)'),
    (1, 1, np.pi/2,  'Circle (1:1, 90°)'),
    (1, 2, 0,        'Figure-8 (1:2, 0°)'),
    (2, 3, 0,        'Trefoil (2:3, 0°)'),
    (3, 4, 0,        'Star (3:4, 0°)'),
    (1, np.sqrt(2), np.pi/4, 'Irrational (1:√2)')
]

fig = make_subplots(rows=2, cols=3,
    subplot_titles=[p[3] for p in patterns])

for idx, (wx, wy, dphi, label) in enumerate(patterns):
    r, c = idx // 3 + 1, idx % 3 + 1
    x = np.cos(wx * t)
    y = np.cos(wy * t + dphi)
    fig.add_trace(go.Scatter(x=x, y=y, mode='lines',
        line=dict(color='#00f3ff', width=1), showlegend=False), row=r, col=c)

fig.update_xaxes(range=[-1.3, 1.3], scaleanchor='y',
    gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080')
fig.update_yaxes(range=[-1.3, 1.3],
    gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080')
fig.update_layout(template='plotly_dark', height=700,
    title='Lissajous Pattern Gallery')
fig.show()
