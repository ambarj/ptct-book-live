Error Analysis: The 1/√N Rule

You’ve seen Monte Carlo estimates get better with more samples. But how much better? The answer is precise: the error drops as \( \sigma / \sqrt{N} \). This is a direct consequence of the central limit theorem. It means doubling your accuracy requires four times the work — slow, but dimension-independent. In this section you’ll verify this law, compare it to deterministic methods, and understand exactly when Monte Carlo is the right tool.

Learning Objectives
  • Derive the MC error formula \( \epsilon = \sigma_f / \sqrt{N} \) from the central limit theorem
  • Verify the \( 1/\sqrt{N} \) scaling on a log-log plot (slope = −1/2)
  • Compare MC convergence (\( N^{-1/2} \)) to trapezoidal rule (\( N^{-2} \)) and see that MC loses in 1D
  • Understand the dimensional crossover: MC becomes competitive above ~4 dimensions

The MC Error Formula:

$$ \epsilon_N = \frac{\sigma_f}{\sqrt{N}}, \qquad \sigma_f^2 = \frac{1}{N-1}\sum_{i=1}^{N}\bigl(f(x_i) - \bar{f}\bigr)^2 $$

The error depends on two things: the sample standard deviation \( \sigma_f \) (a property of the function) and the number of samples \( N \) (under your control). To halve the error: quadruple N.

Explorer: Verifying the 1/√N Law

Run the MC integral many times at each value of N. The spread of the estimates measures the true error. On a log-log plot, the error vs N should be a straight line with slope −1/2. Try different functions — the slope is always the same.

Why 1/√N? The Central Limit Theorem

Each sample \( f(x_i) \) is a random variable with mean \( \mu \) and variance \( \sigma^2 \). The sample average \( \bar{f} = \frac{1}{N}\sum f(x_i) \) has variance \( \sigma^2 / N \) (by CLT). Taking the square root: the standard error is \( \sigma / \sqrt{N} \). This is universal — it doesn’t depend on the function, the dimension, or the distribution. Only two things matter: the variance of the integrand and the number of samples.

What is the fundamental reason MC wins in high dimensions?
Explanation: The key insight: MC error \( \sigma/\sqrt{N} \) depends on N and σ only — not on dimension. Grid-based methods have error \( \propto N^{-p/d} \) where \( p \) is the method order. As \( d \) grows, the exponent \( p/d \to 0 \) and the grid method becomes useless. MC doesn’t care about \( d \) at all. This is Monte Carlo’s fundamental advantage.

import numpy as np
import plotly.graph_objects as go

# Verify 1/√N scaling for MC integration of ∫₀¹ 1/(1+x) dx
f = lambda x: 1 / (1 + x)
true_val = np.log(2)
n_trials = 200

Ns = [50, 100, 200, 500, 1000, 2000, 5000, 10000]
errors = []

for N in Ns:
    estimates = []
    for _ in range(n_trials):
        x = np.random.uniform(0, 1, N)
        estimates.append(np.mean(f(x)))
    errors.append(np.std(estimates))

# Fit slope on log-log
log_N = np.log10(Ns)
log_err = np.log10(errors)
slope = np.polyfit(log_N, log_err, 1)[0]
print(f'Log-log slope: {slope:.3f} (expected: -0.500)')

fig = go.Figure()
fig.add_trace(go.Scatter(
    x=Ns, y=errors, mode='markers+lines',
    marker=dict(color='#00f3ff', size=10),
    line=dict(color='#00f3ff', width=2),
    name=f'Measured (slope = {slope:.2f})'))

# Reference 1/√N line
N_ref = np.array([50, 10000])
fig.add_trace(go.Scatter(
    x=N_ref, y=errors[0] * np.sqrt(Ns[0]) / np.sqrt(N_ref),
    mode='lines',
    line=dict(color='white', width=1.5, dash='dash'),
    name='1/√N reference'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='N', type='log', zerolinecolor='#808080'),
    yaxis=dict(title='Standard error', type='log',
               zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
Python 

import numpy as np
import plotly.graph_objects as go

# Compare MC vs trapezoidal for ∫₀¹ 1/(1+x) dx
f = lambda x: 1 / (1 + x)
true_val = np.log(2)

Ns = [10, 20, 50, 100, 200, 500, 1000, 2000, 5000]
mc_errors, trap_errors = [], []

for N in Ns:
    # Trapezoidal rule
    x = np.linspace(0, 1, N + 1)
    h = 1.0 / N
    trap = h * (f(x[0])/2 + np.sum(f(x[1:-1])) + f(x[-1])/2)
    trap_errors.append(abs(trap - true_val))

    # MC (average over trials)
    errs = []
    for _ in range(100):
        xr = np.random.uniform(0, 1, N)
        errs.append(abs(np.mean(f(xr)) - true_val))
    mc_errors.append(np.mean(errs))

fig = go.Figure()
fig.add_trace(go.Scatter(x=Ns, y=mc_errors, mode='markers+lines',
    marker=dict(color='#00f3ff', size=8),
    line=dict(color='#00f3ff', width=2),
    name='Monte Carlo (slope ≈ -0.5)'))
fig.add_trace(go.Scatter(x=Ns, y=trap_errors, mode='markers+lines',
    marker=dict(color='#ff006e', size=8),
    line=dict(color='#ff006e', width=2),
    name='Trapezoidal (slope ≈ -2)'))

fig.update_layout(
    template='plotly_dark',
    xaxis=dict(title='N', type='log', zerolinecolor='#808080'),
    yaxis=dict(title='|Error|', type='log', zerolinecolor='#808080'),
    height=450, width=600)
fig.show()
