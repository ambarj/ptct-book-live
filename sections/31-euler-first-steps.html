Numerical Methods: Euler’s First Steps

So far, every oscillator we’ve studied had a neat analytical solution: sines, cosines, exponentials. But what happens when the equation gets messy — nonlinear springs, complicated forcing, friction that depends on velocity? Analytical solutions vanish. The only way forward is to let the computer march through time, step by step.

The simplest such marching method is Euler’s method, invented by Leonhard Euler in 1768. It’s beautifully simple: at each moment, follow the tangent line for a small time \( h \), then recalculate the slope and follow the new tangent. Think of it as navigating with a compass — you check your heading, walk a bit, then check again.

Learning Objectives
  • Explain why numerical methods are needed when analytical solutions fail
  • Implement Euler’s method: \( x_{n+1} = x_n + h\, f(x_n, t_n) \)
  • Observe how step size \( h \) controls accuracy vs computation
  • Identify Euler’s fatal flaw: energy drift in conservative systems

Euler’s method for a second-order ODE \( \ddot{x} = -\omega_0^2 x \):

Convert to a first-order system:

$$ \frac{dx}{dt} = v, \qquad \frac{dv}{dt} = -\omega_0^2\, x $$

Then step forward:

$$ x_{n+1} = x_n + h\, v_n, \qquad v_{n+1} = v_n + h\,(-\omega_0^2\, x_n) $$

Each step follows the current tangent for a time \( h \). The smaller \( h \), the more faithful the path — but the more steps you need.

Why does Euler’s method need to convert a second-order ODE into two first-order equations?
Explanation: Euler’s formula \( x_{n+1} = x_n + h\,f \) steps one derivative at a time. To handle \( \ddot{x} = -\omega_0^2 x \), we introduce \( v = \dot{x} \) and get two coupled first-order equations. This is a general technique: any \( n \)-th order ODE becomes \( n \) coupled first-order equations.
The Euler Recipe

Euler’s method in three lines of pseudocode:

  1. Evaluate the derivative: slope = f(current state, current time)
  2. Step: new state = old state + h × slope
  3. Repeat until you reach the final time

That’s it. Every numerical ODE method is a refinement of this basic idea — the differences lie in how they estimate the slope.

The Step Size Dilemma

A smaller step size means more accuracy — but more computation. A larger step size is fast but inaccurate. The left panel shows Euler’s solution (cyan) vs exact (green) for a step size you choose. The Fatal Flaw: Energy Drift

The SHO should conserve energy: \( E = \tfrac{1}{2}v^2 + \tfrac{1}{2}\omega_0^2 x^2 \) is constant. But Euler’s method breaks this. The left panel shows how the final error depends on step size. Both axes use a logarithmic scale (each tick mark is 10× the previous), so a straight line means a power-law relationship. If the data follows the dashed reference line, error is proportional to \( h \). The right panel shows the energy ratio \( E(t)/E(0) \) growing steadily above 1 — the numerical oscillator is gaining energy it shouldn’t have.

Why Euler Matters (Even Though It’s Terrible)

Euler’s method is inaccurate, energy-violating, and first-order. So why study it? Because every better method is built on the same idea: evaluate derivatives, step forward. Once you understand Euler’s strengths and weaknesses, you’ll immediately appreciate why smarter methods sample the slope at multiple points per step. Euler is the conceptual foundation; the Runge-Kutta methods in the next section are the practical tools.

Code Examples

Python 
import numpy as np
import plotly.graph_objects as go

def euler_sho(x0, v0, omega0, h, t_max):
    """Euler's method for the simple harmonic oscillator."""
    n_steps = int(t_max / h)
    t = np.zeros(n_steps + 1)
    x = np.zeros(n_steps + 1)
    v = np.zeros(n_steps + 1)
    x[0], v[0] = x0, v0

    for i in range(n_steps):
        x[i+1] = x[i] + h * v[i]
        v[i+1] = v[i] + h * (-omega0**2 * x[i])
        t[i+1] = t[i] + h
    return t, x, v

# Parameters
omega0, x0, v0 = 2.0, 1.0, 0.0
t_max = 10.0

# Exact solution
t_exact = np.linspace(0, t_max, 500)
x_exact = x0 * np.cos(omega0 * t_exact)

# Euler with h = 0.10
t_eu, x_eu, v_eu = euler_sho(x0, v0, omega0, h=0.10, t_max=t_max)

fig = go.Figure()
fig.add_trace(go.Scatter(x=t_exact, y=x_exact, mode='lines',
    line=dict(color='#00ff9f', width=2), name='Exact'))
fig.add_trace(go.Scatter(x=t_eu, y=x_eu, mode='lines',
    line=dict(color='#00f3ff', width=2), name='Euler h=0.10'))

fig.update_layout(template='plotly_dark',
    title='Euler vs Exact: Simple Harmonic Oscillator',
    xaxis=dict(title='Time (s)', range=[0, 10],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'),
    yaxis=dict(title='x(t)', range=[-3, 3],
        gridcolor='#2a2f4a', zerolinecolor='#808080', linecolor='#808080'))
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def euler_sho(x0, v0, omega0, h, t_max):
    n = int(t_max / h)
    t, x, v = np.zeros(n+1), np.zeros(n+1), np.zeros(n+1)
    x[0], v[0] = x0, v0
    for i in range(n):
        x[i+1] = x[i] + h * v[i]
        v[i+1] = v[i] + h * (-omega0**2 * x[i])
        t[i+1] = t[i] + h
    return t, x, v

omega0, x0, v0 = 2.0, 1.0, 0.0
h_values = [0.50, 0.20, 0.10, 0.05]
colors = ['#ff6b6b', '#ffff00', '#00f3ff', '#ff00ff']
t_max = 10.0
t_exact = np.linspace(0, t_max, 500)
x_exact = x0 * np.cos(omega0 * t_exact)

fig = make_subplots(rows=1, cols=2,
    subplot_titles=['Euler vs Exact', 'Error Growth'])

fig.add_trace(go.Scatter(x=t_exact, y=x_exact, mode='lines',
    line=dict(color='#00ff9f', width=3), name='Exact'), row=1, col=1)

for h, color in zip(h_values, colors):
    t_eu, x_eu, _ = euler_sho(x0, v0, omega0, h, t_max)
    fig.add_trace(go.Scatter(x=t_eu, y=x_eu, mode='lines',
        line=dict(color=color, width=1.5), name=f'h={h}'), row=1, col=1)

    # Error
    x_ex = x0 * np.cos(omega0 * t_eu)
    error = np.abs(x_eu - x_ex)
    error[error == 0] = 1e-10  # avoid log(0)
    fig.add_trace(go.Scatter(x=t_eu, y=error, mode='lines',
        line=dict(color=color, width=1.5), name=f'h={h}',
        showlegend=False), row=1, col=2)

fig.update_layout(template='plotly_dark')
fig.update_yaxes(type='log', row=1, col=2)
fig.update_xaxes(title_text='Time (s)', gridcolor='#2a2f4a',
    zerolinecolor='#808080', linecolor='#808080')
fig.update_yaxes(gridcolor='#2a2f4a', zerolinecolor='#808080',
    linecolor='#808080')
fig.show()
