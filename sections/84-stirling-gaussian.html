Stirling's Approximation & the Gaussian Limit

In Chapter 7 we asserted that the binomial distribution becomes a Gaussian for large \( N \). Now we prove it. The key ingredient is Stirling's approximation — a formula for \( N! \) that turns the unwieldy factorials in the binomial coefficient into a smooth, tractable expression. Apply it, expand around the peak, and the Gaussian emerges naturally.

Learning Objectives
  • State Stirling's approximation: \( \ln N! \approx N\ln N - N + \tfrac{1}{2}\ln(2\pi N) \)
  • Understand why it works: the sum \( \sum \ln k \) is well approximated by the integral \( \int \ln x\,dx \)
  • Apply Stirling to the binomial coefficient to derive the Gaussian limit
  • Quantify how the approximation error shrinks with \( N \)

Stirling's Approximation:

$$ \ln N! \approx N\ln N - N + \tfrac{1}{2}\ln(2\pi N) $$

Equivalently: \( N! \approx \sqrt{2\pi N}\,(N/e)^N \). The relative error is \( \sim 1/(12N) \) — already less than 1% for \( N = 10 \).

Explorer: How Good is Stirling?

Compare the exact \( \ln N! = \sum_{k=1}^{N} \ln k \) (a sum) with Stirling's approximation (a smooth formula). The left panel shows both curves; the right panel shows the relative error. Even at modest \( N \), the approximation is remarkably accurate.

Why Does Stirling Work?

\( \ln N! = \ln 1 + \ln 2 + \cdots + \ln N = \sum_{k=1}^{N} \ln k \). This sum is the area of \( N \) rectangles of width 1. The integral \( \int_1^N \ln x\,dx = N\ln N - N + 1 \) is the smooth area under the same curve. The difference — the Euler–Maclaurin correction — gives the \( \tfrac{1}{2}\ln(2\pi N) \) term. Bigger \( N \) means more rectangles, so the rectangle-sum hugs the integral more tightly.

Explorer: Binomial → Gaussian as N Grows

Here is the payoff: apply Stirling to the binomial \( P(m) = \binom{N}{(m+N)/2}\,2^{-N} \), expand \( \ln P \) around the peak at \( m = 0 \), keep terms to second order, and out pops the Gaussian \( (2\pi N)^{-1/2}\exp(-m^2/(2N)) \). Watch it happen: as \( N \) increases, the exact binomial dots converge onto the smooth Gaussian curve.

The Derivation in One Line:

$$ \ln P(m) = \ln\!\binom{N}{\frac{m+N}{2}} - N\ln 2 \;\;\xrightarrow{\text{Stirling}}\;\; -\tfrac{1}{2}\ln(2\pi N) - \frac{m^2}{2N} + O(m^4/N^3) $$

Exponentiating: \( P(m) \approx (2\pi N)^{-1/2}\exp(-m^2/(2N)) \). This is the Gaussian with variance \( N \) — exactly what we assumed in earlier sections.

The Big Picture

We have now closed the loop that spans the entire chapter: discrete random walk → binomial distribution → (Stirling) → Gaussian → diffusion equation. Every step is rigorous: the random walk gives an exact binomial, Stirling turns it into a Gaussian, and taking the continuum limit yields the diffusion PDE. The Gaussian is not an assumption — it is a theorem.

Python Code

Python

import numpy as np
import plotly.graph_objects as go
from scipy.special import gammaln

N = np.arange(1, 201)
exact = gammaln(N + 1)  # ln(N!) via log-gamma
stirling = N*np.log(N) - N + 0.5*np.log(2*np.pi*N)
stirling[0] = 0  # fix N=1

rel_err = np.abs(exact - stirling) / np.maximum(exact, 1e-15) * 100

fig = go.Figure()
fig.add_trace(go.Scatter(x=N, y=exact, mode='lines',
    line=dict(color='#00f3ff', width=2), name='exact ln(N!)'))
fig.add_trace(go.Scatter(x=N, y=stirling, mode='lines',
    line=dict(color='#ff006e', width=2, dash='dash'), name='Stirling'))
fig.update_layout(template='plotly_dark',
    xaxis=dict(title='N', zerolinecolor='#808080'),
    yaxis=dict(title='ln(N!)', zerolinecolor='#808080'),
    height=400)
fig.show()

print(f"Relative error at N=10: {rel_err[9]:.3f}%")
print(f"Relative error at N=50: {rel_err[49]:.4f}%")

import numpy as np
import plotly.graph_objects as go
from scipy.special import comb

for N in [10, 50, 200]:
    m = np.arange(-N, N+1, 2)
    k = (m + N) // 2
    binom = np.array([comb(N, ki, exact=True) * 2.0**(-N) / 2 for ki in k])
    gauss = np.exp(-m**2 / (2*N)) / np.sqrt(2*np.pi*N)

    fig = go.Figure()
    fig.add_trace(go.Scatter(x=m, y=binom, mode='markers',
        marker=dict(color='#ffbe0b', size=5), name='binomial'))
    fig.add_trace(go.Scatter(x=m, y=gauss, mode='lines',
        line=dict(color='#ff006e', width=2), name='Gaussian'))

        yaxis=dict(title='P(m)', zerolinecolor='#808080'),
        height=350)
    fig.show()

import numpy as np
import plotly.graph_objects as go
from scipy.special import comb

Ns = np.arange(4, 202, 2)
max_errs = []
for N in Ns:
    m = np.arange(-N, N+1, 2)
    k = (m + N) // 2
    binom = np.array([comb(N, ki, exact=True) * 2.0**(-N) / 2 for ki in k])
    gauss = np.exp(-m**2 / (2*N)) / np.sqrt(2*np.pi*N)
    max_errs.append(np.max(np.abs(binom - gauss)))

fig = go.Figure()
fig.add_trace(go.Scatter(x=Ns, y=max_errs, mode='markers+lines',
    marker=dict(color='#00f3ff', size=6), name='max |error|'))
fig.add_trace(go.Scatter(x=Ns, y=max_errs[0]*(Ns[0]/Ns),
    mode='lines', line=dict(color='#ff006e', dash='dash'),
    name='1/N reference'))
fig.update_layout(template='plotly_dark',
    xaxis=dict(title='N', type='log', zerolinecolor='#808080'),
    yaxis=dict(title='max |P_binom − P_Gauss|', type='log',
               zerolinecolor='#808080'),
    height=400)
fig.show()
