Introduction to Visual Thinking

Before diving into equations and algorithms, let's develop our intuition through visual thinking. The human brain processes images 60,000 times faster than text. By visualizing mathematical relationships, we can understand complex physics intuitively before formalizing our understanding.

Learning Objectives
  • Learn to represent data and functions visually
  • Understand function behavior through interactive exploration
  • Build intuition before diving into mathematics
  • Master basic plotting with Python

What is Visual Thinking?

Visual thinking is the practice of using visual representations—graphs, charts, diagrams, and animations—to understand and communicate ideas. In computational physics, we use it to:

  • Explore - See patterns before proving them mathematically
  • Verify - Check if our calculations make sense
  • Communicate - Share insights with others effectively
  • Discover - Find unexpected behaviors in systems

Comparing Function Growth

Different functions grow at different rates. Let's compare how \( \sqrt{x} \), \( x \), \( x^2 \), and \( x^3 \) behave near the origin and far away.

Interactive: Function Growth Comparison
Test Your Understanding

Use the function growth comparison above to answer these questions.

Set the slider to show x from 0 to 5. Which function grows the FASTEST as x increases?
Explanation
For large values of x, higher powers dominate.

At \( x = 5 \):
- \( \sqrt{5} \approx 2.24 \)
- \( 5 = 5 \)
- \( 5^2 = 25 \)
- \( 5^3 = 125 \) ← Largest!

This is why in physics, when analyzing behavior for large systems, we often only keep the highest power term!

- At \( x = 2 \): \( \sqrt{2} \approx 1.41 \)

Notice how \( \sqrt{x} \) grows slowly - doubling x from 2 to 4 doesn't double \( \sqrt{x} \)! This sublinear growth is important in physics.
Adjust the slider and observe the functions. Which are TRUE? (Select all that apply)
Explanation
All statements are TRUE!

Statement 1: At \( x = 0.1 \): \( x = 0.1 \) but \( x^3 = 0.001 \) (much flatter).
Statement 2: At \( x = 1 \): \( \sqrt{1} = 1 \), \( 1 = 1 \), \( 1^2 = 1 \), \( 1^3 = 1 \). This special point is where they all meet!
Statement 3: \( \sqrt{x} \) is sublinear - grows slower than even \( x \) for large values.
Statement 4: \( 0.1^2 = 0.01 < 0.1 \). Higher powers are smaller near zero!
Important Observation

Near \( x = 0 \), higher powers grow slower (they're flatter). Far from the origin, higher powers completely dominate. This asymptotic behavior is crucial in physics!

Python Code Examples

Let's see how to create these plots in Python using Plotly — the same library powering the interactive plots you see on this page. Learning one plotting approach works everywhere!

One Library, Less Confusion

Throughout this book, we use only Plotly for all visualizations. The same code patterns you see on this webpage work in your Python scripts. No need to learn multiple plotting libraries — focus on physics and problem-solving instead!

Python 
import numpy as np
import plotly.graph_objects as go

# Generate x values
x = np.linspace(-10, 10, 200)

# Define the function
y = 2*x - 5

# Create the plot
fig = go.Figure()
fig.add_trace(go.Scatter(
    x=x, y=y,
    mode='lines',
    name='f(x) = 2x - 5',
    line=dict(color='cyan', width=2)
))

# Styling
fig.update_layout(
    template='plotly_dark',
    title='Linear Function',
    xaxis_title='x',
    yaxis_title='f(x)',
    xaxis=dict(range=[-10, 10], zeroline=True),
    yaxis=dict(range=[-35, 35], zeroline=True)
)

fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

# Quadratic function plotter
def plot_quadratic(a=1, b=0, c=0):
    x = np.linspace(-10, 10, 200)
    y = a*x**2 + b*x + c

    fig = go.Figure()

    # Plot the parabola
    fig.add_trace(go.Scatter(
        x=x, y=y,
        mode='lines',
        name=f'f(x) = {a}x² + {b}x + {c}',
        line=dict(color='cyan', width=2)
    ))

    # Calculate and plot the minimum/maximum
    if a != 0:
        x_vertex = -b / (2*a)
        y_vertex = a*x_vertex**2 + b*x_vertex + c

        fig.add_trace(go.Scatter(
            x=[x_vertex], y=[y_vertex],
            mode='markers',
            name='Minimum' if a > 0 else 'Maximum',
            marker=dict(color='magenta', size=10)
        ))

    # Styling
    fig.update_layout(
        template='plotly_dark',
        title='Quadratic Function',
        xaxis_title='x',
        yaxis_title='f(x)',
        xaxis=dict(range=[-10, 10]),
        yaxis=dict(range=[-25, 50])
    )

    return fig

# Try different values
fig = plot_quadratic(a=1, b=0, c=0)
fig.show()
Python 
import numpy as np
import plotly.graph_objects as go

# Generate x values
x = np.linspace(0.1, 5, 200)

# Create figure
fig = go.Figure()

# Add multiple functions
functions = [
    {'name': '√x', 'y': np.sqrt(x), 'color': 'cyan'},
    {'name': 'x', 'y': x, 'color': 'magenta'},
    {'name': 'x²', 'y': x**2, 'color': 'yellow'},
    {'name': 'x³', 'y': x**3, 'color': 'lime'}
]

for func in functions:
    fig.add_trace(go.Scatter(
        x=x, y=func['y'],
        mode='lines',
        name=func['name'],
        line=dict(color=func['color'], width=2)
    ))

# Styling
fig.update_layout(
    template='plotly_dark',
    title='Function Growth Comparison',
    xaxis_title='x',
    yaxis_title='f(x)',
    showlegend=True
)

fig.show()

Create a Python script using Plotly to plot the linear function f(x) = 2x - 5

Write a Python function using Plotly that plots a quadratic function
f(x) = ax² + bx + c. The function should calculate and highlight the
minimum or maximum point with a magenta marker. Use dark theme, cyan line
for the parabola, gray axes. Set x range to [-10, 10] and y range to
[-25, 50].
Prompt for Multiple Functions 
Create a Plotly visualization comparing four functions: √x, x, x², and x³
on the same plot from x = 0.1 to 5. Use different neon colors (cyan, magenta,
yellow, lime) for each function. Apply dark theme and show a legend. This
should demonstrate how different power functions grow at different rates.
Pro Tips for Effective Prompts
  • Be specific: Mention the library (Plotly), colors, ranges
  • Describe the goal: What should the visualization show?
  • Include constraints: Fixed ranges, specific styling
  • Iterate: If the first result isn't perfect, ask for adjustments
  • Learn from output: Study the generated code to understand patterns
